# 退货入库自动化

通过售后系统 Web 面板批量把退货快递单号录入快麦 ERP「售后工单新版」，并执行创建与收货。

## 日常使用

1. 打开售后系统：`http://localhost:3457`。
2. 进入「退货入库」Tab，粘贴快递单号。
3. 点击「开始处理」，逐条查看结果。

业务操作由售后系统的全局 `op-queue` 串行执行，不要同时运行 CLI 或其他 ERP 自动化任务。

## 处理结果

| 状态 | 含义 |
|---|---|
| `已入库` | ERP 已完成创建并收货 |
| `未出库无需入库` | ERP 没有可关联订单，通常是未出库或单号无效 |
| `错误: ...` | 页面状态、加载或操作异常，保留具体原因 |

## 稳定性策略

- 页面状态轮询与必要的稳定延时配合使用；不能只靠固定延时，也不能在 Vue 状态刚切换时立刻执行下一步。
- 点击「继续关联」后先等待关闭动画和请求启动，再最多等待 45 秒加载订单；轮询间隔为 1 秒。
- 关联弹窗必须同时匹配「提示」标题和「继续关联」按钮；主弹窗必须精确匹配「新建售后工单」，禁止依赖弹窗 DOM 顺序。
- 「创建并收货」属于真实 ERP 写操作，不自动重试提交。

具体运行边界和文件地图见 [SKILL.md](SKILL.md)。

```bash

```
