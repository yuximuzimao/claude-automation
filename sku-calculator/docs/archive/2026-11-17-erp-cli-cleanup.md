# ERP 读取命令收尾修复

日期 2026-11-17

## 修复记录

`be3a9204` 为 `resolve-components` 和 `resolve-stock` 加入了 `releaseErpLock()` 收尾。`4afd67da` 移除共享模块的旧接口后，这两条命令在查询完成时仍会退出 1，查询抛出的原始错误也可能被收尾错误覆盖。

修复移除了两处旧导入和仅用于解锁的 `try/finally`。ERP 查询、店铺选择、匹配检查和结果输出的代码与修复前一致。库存计算仍按[操作手册 §5](../operations.md#5-erp-接入run-full-流程)执行售后手动停启。

- 逐行对比修复前的 CLI，确认代码差异限于两条 ERP 命令的解锁收尾及缩进。

本轮使用模拟 ERP 响应，验证范围为 CLI 调用顺序、退出码与本地流程。真实 ERP、售后服务和业务运行数据均未操作。
