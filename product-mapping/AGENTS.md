# Codex 项目入口

进入本目录后遵循根 `AGENTS.md` 的统一启动顺序，不维护第二套顺序：

1. 先读 `SKILL.md`，用它定位本次任务的权威规则；
2. 再读 `CLAUDE.md`、`tasks/todo.md`、`docs/INDEX.md`；
3. 当前若是 ChatGPT 通过 CodexPro 操作，**在执行任何正式商品匹配命令前**额外读取 `docs/chatgpt-codexpro-operations.md`；
4. 涉及自动匹配、断点恢复或 ERP 页面异常时，再读取 `docs/matching-stability.md`。

本文件只负责启动路由，不复制业务规则或执行细节。
