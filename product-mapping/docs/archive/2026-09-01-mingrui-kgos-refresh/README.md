## 本轮异常与处置

- ERP 对应表曾因页面分页状态异常从第 1 页跳到第 3 页；用户刷新 ERP 后，同一读取流程正常完成 4 页。
- 套件流程两次遇到“选择商品 / 换对应商品”弹窗状态与脚本预期不一致；均在 stop-on-error 后先检查 ERP 当前状态，再按目标商品和数量定向完成，没有从头重复写入。
- `km-read` 定向查询在完整 JSON 已输出后仍未自动退出，最终被 CodexPro 180 秒上限终止；结果本身已完整返回。该现象属于执行进程生命周期，不等同于 ERP 查询失败，现行 `docs/chatgpt-codexpro-operations.md` 已覆盖“timeout 不等于业务操作完全失败”的处理原则，本轮不再新增重复规则。
