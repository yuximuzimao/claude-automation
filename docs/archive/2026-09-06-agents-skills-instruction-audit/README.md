# AGENTS / Skills 指令审计归档

日期：2026-09-06
状态：已完成并验证。本目录只保存历史证据，不是现役规则入口。

## 本轮目标

审阅并收紧全局 AGENTS 与个人 Skills 中关于自主性、澄清、批准和任务完成的约束，避免重复确认、提前停止、无意义过度工程和越权，同时保留用户明确要求的业务、写作与设计决定权，并兼容 Astra 与 ChatGPT/Sol 经 CodexPro 的日常执行方式。

## 最终决策

- 用户级 AGENTS：收紧“进入新项目先确认规则”的语义，并把授权范围与完成判据合并成一条短规则。阶段由用户授权定义，阶段内可连续完成必要工作和验证；跨范围、改方向或触及用户保留决定权时重新获批。业务逐步批准规则不变。
- `hv-analysis`：只做技术兼容，修当前工具能力映射、实际 Skill 路径与隔离依赖环境；研究方法、PDF、字数、署名、arXiv 和来源要求不变。
- `web-access`：公开搜索、读取和 curl 不再被未使用的 CDP 前置检查阻断；进入 CDP 路径时仍保留浏览器、登录、授权和风险要求。代理停止改为精确进程归属处理；不同 tab 不再被描述为共享状态“无竞态”。
- `storage-analyzer`：只修“扫描只读”与必须生成 JSON/HTML 报告的文字冲突。被扫描数据仍只读，报告输出可写；移动和清理仍按原确认规则。
- `frontend-design`：完整设计流程只用于新界面或用户明确同意的整体重设计。局部维护按用户需求和现有视觉体系执行；模型认为重设计更好时可提出，但未获同意不得因此停止原定局部修改。
- `khazix-writer`、`aihot` 保持原内容；备用三技能的方法论、作者定位、触发与交付定义冻结，未来只允许官方更新或另行批准的纯技术兼容修复。
- PUA 已退出 Codex 与 Claude Code 的活跃工作流；`grill me` 未安装，也未创建替代排障 Skill。现有验证、读回、业务批准和范围边界继续由各自正式规则承担。
