# 项目别名路由表

用途：把用户的中文项目名、简称或触发词映射到英文目录，并顺手记录极简项目属性。命中目录后，按 `AGENTS.md` / 根 `CLAUDE.md` 的启动顺序读取该项目入口文档。本文不维护项目流程、当前业务状态或跨项目关系。

轻量属性只保留三项：
- **类型**：自由标注，例如一次性工具；不要求所有项目都必须填写。
- **生命周期**：`活跃` / `已完成` / `已废弃`。
- **维护级别**：`长期维护` / `按需维护` / `不维护`。

项目重新启用、完成或明确放弃时，只更新对应标注，不因为使用频率或最近更新时间自动改变状态。
