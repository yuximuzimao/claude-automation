## 算法当前状态

- 最新架构与理论来源统一见[2026-09-12装箱算法研究](2026-09-12-packing-algorithm-research.md)：完整结构为 `1～N箱外层 + 单箱几何内核`，单箱只是 `N=1` 特例。
- 当前单箱内核算法版本为 `single-carton-geometry-stability-split-v3`。物件顺序已进入搜索维度，保留确定性排序、等价类/旋转去重和共享 deadline；“薄礼袋先铺底”反例继续通过。
- 几何有效性与稳定性已拆层：边界/碰撞是硬条件；离地物件至少需要实际承重点；完整底面支撑改为独立指标。求解器优先完整支撑方案，当前预算内没有时才返回部分支撑方案，并报告最低底面支撑覆盖率供3D人工复核。
- 候选点已升级为混合 frontier / Extreme-Point 风格层：优先低 z、高支撑和已放物件直接边界点，同时保留旧表面坐标笛卡尔组合作兜底；同类物件增加规则网格 fast path。自动选箱按剩余候选公平分配节点预算，避免小箱耗尽100000节点导致后续大箱未被尝试。
- 下一算法主线只剩完整 `pack_order()` 1～N箱外层及其盲测。历史人工拆法、历史箱型和固定容量答案继续不得进入求解输入；UNKNOWN 也继续不得解释为装不下。
