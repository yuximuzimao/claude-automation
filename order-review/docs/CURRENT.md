## 下一阶段：把尺寸计算接到推荐兜底

线上调用顺序已经确定，不能调整成每单都计算：

1. 同一订单保存方案、唯一无冲突精确历史、相同总量单包、唯一历史包裹模块精确
   组合、固定业务规则或确认箱规命中时，直接复用，不运行三维计算。
2. 精确规则存在冲突时交给人工，不用尺寸计算替某个分支背书。
3. 只有没有可靠结果的新组合才运行三维求解；`single_package_capacity` 等近似
   容量可以显示为参考，但不能阻断更可靠的尺寸结果。
4. 新组合先判断整单一箱；确需拆分时先保持平台子订单完整，再只拆无法整体安排的
   子订单。同包裹数下减少被拆子订单、跨包片段和交叉混装片段。
5. 尺寸不足、搜索超限或没有同品牌可用纸箱时保持人工处理，不输出虚假的确定方案。
6. 尺寸推荐只生成本地可解释候选，必须带箱型、摆放证据和规则来源；不得自动保存、
   拆单、审核或执行其他 ERP 写操作。

实现前先确定线上候选数据结构、搜索耗时上限和缓存方式，再用现有回放问题集比较
覆盖率、错误率、包裹数和耗时。不要重新扩展多包比例投影、容量单调性或按历史次数
静默排序。
