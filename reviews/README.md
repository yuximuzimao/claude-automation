# 日记回顾索引

这里存放个人日记的周回顾和月回顾，内容来源主要是 Apple Notes 日记条目，并结合必要的项目记录、周回顾和提交历史做交叉校验。

## 目录

- `weekly/`：周回顾，文件名格式 `YYYY-Www.md`，按 ISO 周编号。
- `monthly/`：月回顾，文件名格式 `YYYY-MM.md`。

## 写作约定

- 周回顾优先基于该周日记原文，必要时补充项目提交和任务记录。
- 月回顾优先综合当月周回顾，再补充项目层面的实际产出。
- 不写流水账，重点抽取反复出现的模式、转折、风险和可延续观察点。
- 不把单次回顾结论写进根 `CLAUDE.md` / `AGENTS.md`；这些文件只放会影响后续 AI 工作的规则。
