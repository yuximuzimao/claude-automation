# 软件工程与 AI 系统设计学习

这是一个独立的长期学习项目，目标是帮助非程序员项目负责人建立判断 AI 辅助软件设计的能力。

重点解决的问题：在 AI 将业务需求转换成技术方案时，能够发现尚未表达的条件、隐含假设、边界遗漏和实现风险；不因听懂自然语言解释，就误以为已经验证了底层设计。

## 学习范围

- 需求发现与需求工程
- 业务建模、领域概念与系统边界
- 软件架构、模块职责和接口契约
- 状态机、数据归属、并发与故障恢复
- 测试设计、风险驱动验证与可靠性
- 可观测性、日志和链路追踪
- AI Agent / Harness 工程化治理
