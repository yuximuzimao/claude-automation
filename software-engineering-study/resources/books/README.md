# 本地教材资源

本目录保存五本原始教材 PDF 的主副本。原始 PDF 不提交 Git，处理时只读，不修改、不重命名。

- 版本、页数、文件校验值和目录证据见 ../../docs/book-audit.md。
- 五本 PDF 的工作副本已放入 Workbuddy“杂事”工作区中的“教材流水线/原始教材PDF/”；复制时 SHA-256 与本目录主副本一致。
- 逐章提取、独立复核、修订和进度状态遵循 ../../docs/book-processing-protocol.md。DeepSeek 是唯一主控；千问办公为默认复核模型，可由 Kimi K2.8 或 Kimi 3.1 Pro 替代。
- 全部章节处理完成后，整个“教材流水线”文件夹应迁回 ../processed-books/教材流水线/；若忘记，Codex 应按项目 Todo 从 Workbuddy“杂事”工作区找回并整体迁回。
- 正式学习时只读取当前知识单元对应的最终章节 Markdown 和图表资源，不加载整本教材。
