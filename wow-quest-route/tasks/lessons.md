# 临时教训

- 2026-07-30：WTF中的插件SavedVariables只能证明历史使用或预设，不能证明当前AddOns仍安装插件；必须核对.toc和核心代码。
- 2026-07-30：逐日岛任务的`zoneOrSort`为3431，而NPC/物体spawns使用3430；区域识别需要独立映射。
- 2026-07-30：路线数据必须保留原始刷新点，不能把人工选取的代表坐标误称为完整坐标。
- 2026-07-30：五开路线的离开条件不能只看主号完成；个人掉落、物体交互、技能和物品触发必须逐号检查。
- 2026-07-30：RXP SavedVariables可能保留当前指南、指南目录、等级段和下一指南，但不一定包含`.accept/.goto/.turnin`正文；只能使用实际存在的元数据，不能还原不存在的路线步骤。
- 2026-07-30：打怪掉落物直接触发任务时，候选路线可能只有接取/交付而没有普通目标节点；极简页面必须合成一个明确的掉落步骤，否则统计会正确但用户页面漏标。
- 2026-07-30：每个`【打怪掉物·必做】`或`【打怪掉物·可跳】`任务都必须由测试反查到实际页面步骤，不能只验证内部分类数量。
- 2026-07-30：单页极简不等于任务数量很少；应压缩为接取批次、目标批次和交付批次，同时把6—80自动推导状态明确留在内部归档。
- 2026-07-30：Questie的`preQuestSingle`表示“列表中任选一个完成”，`preQuestGroup`表示“列表中全部完成”；把两者都当作全部前置会制造大量假断链。
- 2026-07-30：任务筛选完成后必须做跨地图前置闭包；能在更早阶段找到的前置补入，无法由主路线满足的后续任务删除，最终未满足前置必须为0。
- 2026-07-30：RXP地图阶段不能机械保留。若前置闭包后某次地图回访没有独立可接任务，应由相邻地图覆盖等级并删除空标签。
- 2026-07-31：按动作类型连续合并“接取/目标/交付”会跨越多个真实任务点，生成文字整齐但路线失真；空间位置必须优先于动作类型。
- 2026-07-31：Questie目标的平均坐标和刷新边界不能代表一个小区域。永歌森林实测证明鱼头、失落的军备、浸水的书页、法力水晶和豹皮不能按大范围坐标簇合并。
- 2026-07-31：炉石绑定、飞行点和回程不是可省略的常识，而是决定少回头路线的核心步骤。鹰翼广场必须显式提醒绑定炉石。
- 2026-07-31：页面重点应落在任务名本身。颜色直接落在任务名上，但必须按实际五开负担判断，不能把所有收集或点击任务机械标红；不要在句尾追加重复分类标签。
- 2026-07-31：未经实跑的自动任务顺序不能称为稳定攻略，但可以明确标注为“全任务审阅母版”直接公开，用于先完成覆盖；实跑后再升级为固定流程。
- 2026-07-31：任务物品类型不等于五开负担。单个命名怪必掉1件、固定物体单次点击应归为低负担；真正需要规避的是随机掉落或多数量个人收集被五个角色放大。
- 2026-07-31：任务颜色与路线可选性是两个独立维度。绿色任务也可能因长巡逻或高成本前置而放入补经验清单，红色任务也不能仅靠颜色解释前置关系。
- 2026-07-31：任务链前置必须直接展示给玩家。地图图标不能解释为什么任务接不到；单一前置应明确写“必须先完成《任务名》”。
- 2026-07-31：可跳支线夹在主流程中会破坏阅读和执行。应从主步骤移除，放在地图末尾按同级基础经验排序，经验不足时再选择。
- 2026-07-31：坐标距离只能作为实跑反馈标签。固定阈值应可见，并允许用户标记“实际过远”后集中反馈，而不是让算法自动宣称路线最优。
- 2026-07-31：五开判断是生成器的内部决策依据，不是用户执行任务时需要反复阅读的信息；用户详情应只保留会改变下一步操作的内容。
- 2026-07-31：详情中的“无前置”“经验计算说明”和完整Questie描述会稀释重点。经验放在任务标题旁，无前置不显示，正文只保留突出前置、地点、重点目标和最短流程。
- 2026-07-31：怪物名和任务物品名不能只靠句子语义辨认，必须作为独立视觉关键词高亮；主步骤中的目标字段也应使用同一强调方式。
- 2026-07-31：同一页面不同地图不能混用段落式和结构化格式。旧地图也要迁移到地点/NPC/目标/操作结构，避免用户重新学习两套阅读方式。
- 2026-07-31：人工整理不等于宣称实跑正确。幽魂之地和贫瘠之地可以依据前置、坐标、任务目标与负担形成验证版，但必须明确标注尚未实跑，并把高风险步骤列为验证重点。
- 2026-07-31：用户已明确将“完成全部地图人工初版”置于“逐地图实跑确认”之前。后续不能要求先验证前三张地图才继续，也不能在每张地图后停下来等待反馈。
- 2026-07-31：自动发布只解决“任务覆盖是否完整”，不解决“路线是否可用”。任务取舍、任务中心划分、道路与移动顺序仍需通过人工审阅和实跑修正。
- 2026-07-31：洞穴名称和Questie代表坐标不能直接转成“进入洞穴”的执行指令。《幽光矿洞的麻烦》五开实跑在洞内因密集怪、巡逻怪及周边蜘蛛蝙蝠连续死亡；任务目标可在西侧约24,50的外部稀疏区域完成，路线必须优先给出安全拉怪点。
- 2026-07-31：Questie任务存在不代表当前服务器一定可完成。《飞往银月城》实跑遇到黑色城门且无法进入，原因尚未确认；无法验证的服务器/位面阻断任务必须记录并跳过，不能让单个任务阻塞升级主目标。
- 2026-07-31：首组角色与重复打金角色的目标不同。首组圣骑士只需稳定到55级解锁死亡骑士；后续应以55级死亡骑士五开为标准样本，重复跑55—80主要地图，不能继续用首组1级路线承担长期打金流程。
- 2026-07-31：全任务覆盖母版与最终最优路线是两个阶段。第一版必须先把所有可执行任务展示出来，实跑后再根据收益、死亡、折返和逐号操作将地图与任务分成主流程、补充和跳过。
- 2026-08-01：Questie人物历程来自账号级`QuestieConfig.char[*].journey`，一个`Questie.lua`同时容纳多个角色条目；不能把整个文件当作单一角色日志，也不能再把`profiles`误当成历程存储位置。
- 2026-08-01：Questie不记录死亡。两小时以上空档应先视为离线/长暂停；较短空档只能作为死亡、跑尸或任务耗时的复盘候选，不能直接换算死亡次数。
- 2026-08-01：《暗松巨魔的武器》在15、16、19、20级共接取并立即放弃4次、完成0次，应先按强跳过候选处理并调查是否由掉落物反复触发。
- 2026-08-01：《飞往银月城》后来在20级完成，早期黑色城门只能标为临时阻断；未找到稳定复现方式前保持可跳，但不能再宣称永久不可完成。
- 2026-08-02：Questie给矿工哈克特的31.12,58.63只是地图投影坐标，不能据此判断目标在矿洞入口或洞外。用户实跑确认哈克特位于矿洞内部；错误的“入口清怪并等刷新、不进洞”指令导致约30分钟无效搜索。今后洞穴目标若没有实跑路径，只能写“需进洞，内部路径待验证”，不得用外部地图坐标编造楼层、深度或刷新位置。
- 2026-08-02：规划敦霍尔德时只保留了549《通缉：辛迪加成员》，没有提前枚举同地点可接的498《拯救行动》，导致用户完成549并回塔伦米尔交付后才接498，再次前往敦霍尔德。去任何远端区域前必须同时检查已接任务、当前可接任务、同目的地支线和交付后立即出现的后续。
- 2026-08-02：用户所说的“一段路线”是当前地图的完整可执行任务块，不是一次往返或一两个任务。输出必须包含本区域剩余主线、可合并支线、明确跳过项、离图条件和下一区域候选，避免每完成一个任务就要求用户再次询问。
- 2026-08-02：任务名称必须是执行文本的主标识，格式固定为《任务完整名称》（编号）。只写541、547等编号会迫使用户来回翻任务日志，编号只能用于精确定位，不能隐藏名称。
- 2026-08-02：随机掉落用于平衡五号经验时，应让低经验且缺物品的角色补刷怪物经验，高经验号离开经验范围；但不能机械只让低号交任务，任务奖励若大于现有差值会造成反向拉开。
- 2026-08-02：连续步骤不等于同一区域。《清除半人马》和《异型卵》目标区分离，路线必须显式写“离开半人马区后前往卵刷新区”，不能用“在同一区域继续找”制造空间歧义。
- 2026-08-02：回到同一个任务中心时必须枚举本轮所有可交任务。返回乱风岗交《异型卵》时遗漏《清除半人马》，会让用户误以为后者需要延后交付。
- 2026-08-02：可选任务必须在标题和执行条件中明确标记。《信仰的试炼》只是经验储备，不是闪光平原硬前置；同时必须给出55,45上坡入口、53,41—42洞穴和只从木板末端跳下的机制。
- 2026-08-02：不能因任务类型是护送就机械跳过。《终获解救》位于阿纳克附近，护送与下山路线重合、途中本来就要清怪，本服交付约4700经验，应按路线重合度和实际失败成本评估。
- 2026-08-02：地图进入等级必须从具体任务最低等级推导。闪光平原四项任务28级即可接，只有《减轻负重》要求29级；错误的29级硬门槛会制造无意义磨怪。
- 2026-08-02：固定数量收集任务只有全部完成才能兑现经验。《火箭车零件》五个角色各30个，不能写“只补到足够升级为止”；部分进度不是可计入经验预算的确定性收益。
- 2026-08-02：个人拾取任务不能只按“是否个人拾取”二元分类，还必须同时衡量每号数量、掉落稳定性、目标距离和是否可并入既定路线。《另一条路》每号仅2份纯净之土，虽然较远，但仍优于10—30件个人收集。
- 2026-08-02：命名怪任务要验证同一尸体是否可供五号分别拾取。《超适应齿轮》首组确认只杀一次黑豹即可让五号分别拾取，属于高经验、低重复战斗任务，不能按普通个人掉落降权。
- 2026-08-02：经验预算不能只列任务奖励总量，还要在关键交付点用实际最低经验检查是否缺少完整任务块。本轮西部主任务交完后实际至少差约两个任务，说明此前“接近29级”的估算没有足够安全余量。
- 2026-08-02：后续经验预测固定拆成三层：确定交付的精确任务经验；任务明确要求的强制击杀保守经验；沿途怪、补掉落和探索全部按0。禁止再用“正常打怪大概够”填补任务奖励缺口。
- 2026-08-02：任务优先级必须综合任务经验、强制怪数量、跑路时间、回头路、每号拾取数量、经逐任务确认的拾取机制、物体交互、刷新密度和后续链收益。任务类型只是输入，不是结论。
- 2026-08-02：用户要求的“一轮”以主要执行任务的地图切换为边界；主城、飞艇、船和纯交通地图不机械单独计轮，但其交付必须并入相邻地图轮。
- 2026-08-02：千针石林西部阶段终点精确为最低29级12184/36300、最高29级16968/36300；从27级起点计算，最低增加60304，最高增加61264，经验差扩大960。
- 2026-08-02：预设地图等级段不能反过来支配任务选择。荆棘谷可在高效共享与固定任务做完后约31级离图，阿拉希可在31—32级进入；不能为了兑现“30—34”“34—36”标签强刷低效率个人任务。
- 2026-08-03：自动`world-candidate`区域候选不能证明任务覆盖完整。《回家》（4770）未出现在任何自动候选目录中，但实际位于风巢高地收集双足飞龙蛋的同一路线；每次路线必须额外检查现场NPC、野外护送、物品/物体触发、跨区归属、任务链闭包和未来回访，并用“候选并集－路线任务－明确跳过任务”做差集对账。
- 2026-08-04：击杀/掉落路线不能把Questie散点机械连成覆盖大环线。闪光平原乌龟、食腐鹫、蝎子各有集中刷新区，五开个人掉落应直奔集中点、完成一类再换下一类；没有实跑密度验证时只能标候选路线。
- 2026-08-04：《流放者马特克》（1106）不是首次抵达赛车场即可接。实跑历程确认必须先完成并交付《含盐的蝎毒》（1104）和《硬化龟壳》（1105），之后1106才出现；`preQuestGroup`必须转成玩家可见的接交顺序。
- 2026-08-04：Questie账号历程导入需要容忍SavedVariables中的少量非UTF-8字节，但只能替换异常文本字节，不能影响任务ID、等级和Unix时间戳；解析输出必须脱敏，不保存角色键。
- 2026-08-04：五开出现单号经验明显领先时，先逐号检查同一任务是否漏交。本次2788经验差来自其余角色忘记交《猎龙》（195），不是路线漏了未知任务；交付后必须确认任务从五个日志中都消失。
- 2026-08-04：新飞行点开启后要重新查看直飞列表。斯通纳德实测可直飞藏宝海湾，继续经格罗姆高中转属于无效飞行时间。
- 2026-08-04：34级角色可以正常命中翠绿幼龙，但睡梦雏龙附近蜘蛛几乎无法命中；任务路线不能因目标相邻就默认周边怪可顺路处理，必须按具体怪物实测命中率避让。
- 2026-08-04：阶段等级目标只代表旧经验保证预算结束，不能自动变成顺路任务停止线。达到35级后仍要复算下一地图进入等级，把当前任务按同区域收尾、明确回访、未来地图和真正不可做分类；本次撤销了直接跳过1107、5361和猎虎后续的错误结论。
- 2026-08-06：误把普通五人小队转换为团队会使普通任务物品无法获取；开始任何掉落任务块前必须检查队伍类型。当前服已验证的普通自由拾取任务物遵循“一具尸体只由一个当前缺物品的角色拾取一次”，五号轮换最慢号；只有逐任务确认的Party Loot、共享或个人例外才能改用其他规则。
- 2026-08-06：《摩克萨尔丁的魔法》（571）成年大猩猩肌腱在时光服实测约2%—5%，约1小时仅2/5角色完成；已有进度不能成为继续投入的理由，低掉率且无高价值后续的任务必须立即止损。
- 2026-08-06：路线目标应是单位时间经验最大化，而不是“低风险任务全部做”。历史低等级均速不能线性外推39→55；当时两条候选的时间估计只用于识别明显异常，不能替代后续真实等级、经验和任务块耗时。
- 2026-08-06：单号视频只证明任务、地点、入口和机制可行，不能证明五开最优路线或速度。五开任务经验不分摊且共享击杀只做一次，优化器必须从部落全任务池独立选块，视频遗漏任务仍可能是最优项。
- 2026-08-06：不能把“需要主号操作”作为统一成本。主号正常战斗、骑乘、短跳和短暂绕路属于基线或低增量成本；逐号切换、逐号定位、断跟随、刷新等待和失败重跑才是五开额外成本。
- 2026-08-06：对尸体/场景物使用任务道具不假设必须同时输入；主号同步全队或五号短串行都可接受。机制本身不降权，仍按目标分布、击杀总量和真实操作秒数判断。
- 2026-08-06：保证路线不依赖拍卖行、邮寄或制作材料；已有材料只开启额外奖励。零购买任务池仍足以闭合39→55经验。
- 2026-08-06：玩家执行攻略不能使用纯任务ID、任务ID串或模糊交付。每次引用必须写`《完整任务名》（ID）`；每个地点标题必须写`地点名称（坐标）`；每次返回任务中心必须逐项列出交付和接取，禁止“交2975、2978”“返回交5211和6021”“以及已完成的任务”“交所有任务”等写法。坐标必须紧跟地点或目标名称，禁止放在动作句末。
