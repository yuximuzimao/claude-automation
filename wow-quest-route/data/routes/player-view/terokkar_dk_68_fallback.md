# 泰罗卡森林 · 68级补经验三任务

白骨荒野三任务小路线；需要补经验时单独执行。

## 步骤 1｜沙塔尔前哨站：接三任务
- 沙塔尔前哨站
- 沃尔昆 → 接【待实测】《恐怖圣物》
- 指挥官拉瓦伊 → 接【待实测】《不适当的葬礼》
- 斥候纳弗林 → 接【待实测】《夜间的绑架》

## 步骤 2｜尸体区 → 恐怖圣物 → 灵网山脊
- 白骨荒野·尸体区
- ↳ 做【待实测】《不适当的葬礼》
- 被遗弃的篷车·恐怖圣物
- ↳ 做【待实测】《恐怖圣物》
- 灵网山脊
- ↳ 做【待实测】《夜间的绑架》
备注：
- 《不适当的葬礼》：对尸体使用任务火炬完成焚烧；不是普通击杀。

## 步骤 3｜返回沙塔尔前哨站交三任务
- 沙塔尔前哨站
- 沃尔昆 → 交【待实测】《恐怖圣物》
- 指挥官拉瓦伊 → 交【待实测】《不适当的葬礼》
- 斥候纳弗林 → 交【待实测】《夜间的绑架》

## 步骤 4｜沙塔斯 → 奥格瑞玛
- 陆路：沙塔尔前哨站 → 沙塔斯·奥格瑞玛传送门
- 沙塔斯·奥格瑞玛传送门
- 固定交通：沙塔斯·奥格瑞玛传送门 → 奥格瑞玛
- 奥格瑞玛

三项交完后跑到沙塔斯的奥格瑞玛传送门，传送到奥格瑞玛后结束本路线。
