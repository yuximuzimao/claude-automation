## 关于"5 个号"的说明

5 个账号（Account #1 至 #5）的 `SavedVariables/Questie.lua` 文件内容几乎完全相同（文件大小相差不到 300 字节，事件数完全一致）。这是因为：

1. 新手盒子（NewBeeBox）可能在账号间同步了 WTF 配置
2. 或者 Questie 的账号级 SV 在所有账号登录时被合并保存

**无法从 SavedVariables 文件推测每个账号对应哪个 profile**。如需区分，需在游戏内分别登录每个角色查看 Questie 历程面板，或检查角色级目录名：

```
WTF/Account/<账号#>/<服务器>/<角色名>/SavedVariables/
```

角色级 Questie.lua 均为空（`QuestieConfigCharacter = nil`），但角色目录名本身能揭示对应关系。
