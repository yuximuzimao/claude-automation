- 定位：这是“老手成熟、反复实跑”的外部实战基线，今后新号路线设计必须优先拿它做地图主轴对照；它的战略优先级高于本项目此前依靠Questie候选逐任务拼接出来的地图顺序。

## 一、地图主轴：以后优先按整张图/任务中心推进

### 1—20级：血精灵本地链

- 正常走血精灵出生区、永歌森林、幽魂之地任务。
- 约20级跟任务到幽暗城方向后，不把幽暗城内部任务当作练级主轴；利用传送宝珠/部落交通尽快转到奥格瑞玛—十字路口。

推荐主轴：

`十字路口 → 陶拉祖/石爪山脉（按等级择一或串联） → 千针石林入口`

- 十字路口任务尽量整片清，老手给出的离图经验约为27—29级。
- 约25级可去石爪山脉。
- 约27级可补陶拉祖；也可以石爪山脉清完再清陶拉祖营地。

### 58级左右以后：外域与诺森德统一采用“顺序清图”方法

这里的“同一个概念”指**路线设计方法相同**，不是把外域和诺森德当成同一块地理区域：进入新阶段后不再从全世界挑任务，而是按成熟地图顺序连续推进。当前55—80只进行高价值任务包的初步筛选，已设计好的正式路线在用户确认和反向审查前保持不变。

外域起步主轴先记录为：

`奥格瑞玛 → 外域入口 → 地狱火半岛 → 赞加沼泽 → 后续外域地图依次推进`

- **2026-08-18纠正适用边界：低收益任务剔除原则只用于68级以前。** 此前把老手“跳低收益掉落/拾取任务”的口述写成“外域及以后”范围过宽。用户重新向老手确认：68级进入诺森德后，任务本身的满级折金/装备/金币属于收益来源，诺森德不应再为了纯升级速度批量删慢任务。外域及更前面的地图仍可使用“拾取墙钟 vs 装备/链条收益”筛选。
- 奖励机制本身不能简化成“外域拾取任务都不给装备”：已有任务数据存在直接装备奖励和短后续装备奖励的明确例外。因此初步筛选必须按任务链检查：直接给装备的拾取任务列为保留候选；本任务不出装但短后续出装的按任务包评估；整链只有经验/消耗品且需要额外拾取的列为强跳过候选；几乎零边际成本、与必做任务完全重叠的拾取即使不出装也可以列为保留候选。
- **“地狱火半岛＋赞加沼泽到约68”同样只保留为压缩后的阶段口述，不再当成两张图的保证经验。** 当前同服双倍任务经验视频事实显示，另一条成熟路线是地狱火推进到约64、赞加约65，再由纳格兰等后续地图继续到68；这至少证明达到68前很可能还需要第三张外域地图任务块。后续复用路线的候选筛选按“每图先把无装备收益的多掉落/多拾取任务列为跳过候选→继续评估下一张成熟地图→只在出现接取等级或战力断层时考虑补回前图任务”；这里只产出候选，不直接覆盖正式路线。地狱火和赞加不要求分别命中固定离图等级；第三张外域地图可作为经验缓冲区。

## 二、任务优先级：地图轴先于任务类型

以后顺序固定为两层：

### 第一层：先决定地图是否值得进

1. 优先连续清当前地图/当前任务中心。
2. 只有下一张图整体效率明显更高、或当前图出现明确等级断层时才转图。
3. 飞艇、跨大陆、长距离飞行和必须重复回城的成本要直接视为任务块成本；不能为了一个“理论高经验任务”忽略7—15分钟转场。
4. 不再用“哪里有几个好任务就插过去”的方式拼路线。

### 第二层：同一地图内部再排任务

默认优先级改为：

1. **共享刷怪/高密度击杀任务：最高。** 五开主号连续杀怪即可全队推进，操作负担最低；血精灵圣骑士在特定类型目标上还有职业伤害收益。
2. **固定拾取、固定场景物、固定交互任务：第二。** 没有随机掉率长尾，虽然要逐号操作，但耗时可预测。
3. **顺路护送：按刷怪高优先级处理。** 若护送与主路重合、不需要独立等待/回头，继续保留；若存在长等待、失败重跑、明显绕路再单独降权。
4. **随机掉落任务：最低。** 尤其是五号分别需要多件、掉率波动大、需要为了掉落继续补刷的任务；只有与高优先级刷怪高度重叠或有强后续链时才保留。

这个优先级不是“看见掉落任务就全部删掉”，而是明确打破此前把多种任务成本混在一起逐项估值的平权思路：五开速度路线首先追求稳定、高密度、可连续推进的墙钟效率。

### 下一批新号实验：1—57尽量减少“刷怪随机掉任务物”任务

老手补充的长期经验需要精确定义：他指的是**杀怪后随机掉任务物、需要继续刷怪补掉落**的任务，外域以前通常不接；他目前没有建议跳过固定场景物拾取。固定场景物/固定交互在首组实跑中通常耗时较短、可预测，所以暂时正常保留。这个意见只作为下一批新号的**实验假设**，不是把首组历史路线改写成错误，也不是永久禁止所有掉落任务。

下一批从1级重新练时，1—57级先建立一条“低随机掉落路线”对照分支：

1. 默认降权或跳过需要杀怪后随机掉多件任务物、掉率波动大、五号需要持续补刷的任务；固定场景物拾取、固定物体逐号点击暂时保留，不进入这次实验的删除对象。
2. 优先用共享击杀、单个命名怪、固定拾取/固定交互、顺路护送、连续任务链和自然刷怪经验补足地图切换等级。
3. 每个地图离开前记录最低号等级/经验，并与首组原路线比较：少做了哪些随机掉落任务、少了多少任务经验、节省多少墙钟、是否仍能自然达到下一地图的合理进入等级。
4. 首组已经出现过“随机掉落任务删得太多，后续经验跟不上”的实际情况，因此实验不追求零掉落。若经验出现缺口，优先补回与主体刷怪高度重合、需求数量少、掉率高或能开启高价值后续链的随机掉落任务，找出达到转图等级所需的**最小随机掉落任务集合**。
5. 单命名怪一次击杀后拿一个任务物、同尸体五号都能拿到任务物，或掉落任务本身几乎不增加额外刷怪时间的，不与普通10—30件随机收集任务同等处理；它们可以作为低成本例外保留。
6. 这个实验边界到进入外域为止。**58级进入外域后不套用“尽量少做随机掉落”规则**：外域任务本身给的钱明显更多，任务奖励装备和沿途装备也具有出售价值，任务选择重新按“经验 + 墙钟 + 金币/装备变现 + 后续链”综合判断。诺森德同样不继承1—57的实验性硬降权。

实验成功的判据不是“完全零随机掉落”，而是验证能否在不造成经验断层、也不显著增加纯刷怪/转场时间的前提下，用更少的随机掉落任务稳定达到各地图切换等级。

## 三、血精灵圣骑士职业加成与装备规则

- 人形、亡灵目标优先级上调。当前惩戒天赋中的《征伐》本来就对人形、亡灵、恶魔、元素提供额外伤害；老手实战也明确建议优先打亡灵和人形怪。
- 升级天赋和满级天赋不是同一套。老手明确建议升级阶段把《偏斜》点满；该项先作为高优先级老手情报进入天赋复审，后续不要直接沿用满级输出模板。
- 蓝色装备只要是明确提升，就提高对应任务优先级。
- 力量、敏捷类装备奖励的任务优先级上调，因为装备提升会反馈到后续整个练级阶段的击杀速度；不能只按该任务本身经验评价。
- 武器仍是最高装备检查项之一；接近当前等级、明显提高武器伤害的蓝色双手武器尤其值得顺路拿。

## 四、与首组真实路线的结构对照

首组20—50实际地图轴曾出现：

`贫瘠 → 石爪 → 灰谷 → 南贫瘠 → 石爪 → 东部王国 → 千针/闪光 → 荆棘谷 → 悲伤 → 荆棘谷 → 菲拉斯 → 塔纳利斯 → 尘泥 → 塔纳利斯 → 菲拉斯 → 荆棘谷 → 辛特兰 → 灼热`

老手主轴则接近：

`十字路口/贫瘠 → 石爪/陶拉祖 → 千针/闪光 → 尘泥 → 塔纳利斯 → 安戈洛 → 外域 → 诺森德`

因此后续新号优化的第一目标不是继续把旧地图轴上的单任务排序做得更精细，而是先删除不必要的地图振荡和跨大陆转场，再在每个保留地图内部优化任务顺序。
