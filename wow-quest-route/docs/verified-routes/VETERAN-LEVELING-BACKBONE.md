# 老手成熟练级主轴（高优先级外部实战基线）

更新时间：2026-08-09（UTC+8）

## 证据状态

- 来源：用户于2026-08-09转述长期实跑老手的最新路线与效率经验。
- 定位：这是“老手成熟、反复实跑”的外部实战基线，今后新号路线设计必须优先拿它做地图主轴对照；它的战略优先级高于本项目此前依靠Questie候选逐任务拼接出来的地图顺序。
- 边界：除用户自己已经实跑重合的部分外，不把老手的每一个等级检查点伪装成本项目首组已实测值。用户记忆不确定处原样标明，不擅自补数字。
- 核心结论：首要优化对象是“地图切换次数和任务中心连续性”，其次才是同一地图内部的逐任务取舍。飞艇/跨大陆一次常见就是7—10分钟甚至更久，频繁换图会吞掉大量本来可以用于连续杀怪和交任务的墙钟时间。

## 一、地图主轴：以后优先按整张图/任务中心推进

### 1—20级：血精灵本地链

- 正常走血精灵出生区、永歌森林、幽魂之地任务。
- 约20级跟任务到幽暗城方向后，不把幽暗城内部任务当作练级主轴；利用传送宝珠/部落交通尽快转到奥格瑞玛—十字路口。
- 老手自己的激进路线可以约15级就坐飞艇去十字路口，并称约2小时可到20—23级；这条属于老手个人速度路线，不要求首组当前角色回头验证。

### 20—32/34级：贫瘠之地体系为主，不跨大陆

推荐主轴：

`十字路口 → 陶拉祖/石爪山脉（按等级择一或串联） → 千针石林入口`

- 十字路口任务尽量整片清，老手给出的离图经验约为27—29级。
- 约25级可去石爪山脉。
- 约27级可补陶拉祖；也可以石爪山脉清完再清陶拉祖营地。
- 陶拉祖优先野猪人相关任务；“矿洞众星揽月”等高密度击杀任务也是老手举出的高效率类型。
- 老手还会在这个等级段使用凄凉之地；用户只记得“到32级大约需要一个半小时”，没有记清该1.5小时从多少级开始，因此只保留为效率参考，不写成精确阶段预算。
- 若等级已经超过32，则不要为补旧地图来回折返，直接转千针石林。
- 石爪山脉完整清理后的老手经验检查点约33—34级。

### 33/34—38/39级：千针石林 + 闪光平原

- 石爪结束后一路向南进入千针石林，再接闪光平原。
- 千针石林 + 闪光平原清完，老手经验检查点约38—39级。
- 不再为远端旧任务频繁返回十字路口、灰谷、东部王国或荆棘谷插任务。

### 38/39—42/43级：尘泥沼泽

- 从千针/闪光继续进入尘泥沼泽，按完整任务中心清理。
- 老手经验检查点：尘泥沼泽清完约42—43级。

### 42/43—48/49级：塔纳利斯/加基森

- 下一主地图固定为塔纳利斯，以加基森为任务中心。
- 目标是把适合等级的加基森/塔纳利斯任务连续清掉，而不是为了单个任务再跨图。
- **48—49只保留为阶段检查点，不再解释成“塔纳利斯单图保证离图等级”。** 当前项目的可执行任务预算不足以证明纯塔纳利斯户外任务必然从42/43推到48/49；如果本图一次性任务已经自然清空而等级仍低于口述检查点，应直接进入主轴下一张图，不在塔纳利斯无任务刷怪硬补等级。

### 50—58级阶段：安戈洛环形山 → 希利苏斯塞纳里奥要塞 → 艾萨拉

- **50→54：安戈洛环形山。** 用户首组本服实跑确认：50级进入安戈洛，把当前职业/前置可开的本图一次性任务全部做完后，除《无人知晓的秘密》（3908）和《新的泉水》（980）两条去冬泉谷的远后续外已无本图任务，实际离图等级约54级。

这里的“同一个概念”指**路线设计方法相同**，不是把外域和诺森德当成同一块地理区域：进入新阶段后不再从全世界挑任务，而是按成熟地图顺序进入一张图，尽量把当前可接的一次性任务完整清掉，再顺势进入下一张。

外域起步主轴先记录为：

`奥格瑞玛 → 外域入口 → 地狱火半岛 → 赞加沼泽 → 后续外域地图依次推进`

- 老手原则：外域任务基本都做，区别只在图内先后顺序；不再按旧思路大量跳任务后靠跨图补经验。

## 二、任务优先级：地图轴先于任务类型

以后顺序固定为两层：

### 第一层：先决定地图是否值得进

1. 优先连续清当前地图/当前任务中心。
2. 只有下一张图整体效率明显更高、或当前图出现明确等级断层时才转图。
3. 飞艇、跨大陆、长距离飞行和必须重复回城的成本要直接视为任务块成本；不能为了一个“理论高经验任务”忽略7—15分钟转场。
4. 不再用“哪里有几个好任务就插过去”的方式拼路线。

### 第二层：同一地图内部再排任务

默认优先级改为：

1. **共享刷怪/高密度击杀任务：最高。** 五开主号连续杀怪即可全队推进，操作负担最低；血精灵圣骑士在特定类型目标上还有职业伤害收益。
2. **固定拾取、固定场景物、固定交互任务：第二。** 没有随机掉率长尾，虽然要逐号操作，但耗时可预测。
3. **顺路护送：按刷怪高优先级处理。** 若护送与主路重合、不需要独立等待/回头，继续保留；若存在长等待、失败重跑、明显绕路再单独降权。
4. **随机掉落任务：最低。** 尤其是五号分别需要多件、掉率波动大、需要为了掉落继续补刷的任务；只有与高优先级刷怪高度重叠或有强后续链时才保留。

这个优先级不是“看见掉落任务就全部删掉”，而是明确打破此前把多种任务成本混在一起逐项估值的平权思路：五开速度路线首先追求稳定、高密度、可连续推进的墙钟效率。

## 三、血精灵圣骑士职业加成与装备规则

- 人形、亡灵目标优先级上调。当前惩戒天赋中的《征伐》本来就对人形、亡灵、恶魔、元素提供额外伤害；老手实战也明确建议优先打亡灵和人形怪。
- 升级天赋和满级天赋不是同一套。老手明确建议升级阶段把《偏斜》点满；该项先作为高优先级老手情报进入天赋复审，后续不要直接沿用满级输出模板。
- 蓝色装备只要是明确提升，就提高对应任务优先级。
- 力量、敏捷类装备奖励的任务优先级上调，因为装备提升会反馈到后续整个练级阶段的击杀速度；不能只按该任务本身经验评价。
- 武器仍是最高装备检查项之一；接近当前等级、明显提高武器伤害的蓝色双手武器尤其值得顺路拿。

## 四、与首组真实路线的结构对照

首组20—50实际地图轴曾出现：

`贫瘠 → 石爪 → 灰谷 → 南贫瘠 → 石爪 → 东部王国 → 千针/闪光 → 荆棘谷 → 悲伤 → 荆棘谷 → 菲拉斯 → 塔纳利斯 → 尘泥 → 塔纳利斯 → 菲拉斯 → 荆棘谷 → 辛特兰 → 灼热`

老手主轴则接近：

`十字路口/贫瘠 → 石爪/陶拉祖 → 千针/闪光 → 尘泥 → 塔纳利斯 → 安戈洛 → 外域 → 诺森德`

因此后续新号优化的第一目标不是继续把旧地图轴上的单任务排序做得更精细，而是先删除不必要的地图振荡和跨大陆转场，再在每个保留地图内部优化任务顺序。
