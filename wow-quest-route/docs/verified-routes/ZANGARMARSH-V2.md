## 2. 9731 + 9845 水域包

这是V2相对旧路线最重要的结构变化。

- 9845《下钩钓鱼》需要在第三泵阶段前后已接；第一次自然到萨布拉金时开飞行点、绑定炉石并接9845，不做全图专门预跑。
- 9731《抽水泵结构图》是怪物掉落物触发任务。抽水泵周边的蒸汽泵监工会掉任务起始图纸；第三泵/毒蛇湖附近还可由血鳞监工、血鳞召潮者掉落。拾取图纸后自动接《抽水泵结构图》。第二泵若自然掉图就保留，但**不强刷**。
- 第三泵/毒蛇湖附近，9728《热情的欢迎》的纳迦爪子来源与9731图纸来源高度重合：优先刷血鳞监工/血鳞召潮者，并顺手处理蒸汽泵监工。特殊条件按当前WotLK资料与本线结构处理：先处于9720《恢复平衡》四泵阶段再刷9731图纸；蒸汽泵监工可在泵旁随《恢复平衡》的铁藤种子交互再次出现，因此不要在此前专门刷。**离开第三泵阶段前确保图纸到位**。
- 图纸到位后，把 `C9731排水口调查 (约50.34,40.87) + C9845泥爪水域 (约51.98,41.68)` 绑定成一次不可拆水域服务。
- 水域包完成后，**直接在水中炉石萨布拉金**；不为了继续第四泵而从水域中央慢游上岸。
- 第四个9720水泵本身在陆地。炉石落地后T9845并接9903/9904，再把第四泵作为陆地动作处理。
- 四泵与9731均READY后，经萨布拉金飞塞纳里奥，一次性交T9720 + T9731及当时已经READY的塞纳里奥任务；不再把9720/9731留到地图结尾反向返东。
