# 46—47级藏宝海湾→55级五开执行攻略（人工复核修订版）

起点：五个号已到46—47级，人在藏宝海湾；本路线按炉石已经设在加基森执行，开始前看一眼炉石地点，避免灼热峡谷结束后才发现不能直回。目标只有一个：最低号到55级，到了立刻停止。

这版已经删掉《吓唬病鬼》（606）一类“看着顺路、实际经验已经衰减又要五号刷个人物品”的任务，也不再用任务类型一刀切。下面只写当前路线会遇到、会影响取舍的内容。

## 一、藏宝海湾：只做北上顺路块

时间预算：约30—45分钟，包括两次回藏宝海湾；这是首组正常刷新下的安排区间，不把随机等怪算成保证值。

### 1. 下船先交

- 奥格索普·奥布诺提斯（28.36,76.35）：《拯救OOX-22/FE！》（2767）。这条护送你已经实做完成，直接领奖。
- “海狼”马克基雷：《给马克基雷的货物》（2874）。

接《荆棘谷热疫》（348）、《船长的箱子》（8551）和《血帆海盗》（595）。

日志里若还留着未完成的《吓唬病鬼》（606）、《风险投资公司》（600）、《一捆海蛇草》（617）、《劈颅巨魔的獠牙》（209）或《裂骨项链》（598），现在放弃；已经显示完成的才交，不再补刷。

### 2. 从藏宝海湾一路向北

1. 出城沿海到血帆小营地约（27,69），点木桶上的纸条完成《血帆海盗》（595），原地接《血帆海盗》（597）。这两步虽然任务等级低，但没有刷怪和额外折返，边际时间很短。
2. 沿东侧海岸到（36,69）杀高拉什，五号逐个拾取箱子，完成《船长的箱子》（8551）。
3. 继续北上到猩猩洞（约35.2,60.4）。确认五号都有《荆棘谷热疫》（348），主号用1颗猩猩牙启动事件；三波猩猩后杀莫克，五号都点尸体拿莫克之心。
4. 回藏宝海湾交《荆棘谷热疫》（348）、《船长的箱子》（8551）和《血帆海盗》（597）；把同城对话《血帆海盗》（599）也交掉。

到这里停止血帆链，不接《血帆海盗》（604）。《血帆海盗》（604）要再去南部等10名流氓和两份文件，后续《血帆海盗》（608）还要第二次南下进三条船；从47级当前位置算，折返成本高于这两环的经验。若你此前已经做到《血帆海盗》（608），才把三船长收尾；按本路线新走的人不开始《血帆海盗》（604）。

不做从《甘祖拉恩》（586）开始的耶尼库链。它的任务等级合适，但第一环的猎头者、狂战士和其他巨魔共享刷新，后面又分散到水晶矿洞和莫什奥格洞穴；此时直接进辛特兰任务中心更快。

交完后从藏宝海湾飞行点直接飞格罗姆高，认准通往幽暗城的飞艇塔，不要坐去奥格瑞玛的那一班；到幽暗城后，如果《知识试炼》（1159）仍显示已完成，就顺手交掉，但不要接副本后续《知识试炼》（1160）。然后从幽暗城飞塔伦米尔，再从塔伦米尔沿主路向东进入辛特兰恶齿村。

## 二、辛特兰：外圈、海岸、辛萨罗一次做完

时间预算：原估约2小时15分—3小时15分；首组实跑在未单独补做《又一个给蛮锤部族的警告》（7842）的情况下，比原“最短预算”节点提前约10分钟完成，说明本段主轴节奏正确。后续把狮鹫羽毛改为纯顺路收益，不再把专刷羽毛计入本段必做时间。

### 1. 东海岸只做乌龟起手

从恶齿村北上，沿海岸杀10只海水钳嘴龟；立即回村交《钳嘴龟！》（7815），接《加莫里塔！》（7816）。先不继续北上：现在把命名龟后续带在身上，后面从辛萨罗一路向东时再收海岸目标，避免来回横穿。

### 2. 西部外圈、林吉和辛萨罗连做

从恶齿村一路向西：

- 沿路杀银鬃捕猎者和嗥狼，完成《银鬃捕猎者》（7828）。
- 枭兽不够时顺手杀同区普通狼，让共享刷新重新滚动；凑满10只《野蛮的枭兽》（7829）就停。
- 杀锋喙狮鹫，轮换当前缺物品的角色拾取，给五号补齐《死者的复仇》（7830）的任务羽毛。狮鹫还会掉可交易的“细长的狮鹫羽毛”；这件材料没接《又一个给蛮锤部族的警告》（7842）也会掉，先留够5根总量，别卖商店。
- 到蛮锤营地完成《给蛮锤部族的警告》（7841）的8斥候、5前锋、5游侠、2神射手。

到奎尔丹尼小屋（约32,48）后，先把笼子南面的道路清干净，再让五号接受《林吉被困住了！》（2742）的共享弹窗，由主号启动。途中有两波各3人的伏击；五号贴住林吉，不要为了路边怪离队。护送完成后不用找交付NPC，也不要横穿回恶齿村，直接沿南侧道路转向辛萨罗。

### 3. 辛萨罗逐层上山

辛萨罗不是一个平面营地。按坡道逐层上，不要照着地图箭头直爬山。

- 第一段开始留意地上的小罐：它像帐篷旁冒绿烟的小锅，不是杀怪掉落。《黑暗之瓶》（7850）每号要点5个，共25次；第三层开始出现，上层更多。
- 头骨在上层狼圈约（58.6,64.8）；骨头在下一层软泥坑约（62.1,75.4）。五号分别点击，完成《分离的痛苦》（7849）。
- 沿路完成《职位空缺：恶齿村卫兵队长》（7862）：5狂战士、3暗影猎手、3饮血者、2噬魂者，都是共享击杀。
- 顶层先清满5名邪枝精英卫兵，再集火海克斯本人。她会变蛙和治疗，制裁之锤优先留给她；完成《通缉：邪恶祭司海克斯和她的爪牙》（7861）。
- 到顶部断齿长者（59.7,77.8）交《被绑架的断齿长者！》（7845），接《找回钥匙！》（7846）；去守护者希坦亚（57.3,86.6）完成目标，回长者交《找回钥匙！》（7846）并接《向断齿族长复命》（7847）。这里不是护送，长者不会跟你走。

### 4. 从辛萨罗一路向东，最后一次回村

下山后不要直接回恶齿村。向东北经过锋喙狮鹫区（约59,50或63,43）时只顺手处理眼前狮鹫；“细长的狮鹫羽毛”不再专刷。若此时已经自然凑到5根总量就保留，未凑齐也继续东行，不为《又一个给蛮锤部族的警告》（7842）停路线。

继续向东：

1. 到邪枝营地工具点（66.4,44.8），五号逐个点击，完成《邪枝窃贼》（7839）；同区杀6名邪枝割颅者和2名占卜者，完成《野蛮的亲戚》（7844）。
2. 到拉尔德的午餐箱（约84,41）点击箱子，杀出现的3名绑架者，完成《拉尔德的午餐》（7840）。
3. 南下杀加莫里塔（约80.4,58.2），五号逐个拾取任务物，完成《加莫里塔！》（7816）。
4. 游到海上小岛（86.3,59.1），点击岛上的大石板完成《林吉被困住了！》（2742），并接到《林吉的秘密》（2782）；石板不是在悬崖上。

现在回恶齿村一次总交付：

- 交《加莫里塔！》（7816）、《银鬃捕猎者》（7828）、《野蛮的枭兽》（7829）和《死者的复仇》（7830）。
- 交《邪枝窃贼》（7839）、《拉尔德的午餐》（7840）和《野蛮的亲戚》（7844）。
- 交《向断齿族长复命》（7847）、《分离的痛苦》（7849）、《黑暗之瓶》（7850）、《通缉：邪恶祭司海克斯和她的爪牙》（7861）和《职位空缺：恶齿村卫兵队长》（7862）。
- 交《给蛮锤部族的警告》（7841）。只有此时已经自然凑齐5根“细长的狮鹫羽毛”时，才接《又一个给蛮锤部族的警告》（7842），分给五号并原地交掉；不足5根就跳过，不回头、不专刷。

此时NPC会给《给蛮锤部族的最后警告》（7843）。不接：插矛本身很短，但交点仍在恶齿村；保持加基森炉石的前提下，它会多出“横穿到鹰巢山、飞回恶齿村交、再飞塔伦米尔”的整段往返。

途中若自然掉了OOX-09/HL定位器，不为了机器人改变本轮路线；这条护送最终还要回藏宝海湾。现在从恶齿村飞塔伦米尔。

## 三、转场到灼热峡谷

时间预算：塔伦米尔到瑟银哨塔首次陆路约35—55分钟；灼热峡谷任务块约2小时30分—4小时。最大波动来自《无瑕之焰》（3442）的个人材料和寝室事件，不把《被盗：鼓风机和望远镜》（7728）的专刷时间算进去。

从塔伦米尔向东进阿拉希高地，经过落锤镇时给五号开飞行点。继续南下过萨多尔大桥，穿湿地、洛克莫丹到荒芜之地。注意：洛克莫丹西南“国王谷”通往灼热峡谷的石坝小径铁门需要《灼热峡谷钥匙》（5396），部落正常路线不走这里，也不为此拿钥匙；在洛克莫丹应继续向南进入荒芜之地。到卡加斯开飞行点并交已经完成的《流放者马特克》（1106），然后沿荒芜之地最西侧向南，到约（5,60）进入不显示在大地图上的山道，直接无钥匙进入灼热峡谷；灼热峡谷一侧出口约（69,54）。首组实跑若从萨多尔大桥坠落或误入锁门都属于转场损耗，后续新号严格按此防错。

到瑟银哨塔开飞行点，然后接齐这八个任务：

- 《悬赏：工头玛托留斯》（7701）
- 《让他们失眠！》（7702）
- 《绝密配方！》（7722）
- 《该死的手指头！》（7723）
- 《熔岩蜘蛛的威胁！》（7724）
- 《熏火龙》（7727）
- 《被盗：鼓风机和望远镜》（7728）
- 《工作机会：肃清竞争对手》（7729）

再到瑟银哨塔南侧约（39,39）找威拉罗克·温布雷（旧资料名：卡拉然·温布雷），接《神圣的惩戒》（3441）。接取后不要离开：再次与他对话，连续选择剧情对话选项直到任务完成，然后原地交掉并接《无瑕之焰》（3442）。《神圣的惩戒》（3441）没有前置，也不在瑟银哨塔最初那8个任务里。

### 1. 先清地表：《无瑕之焰》（3442）、傀儡和蜘蛛

- 《无瑕之焰》（3442）每号要4颗烈焰之心和4份傀儡之油，不是全队总共4+4。它们按普通FFA收集物处理：每具尸体只让一个当前缺材料的角色拾取，轮换给最慢号；不要五个窗口重复检查同一尸体。
- 优先杀大熔炉内外的炽热/地狱元素；熔岩元素可能同时给两类材料。目标元素没刷新时，杀同区熔岩怪推动刷新。
- 同圈杀20个重型作战傀儡完成《该死的手指头！》（7723），再杀20只巨型熔岩蜘蛛完成《熔岩蜘蛛的威胁！》（7724）。

五号《无瑕之焰》（3442）都完成后回卡拉然交，接《铸造火炬杆》（3443）。

### 2. 大熔炉只进一遍

从大熔炉北侧约（47,45）向下跳到金属平台进洞。先做熏火龙：进洞后看右下方的低层入口，跳下去清20只熏火龙；不要在坑底绕着找洞口。

之后沿矿道做这些：

1. 为《工作机会：肃清竞争对手》（7729）杀15名黑铁工头和15名奴隶贩子，都是共享击杀。
2. 《铸造火炬杆》（3443）的瑟银匕首：每号8把，不是杀12个矮人。奴隶工、工头、奴隶贩子、锻造师都能掉；每具尸体只切一个缺匕首的号拾取，按最慢号轮换，直到五号都8/8。
3. 到玛托留斯高台，先杀守卫和工头玛托留斯，再让五号逐个点击他身后的《绝密配方！》（7722）。入口和高台容易绕错：进矿道过大房间后找右侧上坡，不要一路走到恐龙区。
4. 到寝室做《让他们失眠！》（7702）。每号要20个枕头，共100次点击；先点第一个启动事件，再边捡边清两波昏睡矮人。约10分钟后女仆比拉凯琳出现，贴墙打避免击飞。她死后地上会出现华丽枕头，五号逐个点击并右键任务物接《看看它的个头！》（7704）。

《被盗：鼓风机和望远镜》（7728）只顺手。锻造师出鼓风机、哨兵出望远镜；既定目标全部完成仍缺任一件，就放弃《被盗：鼓风机和望远镜》（7728），不在少量刷新点反复蹲。

### 3. 卡拉然火炬链收尾

回卡拉然交《铸造火炬杆》（3443），接《烈焰之盒》（3452）。去西北暮光营地杀黑暗萨满、火焰卫士和地占师，五号各取1个拉格纳罗斯符记。当前参考库是高掉率，但旧服反馈波动很大；两轮营地仍没人出时，先检查五号是否都接了《烈焰之盒》（3452），再换怪种，不要把任务名看成固定箱子。

回卡拉然交《烈焰之盒》（3452），接并推进《惩戒火炬》（3453）；等锻造动画结束，再拿地上的火炬完成同名后续《惩戒火炬》（3454），和旁边侍卫对话接《烧掉它们！》（3463）。

四塔按这个顺序走：

2. （44.0,60.9）
3. （50.1,54.7）
4. （33.3,54.5）

每号装备惩戒火炬，走到塔上层的小火盆旁使用。东侧塔从绳桥上，不要站塔底点地图箭头。

回卡拉然交《烧掉它们！》（3463），接并原地开箱完成《打开箱子……》（3481）。再回瑟银哨塔集中交《悬赏：工头玛托留斯》（7701）、《让他们失眠！》（7702）、《看看它的个头！》（7704）、《绝密配方！》（7722）、《该死的手指头！》（7723）、《熔岩蜘蛛的威胁！》（7724）、《熏火龙》（7727）和《工作机会：肃清竞争对手》（7729），以及确实自然完成的《被盗：鼓风机和望远镜》（7728）。

## 四、安戈洛：两次护送＋一圈，最后从南口离开

时间预算：约2—3小时；买齐5个秘银外壳时包含A-Me护送，买不到时走无护送分支，通常更短。

在加基森拍卖行只查一次秘银外壳。价格能接受就买5个，每号1个；买不到或贵就直接出发，不制作、不收材料。

### 1. 南口先把拉克维链推到最后一环

从塔纳利斯南口下安戈洛：

1. 湖边完成《无人知晓的秘密》（3844）并接同名后续《无人知晓的秘密》（3845）；到马绍尔营地后先交《无人知晓的秘密》（3845），不接把路线带去冬泉谷的同名后续《无人知晓的秘密》（3908）。
2. 接《拉克维的食物》（4290）和《安戈洛的猩猩》（4289）。
3. 点固定蛇颈龙尸体拿肉，回托尔瓦交《拉克维的食物》（4290），接《拉克维的气味》（4291）。
4. 杀2只拉克维的配偶，五号取腺体；回托尔瓦交《拉克维的气味》（4291），接《拉克维的诱饵》（4292）。先不要召唤拉克维。

### 2. 马绍尔营地先做火山护送

到马绍尔营地先交《无人知晓的秘密》（3845），但不接冬泉谷后续《无人知晓的秘密》（3908）。开飞行点，然后接齐：

- 《找回A-Me 01》（4243）
- 《拉瑞安和穆尔金》（4145）
- 《抢救物资》（3881）
- 《异型的生态》（3883）
- 《走丢了！》（4492）
- 《究根问底》（974）
- 《当心翼手龙》（4501）

先去火羽山：

- 在任务标记点使用测温器完成《究根问底》（974）。
- 进洞找到林格，接《朋友的帮助》（4491）。把水壶拖到动作条；他晕倒就立即对他用水。没有脚本伏击，可以骑马，但要一直保持选中，别把倒地的林格丢在草里。
- 把林格带回马绍尔营地，走到营地NPC附近仍没完成时继续往洞口方向靠几步，等完成提示再交。

### 3. 东北猩猩洞和A-Me

去东北洞，沿右墙走到深处：

- 杀三类猩猩，给每号各收2张毛皮，完成《安戈洛的猩猩》（4289）。这是普通多件任务物：每具尸体只让一个缺对应毛皮的角色拾取；参考掉率100%只表示当前拾取号大概率拿到，不表示一只猩猩给五号各一张。
- 找到A-Me完成《找回A-Me 01》（4243）。
- 五号各有秘银外壳：分别与A-Me完成同名后续《找回A-Me 01》（4244），确认五号都进入护送任务后，由主号启动同名护送《找回A-Me 01》（4245）。洞口和洞外猩猩会呼救，启动前先清；护送时不采矿、不离开A-Me视野。
- 没有5个外壳：做到《找回A-Me 01》（4243）就停，不临时刷材料。

A-Me护送终点就在马绍尔营地附近。

### 4. 外圈和最后交付

从营地出发做一圈：

- 为《拉瑞安和穆尔金》（4145）把四类血瓣花各杀5只，都是共享击杀。
- 为《抢救物资》（3881）拿食物箱和研究设备两个固定物，五号逐个点。
- 为《当心翼手龙》（4501）杀10只狂怒翼手龙。
- 到南部虫巢入口（50,77）；进洞第一个岔口向左，到圆形房间（48,85）中央。五号站到房中央后分别使用背包里的刮取器完成《异型的生态》（3883），不是寻找地上的样本。

完成后回马绍尔营地，把《拉瑞安和穆尔金》（4145）、《抢救物资》（3881）、《异型的生态》（3883）、《究根问底》（974）、《当心翼手龙》（4501）、《朋友的帮助》（4491），以及条件完成的《找回A-Me 01》（4245）交清。《无人知晓的秘密》（3845）在初到营地时已经交过，不要在这里重复寻找；《拉瑞安和穆尔金》（4145）后出现的棘齿城后续不接。

然后骑到东部水晶塔后方平石（79,49）：先用肉，再对肉用信息素，拉克维会从来路跑来。杀掉后向南回托尔瓦，交《拉克维的诱饵》（4292）和《安戈洛的猩猩》（4289）。

不要接《强大的尤尔查》（4301）。它此时才开放，目标却又在东北猩猩洞；为16,300经验再横穿一次环形山并返回南口，不划算。

交完直接从南口回加基森，飞奥格瑞玛，乘飞艇到幽暗城。不要再返回马绍尔营地。

## 五、西瘟疫：用固定任务收口到55

时间预算：约2小时30分—4小时；做到第三锅后先看最低号，只有仍未到55才增加第四锅。包裹链包含一次幽暗城往返，已计入区间。

### 1. 幽暗城先闭合林吉后续

到魔法区找奥兰交《林吉的秘密》（2782）。交完别走，继续点她，原地完成《奥兰的感谢》（8273）；这是旧路线漏掉的即时后续。

再接《战斗的号角：瘟疫之地！》（5094），出城到亡灵壁垒交，接《误导血色十字军》（5096）。五号都从NPC旁边的箱子拿“瓶中火”，再去约（40,52）的血色营地。

从北侧清出一条口：先点帐篷用火烧，再插天灾军旗。插旗时必须脱战；五号逐个确认两项计数，不要以主号完成代替其他号。

回亡灵壁垒交《误导血色十字军》（5096），同时接《标记哨塔》（5098）和《瘟疫之锅》（5228）。《瘟疫之锅》不用出营地：当场交给暗影牧师范蒂丝，再接《目标：费尔斯通农场》（5229）。

### 2. 第一锅和费尔斯通包裹

到费尔斯通农场（37,57）：

1. 护锅者不在就杀锅周围亡灵推动刷新；杀护锅者，五号取钥匙，点大锅或链柱完成《目标：费尔斯通农场》（5229），并接《返回亡灵壁垒》（5230）。
2. 去农场东北房屋二楼找贾妮丝，五号接《迟到总比不到好》（5021）。
3. 到旁边谷仓点击包裹，完成《迟到总比不到好》（5021）后，再点同一个包裹一次，接到同名的幽暗城后续《迟到总比不到好》（5023）。只点一次会断链。

回亡灵壁垒交《返回亡灵壁垒》（5230），接《目标：达尔松之泪》（5231）。然后飞幽暗城：先到公会注册处附近（约69.8,43.2）找皇家管理人巴哈乌斯交《迟到总比不到好》（5023），接《杰雷米亚的忧伤》（5049）；再到银行下层找卖蟑螂的杰雷米亚·派森交《杰雷米亚的忧伤》（5049），接《好运护符》（5050）。

返回费尔斯通二楼找贾妮丝交《好运护符》（5050），接《两半合一》（5051）。杀在农场和房屋周围游荡的“喋喋不休的食尸鬼”；五号拿另一半护符后，右键包里任一半合并，再回二楼交《两半合一》；不要把普通食尸鬼当目标。

### 3. 第二锅和达尔松小事件

到达尔松之泪（46,52）杀护锅者、取钥匙、点锅完成《目标：达尔松之泪》（5231），并接《返回亡灵壁垒》（5232）。

同一农场按严格顺序做：

1. 五号先读谷仓地上的《达尔松夫人的日记》（5058）。它本身0经验，但不读就不掉厕所钥匙。
2. 杀厕所附近屋外的“游荡的骷髅”，不是屋内食尸鬼；同一尸体五号逐个拿厕所钥匙。
3. 用钥匙开厕所，完成《被锁起来的农夫》（5059）；杀跳出来的达尔松农夫，拿橱柜钥匙。
4. 去旁边房屋二楼开柜，完成同名后续《被锁起来的农夫》（5060）。

若一次开厕所没有让五号都完成，先核对各号是否都读过日记并拿到钥匙，再逐号交互；不要反复乱杀普通亡灵。

回亡灵壁垒交《返回亡灵壁垒》（5232），接《目标：嚎哭鬼屋》（5233）。

### 4. 第三锅、狼熊和安多哈尔

去嚎哭鬼屋附近找穆格雷斯·深水（约53.7,64.7），接《大自然的苦楚》（4984）：杀8只病狼，回交并接同名后续《大自然的苦楚》（4985），再杀8只病熊并交。

同区杀第三位护锅者，点锅完成《目标：嚎哭鬼屋》（5233），并接《返回亡灵壁垒》（5234）。然后去安多哈尔：

- 找克罗米接《时间问题》（4971），在粮仓旁使用时光置换器召出寄生虫，杀满10只；不用在城里找一只名为“时光寄生虫”的常驻怪。
- 交《时间问题》，接《找回时间》（4972）。废墟房间里找小锁箱，每号拿5只表，共25次点击；箱子密、刷新快，拿够即停。
- 同时做《标记哨塔》（5098）的四座塔。第一座只让主号在门侧使用信号火炬，检查五号是否一起涨进度；共享成立后其余三塔都只用一次。不要进塔内硬打精英。

在克罗米处交《找回时间》（4972），再回亡灵壁垒交《返回亡灵壁垒》（5234）和《标记哨塔》（5098）。检查最低号：到55立即停止。

### 5. 还没55才做第四锅

若最低号仍没55，接《目标：盖罗恩农场》（5235），去（62.5,58.5）。这里怪56—58级，五圣骑士能打，但先从北侧或东侧单拉外围幽灵；护锅者常带一只57级怪，不要五号散站引整圈。

杀护锅者、点锅完成《目标：盖罗恩农场》（5235），接《返回亡灵壁垒》（5236）；回亡灵壁垒交掉。最后找旁边的高级执行官德灵顿，接取并当场交《任务完成！》（5237）。这是整条四锅链的原地高额奖励，不能以为第四次《返回亡灵壁垒》（5236）交完就结束。

不再用《未竟的事业》（6004）补经验：它的法师和猎人与其他职业共享刷新，数量虽只各2个，实跑却可能长时间等怪。固定第三、第四锅比它可靠。

最低号到55后立即停止，不进东瘟疫，也不继续任何新链。
