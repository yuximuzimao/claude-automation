# 2026-08-05 五开副本刷怪经验测试协议

## 目的

比较五开副本纯刷怪与当前户外个人拾取任务的真实经验效率，不用视频标题或主观感受代替实测。

## 当前对照基准

- 37级后当前个人掉落阶段：约12430经验/小时。
- 36级到当前的综合实跑：约17590经验/小时。
- 37级29548到40级计划中心值：约18750经验/小时。

## 推荐测试顺序（已纠正）

1. 当前荆棘谷先止损：572羽毛停止主动刷；605水晶只补最后少量，设置15分钟硬上限。
2. 删除“血色修道院武器库作为第一测试本”的建议：武器库外门需要先从图书馆取得血色十字军钥匙，额外前置会污染短测成本。
3. 第一测试本仍可选奥达曼外层和前半段，不要求打通，不碰明显高等级后段首领。
4. 地下城查找器只按匹配队列处理，不再把“指定地下城可选”视为自由传送入口。官方已明确将时光服多开协同行为列为重点核查对象，因此不把五开号通过查找器传送作为执行路线。
5. 若以后仍要测试奥达曼，只采用陆路进入；可同时交638《巨魔之敌》、1106《流放者马特克》，并永久开启落锤镇与卡加斯飞行点。纯移动约45—55分钟，计入五号操作和走错风险按55—70分钟预算。
6. 到达后先做20分钟检查，合格才延长到40分钟。

## 测试方法

- 以五号中经验最低角色为统计对象。
- 记录进入前五号精确经验、是否有休息经验。
- 交通时间单独记录，不算入副本内部效率；决定是否长期刷时再加入总账。
- 计时从第一组怪进入战斗开始。
- 不交副本任务，不把一次性任务奖励混入纯刷怪速度。
- 按实际长期刷法操作：正常恢复、正常跟随；非必要尸体不逐号拾取。
- 在10、20、40分钟记录最低号经验，并记录死亡、团灭、跑尸、卡跟随和清到的位置。

## 20分钟判定

- 少于4000经验：低于12000经验/小时，立即退出，不替代任务路线。
- 4000—5999：约12000—18000经验/小时，只能替代深水或高数量个人掉落任务。
- 6000—7999：约18000—24000经验/小时，达到或超过当前综合任务速度，继续测试到40分钟。
- 至少8000：至少24000经验/小时，明显有效，可以考虑连续刷。

## 40分钟复核

副本内部速度与“从当前荆棘谷专程去奥达曼”的总速度必须分开：

- 少于12000：低于18000经验/小时，停止，不替代当前完整任务路线。
- 12000—15499：18000—23250经验/小时；只在已经位于卡加斯附近时替代低效拾取任务，不值得当前专程前往。
- 15500—16999：23250—25500经验/小时；计入约60分钟首趟交通和约5140顺路任务经验后，首次测试大致能超过当前最差个人掉落阶段，但仍未稳定超过完整任务路线。
- 至少17000：至少25500经验/小时；若无团灭和跟随故障，建议连续做三轮40分钟以内的同段测试/重置，交通被摊薄后才有较大概率超过当前约18750经验/小时的计划中心值。

只做一轮40分钟几乎不可能把首趟交通完全摊平；是否采用副本升级应以第二、第三轮的稳定结果决定。

## 强制止损

- 前20分钟出现一次完整团灭并造成明显跑尸：本次副本测试失败。
- 任意跟随号连续两次脱队或卡地形：停止，先解决控制问题。
- 10分钟内经验不足1500且不是因为刚进门整理队伍：提前退出。
- 不为证明副本可行而硬打高等级尾王；短测只评估可稳定重复的怪群。

## 总效率换算

副本内部经验率只回答“打怪快不快”。长期是否值得还要计算：

总经验率 = 副本获得经验 ÷（前往副本时间 + 副本战斗时间 + 出本重置/恢复时间）

若只刷一次，交通会显著降低收益；若连续刷多次，交通成本可以摊薄。
