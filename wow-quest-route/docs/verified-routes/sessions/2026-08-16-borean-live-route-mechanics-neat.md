## E — 本轮形成的实跑/审计证据

### 1. 玩家步骤必须按自然任务块合并，而不是按每条线拆步

北风原始几何仍需要多坐标点描述真实路线，但玩家操作层已经压缩为51个逻辑任务块。固定规则：

- 几何点/线段只负责保持路线形状；
- HUD、步骤列表、上一段/下一段和“播放当前段”都按玩家逻辑步骤工作；
- 同一局部扫怪、同一批NPC交接、同一连续任务块中可以包含多条几何线；
- 不得为了给每条线编号而把自然行动拆碎。

### 2. 战歌要塞飞行点不应在开场专程处理

完整复用路线已经删除开场单独跑飞行点的动作。正确顺序是做到《驭风大师图波尔》/《魔法飞毯》时本来就经过驭风大师，五号顺手开启战歌要塞飞行点，再继续任务。当前首组已提前开启属于本次现场历史，不覆盖下一批复用顺序。

### 3. 北风已确认五开机制

当前已由用户实跑确认并写入`data/observations/fivebox-task-types.json`：

- 11606《耐心是我们不需要的美德》：军需箱不共享，同一箱只能一个角色拾取；五号分别完成，以最低号15/15为离开条件。
- 11611《被掠走的苦工》：释放蛛网苦工进度五号共享；主控释放即可同步。
- 11602《切断虫源》：摧毁蛛卵簇进度五号共享；主控处理即可同步。
- 11676《慈悲为怀》：释放囚犯数量五号共享；主控获得牢笼钥匙后开笼即可同步推进全队，其他四号无需分别开笼。

### 4. 所有“怪掉物品后触发任务”必须写完整来源链

本轮发现“自然触发/顺路掉落”对实际执行不够。长期规则已经升级：所有怪物掉落任务起始物的任务，执行稿必须明确写出：

`打什么怪 → 怪在哪里/主要刷点 → 掉什么触发物 → 拾取后触发什么任务`

若来源怪不是普通常驻怪，还必须说明事件波次、稀有/巡逻、召唤、前置、阶段刷新、等待/不等待策略等特殊条件。

北风当前三条已完整化：

- 11632《寒风中的怪兽……》：战歌要塞南门约(43.2,56.5)检查事件；多波蛛魔后收割者伊斯里克斯出现，击杀后地面生成《伊斯里克斯的甲壳》，拾取触发任务。路线只检查一次，不等待，不在后续回战歌时绕南门复查。

### 6. 每一个路线任务都必须做“人类可执行性/隐藏机制审计”

用户指出《巨大的蛾卵》只给平面坐标仍会找不到，由此把检查从特殊任务抽样升级为逐任务强制审计。北风167条任务已全部逐条过一遍；普通直观任务审计后可以没有备注，但只要“只照任务名+Questie平面坐标仍可能找不到或不会做”，必须给执行备注。

### 7. 《授粉的巨蛾》与《巨大的蛾卵》应当同点完成

早期修正曾把《巨大的蛾卵》安排到迦莫斯洞穴后再从南侧坡道爬山，因为蛋在洞穴上方高处、不是洞内。

2026-08-16首组进一步实跑确认：

- 《授粉的巨蛾》的目标血孢巨蛾就在固定蛋附近非常集中；
- 因此正确路线不是“刷巨蛾→回去→打迦莫斯→再爬山拿蛋”；
- 新固定顺序为：接《授粉的巨蛾》→直接去巨蛋约(48.55,59.04)附近集中刷5份花粉→当场点击Massive Glowing Egg自动接《巨大的蛾卵》→一次回血法师劳莉丝同时交两条；
- 后续做完《折磨者迦莫斯拉》后直接返回，不再为巨蛋重复上山。

这次修正删除了一次明显的后续上山折返。

### 3. 11632只保留一次真正顺路的机会检查

《寒风中的怪兽……》唯一主动检查点固定为南岸炉石回战歌后自然出南门去农场时。若事件不在，立即离开；后续系统鸟回战歌等场景不再为它绕去南门。机会任务不得通过重复检查制造隐性折返。
