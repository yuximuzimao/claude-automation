# DK出生区必要攻略备注

用途：第一组五兽人双手鲜血DK从55级出生区开始实跑时，只记录**容易卡住、有选择、隐藏交互、载具/脚本事件或容易忘记恢复装备**的任务。这里不是路线规划，不规定接取顺序；普通“接—杀—拾取—交”任务按游戏提示执行即可。

证据原则：用户当前时光服实测优先；公开WotLK资料只用于补充任务机制。若当前服任务或技能提示与普通WotLK不同，以实机为准并回写本项目。

## 55级符文熔铸

### 《符文熔铸：战争的准备》

- 55级当前可用核心选择是**灰烬冰河**与**冰锋**；**堕落十字军到70级才解锁**。
- 第一组五号统一双手深鲜血：**55级先刻灰烬冰河，70级统一换堕落十字军**。
- 原因：灰烬冰河触发后强化接下来2次冰霜/暗影伤害，能覆盖冰冷触摸、死亡缠绕等混合伤害；冰锋稳定附加冰霜伤害并叠冰霜易伤，更偏持续冰霜输出。公开升级攻略对55级两者并非完全一致，因此这里按本项目“深血、双手、户外五开、少分叉”目标选择灰烬冰河，而不是声称它对所有DK都绝对最优。
- 符文熔铸**不耗材料**，在符文熔炉旁可随时覆盖，所以选错也没有沉没成本。
- 57级裂法、60级巫妖斩除、63级裂刃暂不设为固定换符文节点；首轮只在实跑证明确有价值时再测试。

## 容易漏但不需要完整攻略

- 《被遗弃的信件》：海文郡做前期任务时留意**邮箱上的信件**，属于容易从旁边跑过去的拾取任务。
- 新阿瓦隆市政厅相关任务：杀市长后，任务册/登记簿在**市政厅内桌子附近**，不是继续刷怪掉落。
- 《诺斯的特殊药剂》后续可重复换药，但第一组目标是验证任务打金效率，**不为了囤药额外刷头骨**；自然获得够交首轮即可。
- 《鲜血、冰霜与邪恶的力量》之类纯对话/教学任务没有必要单独查攻略。

## 首轮五开记录方式

出生区目前不预判共享性。遇到任务物、交互、载具或脚本事件时，以五号实测为准：确认“共享 / 不共享 / 一次击杀后可五号依次拾取 / 需要逐号执行”后，按`TASK_FACT`流程更新对应Task Card的结构化fivebox事实与`fivebox.status`。`data/observations/fivebox-task-types.json`在兼容期只能作为旧消费者所需的投影/历史证据，不再作为新事实写入口。不要从普通WotLK单号攻略直接推断五开机制。
