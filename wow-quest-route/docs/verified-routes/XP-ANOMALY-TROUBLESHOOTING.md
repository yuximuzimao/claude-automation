# 时光服经验获取异常处理

用途：记录五开实跑中已经亲自验证过的经验获取异常恢复方法，避免以后再次遇到同类问题时重新排查。这里只记录运行时故障处理，不改变任务路线、经验模型或职业配置。

## 已验证案例：单号经验约为其他号一半

2026-10-11 第二组兽人鲜血DK实跑时，主号在相同队伍与任务环境下获得的经验一度只有其他号的大约一半。用户现场通过“关闭经验获取，再重新开启经验获取”后确认经验恢复正常。

本次异常造成主号相对其他号约少10万经验；之后单独刷怪补齐的这部分经验属于异常后的人工补偿，不计入正常路线经验或墙钟样本。

## 恢复步骤

1. 先用同一批怪或同一任务奖励与其它号对比，确认不是等级、距离、死亡、任务状态等正常差异，而是单号持续少拿经验。
2. 前往负责经验获取开关的NPC。
3. 关闭该角色的经验获取。
4. 再重新开启经验获取。
5. 用一组可对比的击杀或任务奖励复核；确认经验恢复到正常水平后再继续正式实跑。

## 数据处理

- 异常持续期间的经验变化视为污染数据，不用于校准路线XP模型。
- 为补回缺口而单独刷怪的时间与经验也单独排除，不并入正式路线效率。
- 若以后再次出现，优先按上述流程恢复；如果关闭/开启无效，再作为新的异常单独排查，不默认与本次同因。

## 证据边界

- “关闭经验获取再开启后恢复正常”是2026-10-11用户现场亲自验证的结果。
- 用户根据百度/玩家讨论了解到“时光服可能会遇到此类问题”；这一归因目前没有在项目内独立验证，因此只作为社区说法保留，不把具体根因写成已确认事实。
