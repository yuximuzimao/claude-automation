# 首组血精灵圣骑士练级战斗备注

更新时间：2026-08-02 16:56（UTC+8）

## 时光服版本差异

- 不能直接套用早期巫妖王之怒练级视频或时光服2026年5月7日前的惩戒骑宏。
- 2026年5月7日调整后，惩戒骑的《清算之手》不再对未以自己为目标的敌人造成伤害；只有防护天赋树中的《清算》天赋才能恢复该伤害。
- 旧版所谓“19级后秒怪”很可能是把不占公共冷却的《清算之手》、审判和第一下双手武器攻击压在极短时间内，视觉上像一次击杀；当前纯惩戒路线不能复制这套起手伤害。

## 当前五开实战

- 用户已确认20级时学过一轮主要职业技能，因此不能把当前伤害差距简单归因于“20级后一直没学技能”。后续未学习的主要是若干技能等级提升，通常不会构成“19级以后突然秒怪”的完整解释。
- 五个角色分别投掷审判，可快速击杀单个普通怪；这属于五个伤害包叠加，不等于单个无传家宝惩戒骑一发秒同级满血怪。
- 用户24级时共有15点天赋：神圣系5/5《纯净圣印》，其余10点投入惩戒；因此当时尚未满足《命令圣印》所需的第11点惩戒天赋。
- 用户升到25级后已用新增的第16个总天赋点学习1/1《命令圣印》，并确认《命令圣印》和《正义圣印》是两个不同技能。
- 当前日常练级已切换为常驻《命令圣印》；《正义圣印》仍可作为另一种圣印保留，但不再是默认练级圣印。
- 后续新号的低级练级天赋应修正：10—19级优先在惩戒系投入10点，20级立即点出1/1《命令圣印》，不要先绕去神圣系投入5/5《纯净圣印》。这样可把核心练级圣印提前5级获得。
- 《命令圣印》本身只有1点，不存在5/5；20级点出后，21—24级获得的4点应继续放在惩戒系。若只追求战斗输出，可优先投入《定罪》；若按整条任务路线优化总耗时，可优先考虑《正义追击》的移动速度。25级时才可把一个5级天赋从4/5补到5/5。
- 当前双手剑熟练度119/120，且使用任务蓝色双手剑，已经基本排除武器熟练度过低和武器品质不足。
- 朋友所说的“19级后单号秒怪”仍缺少一个关键定义：是单个技能秒杀，还是单号用《清算之手＋审判＋白字/驱邪术》在极短时间内杀死。若该经验来自2026年5月7日前，旧版《清算之手》伤害宏是最可能解释；当前纯惩戒已无法复现。
- 如果前两到三个审判已足够击杀，就不必让剩余角色继续对同一目标过量施法，可把后续审判留给下一只怪。
- 圣印是施加给圣骑士自身的持续增益；真正对敌人释放的是审判。用户把《正义圣印》当作自身Buff使用是正确的。
- 《清算之手》当前可用于无伤害拉怪和调整目标位置，不应再作为惩戒骑伤害技能计入循环。

## 30级后的技能宏与装备检查点

- 当前30级实测：30—31级虎崽、豹崽单号也能快速击杀；闪光平原的战斗迟缓主要来自目标等级、命中和任务掉落，不应归因于整套装备失效。
- 30—34级仍以《命令圣印》、审判、白字和可用的驱邪术为主。此阶段可使用`/startattack`与单技能宏，但不值得照搬包含十字军打击、神圣风暴的满级循环宏。
- 35—36级点满《战争艺术》后，当前时光服版本会使审判伤害提高25%；十字军打击和神圣风暴尚未取得时，直接收益主要体现在审判。
- 40级取得1/1《智者审判》后，连续拉怪的法力续航明显改善，属于稳定练级循环的第一个完整节点。
- 50级取得《十字军打击》后，常用输出宏才开始真正有价值；60级取得《神圣风暴》后才形成包含审判、十字军打击、神圣风暴、奉献和驱邪术的完整循环。首组圣骑士若55级停止，不会在本阶段取得神圣风暴。
- 2026年5月7日调整后，纯惩戒路线的《清算之手》不能继续作为伤害技能；任何仍把它绑定进常用输出宏的旧攻略都应忽略。
- 55级前不安排整套装备刷取或副本毕业装。护甲继续使用任务奖励；40级学习板甲后逐件替换，不为凑齐板甲套装专程停级。
- 武器单独设两个检查点：35—38级、47—50级。若当前双手武器比角色低8级以上，或可稳定取得的新双手武器武器秒伤高15%以上，则允许安排一次短支线/购买；否则继续使用任务奖励。
- 50级前必须确保有一把接近当前等级的慢速双手武器，因为十字军打击按武器伤害结算。除武器外，不为命中装专门刷装备；优先通过不打高出3级以上的怪解决未命中问题。

## 25级洗点结果与后续顺序

- 首组五个角色已在幽暗城完成首次洗点，移除神圣系5/5《纯净圣印》。
- 当前25级16点统一结构：5/5《祈福》、2/2《强化审判》、3/3《十字军之心》、1/1《命令圣印》、2/2《正义追击》、3/5《定罪》。
- 五个号必须保持相同的2/2《正义追击》，避免主号移动更快导致跟随队形持续拉长。
- 后续优先顺序按当前希尔斯布莱德/敦霍尔德人形怪路线调整：
  - 26—28级：3/3《征伐》。对人形、亡灵、恶魔和元素等常见目标，每点收益高于单点《定罪》。
  - 29—30级：把《定罪》从3/5补到5/5。
  - 31—33级：3/3《双手武器专精》。
  - 34级：1/1《圣洁惩戒》。
  - 35—36级：2/2《战争艺术》。时光服已把该天赋对审判、十字军打击和神圣风暴的伤害加成提高到13/25%，到达层级后优先点满。
  - 37—39级：3/3《复仇》。
  - 40级：1/1《智者审判》；时光服该天赋已由3点压缩为1点，直接取得完整回蓝效果。
- 40级以后再根据时光服后续天赋树和实际五开战斗情况继续规划；不提前照搬旧版标准树的3点《智者审判》。

## 待实测

- 用户单号对同级怪和低2—4级怪的审判、第一下白字、驱邪术分别造成多少伤害。
- 五个角色是否都学习了当前等级可用的审判与驱邪术等级。
