# 首组血精灵圣骑士练级战斗备注

更新时间：2026-08-28（UTC+8）

## 时光服版本差异

- 不能直接套用早期巫妖王之怒练级视频或时光服2026年5月7日前的惩戒骑宏。
- 2026年5月7日调整后，惩戒骑的《清算之手》不再对未以自己为目标的敌人造成伤害；只有防护天赋树中的《清算》天赋才能恢复该伤害。
- 旧版所谓“19级后秒怪”很可能是把不占公共冷却的《清算之手》、审判和第一下双手武器攻击压在极短时间内，视觉上像一次击杀；当前纯惩戒路线不能复制这套起手伤害。

## 当前五开实战

- 用户已确认20级时学过一轮主要职业技能，因此不能把当前伤害差距简单归因于“20级后一直没学技能”。后续未学习的主要是若干技能等级提升，通常不会构成“19级以后突然秒怪”的完整解释。
- 五个角色分别投掷审判，可快速击杀单个普通怪；这属于五个伤害包叠加，不等于单个无传家宝惩戒骑一发秒同级满血怪。
- 用户24级时共有15点天赋：神圣系5/5《纯净圣印》，其余10点投入惩戒；因此当时尚未满足《命令圣印》所需的第11点惩戒天赋。
- 用户升到25级后已用新增的第16个总天赋点学习1/1《命令圣印》，并确认《命令圣印》和《正义圣印》是两个不同技能。
- 当前日常练级已切换为常驻《命令圣印》；《正义圣印》仍可作为另一种圣印保留，但不再是默认练级圣印。
- 后续新号的低级练级天赋应修正：10—19级优先在惩戒系投入10点，20级立即点出1/1《命令圣印》，不要先绕去神圣系投入5/5《纯净圣印》。这样可把核心练级圣印提前5级获得。
- 《命令圣印》本身只有1点，不存在5/5；20级点出后，21—24级获得的4点应继续放在惩戒系。若只追求战斗输出，可优先投入《定罪》；若按整条任务路线优化总耗时，可优先考虑《正义追击》的移动速度。25级时才可把一个5级天赋从4/5补到5/5。
- 当前双手剑熟练度119/120，且使用任务蓝色双手剑，已经基本排除武器熟练度过低和武器品质不足。
- 朋友所说的“19级后单号秒怪”仍缺少一个关键定义：是单个技能秒杀，还是单号用《清算之手＋审判＋白字/驱邪术》在极短时间内杀死。若该经验来自2026年5月7日前，旧版《清算之手》伤害宏是最可能解释；当前纯惩戒已无法复现。
- 如果前两到三个审判已足够击杀，就不必让剩余角色继续对同一目标过量施法，可把后续审判留给下一只怪。
- 圣印是施加给圣骑士自身的持续增益；真正对敌人释放的是审判。用户把《正义圣印》当作自身Buff使用是正确的。
- 《清算之手》当前可用于无伤害拉怪和调整目标位置，不应再作为惩戒骑伤害技能计入循环。

## 2026-08-28 五开职责调整：1防骑 + 4惩戒

- 老手指出当前五开高难Boss失败的重要原因是队伍缺少真正承伤角色；用户据此决定五个圣骑士中固定转一个号为防护天赋，其余四个继续惩戒输出。后续五开高难任务、Boss与需要稳定聚怪/承伤的场景，默认按`1防骑 + 4惩戒`评估，不再按五惩戒硬扛作为标准战力。
- 当前角色已80级且身处达拉然时，可以只让选定的单号回旧世界找圣骑士训练师洗成防护天赋；其它四号无需一起回城。该号炉石仍可用于返回冰冠暗影拱顶，避免五号整体产生额外交通成本。
- 已经向职业训练师购买的普通圣骑士技能不会因为重置天赋而作废；洗点改变的是天赋配置及由天赋直接提供的能力。因此此前技能学习金币不视为损失，不因转防骑重复计算普通技能购买成本。
- 本条只冻结当前五开角色分工；防骑的具体天赋、雕文、装备和循环如后续需要，再单独按当前时光服版本核定，不在本次顺手扩展。

## 雕文与圣契固定方案 / 购买检查点

- 首组本轮实跑确认：20级和40级都没有去拍卖行补雕文，这是路线准备项遗漏，不应复制到后续新号。以后玩家路线必须把雕文作为显式装备检查节点，而不是只放在战斗备注里。
- 用户已冻结最终惩戒雕文方案：
  - **大雕文：**《复仇圣印雕文》＋《正义雕文》＋《审判雕文》。若满级/配装后面板精准已经达到26，则《复仇圣印雕文》可换《奉献雕文》或《驱邪雕文》。
  - **小雕文：**《力量祝福雕文》＋《感知亡灵雕文》＋《圣疗雕文》。明确**不要使用《智者雕文》**；其效果针对智慧圣印耗蓝，不是智慧审判。
  - **圣契：**《致命角斗士的坚韧圣契》，80级检查获取。
- 当前时光服版本特别说明：《正义雕文》不是旧资料里的《正义圣印雕文》/《正义防御雕文》，而是2026-05-07惩戒改版后取代《清算雕文》的新大雕文；效果为每层“正义”使伤害提高1%，最高5%。
- 雕文最低可用等级与槽位提醒按当前WLK规则记录：
  - **15级：**开启第1大＋第1小槽；《审判雕文》《力量祝福雕文》《圣疗雕文》已可用。新号此时至少买《审判雕文》；小雕文按练级需求先插《力量祝福》或《圣疗》。
  - **20级：**《感知亡灵雕文》可用；《奉献雕文》《驱邪雕文》也已可用，可作为练级/以后26精准后的替换候选。20级保留一次拍卖行检查。
  - **30级：**开启第2大雕文槽；如果还没到50级，第二大槽可先用练级临时雕文，50级再换最终核心。
  - **40级：**用户指定的第二次拍卖行补漏检查点；虽然最终方案没有新的核心雕文恰好在40解锁，但必须检查15/20级应买雕文是否漏买，并为50级节点提前准备。
  - **50级：**《复仇圣印雕文》可用，同时开启第2小雕文槽；到此至少应拥有两枚可用大雕文和两枚小雕文。
  - **70级：**开启第3小雕文槽；时光服新版《正义雕文》按当前实战资料在70级换上，此时三枚小雕文也可全部同时装备。
  - **80级：**开启第3大雕文槽，最终三大雕文可同时装备；同时检查《致命角斗士的坚韧圣契》。满级若精准已26，则把《复仇圣印雕文》替换为《奉献雕文》或《驱邪雕文》。
- 当前首组已经55级，并已在拍卖行提前买齐最终6种雕文：大雕文《复仇圣印雕文》《正义雕文》《审判雕文》，小雕文《力量祝福雕文》《感知亡灵雕文》《圣疗雕文》。用户明确决定**不额外购买《驱邪雕文》**：五开本身依靠多号同时释放技能，单个驱邪雕文的边际收益不足以覆盖额外花费；《奉献雕文》同样不提前买，后续只有在满级26精准替换方案实际需要时再处理。55级当前优先装备《审判雕文》；第二大槽只有在当前实际使用《复仇圣印》时才插《复仇圣印雕文》，否则可以暂空，等70级启用《正义雕文》。

## 30级后的技能宏与装备检查点

- 当前30级实测：30—31级虎崽、豹崽单号也能快速击杀；闪光平原的战斗迟缓主要来自目标等级、命中和任务掉落，不应归因于整套装备失效。
- 30—34级仍以《命令圣印》、审判、白字和可用的驱邪术为主。此阶段可使用`/startattack`与单技能宏，但不值得照搬包含十字军打击、神圣风暴的满级循环宏。
- 35—36级点满《战争艺术》后，当前时光服版本会使审判伤害提高25%；十字军打击和神圣风暴尚未取得时，直接收益主要体现在审判。
- 40级取得1/1《智者审判》后，连续拉怪的法力续航明显改善，属于稳定练级循环的第一个完整节点。
- 50级取得《十字军打击》后，常用输出宏开始真正有价值；当前首组目标已经改为80级，因此60级取得《神圣风暴》会成为必须复查的练级战斗节点，届时重新整理审判、十字军打击、神圣风暴、奉献和驱邪术的完整循环。
- 2026年5月7日调整后，纯惩戒路线的《清算之手》不能继续作为伤害技能；任何仍把它绑定进常用输出宏的旧攻略都应忽略。
- 练级到80期间仍不为整套副本毕业装专程停级。护甲优先使用任务奖励即时升级；蓝色力量/敏捷装备和明显提高双手武器伤害的任务奖励按老手规则提高优先级。
- 武器单独设两个检查点：35—38级、47—50级。若当前双手武器比角色低8级以上，或可稳定取得的新双手武器武器秒伤高15%以上，则允许安排一次短支线/购买；否则继续使用任务奖励。
- 50级前必须确保有一把接近当前等级的慢速双手武器，因为十字军打击按武器伤害结算。除武器外，不为命中装专门刷装备；优先通过不打高出3级以上的怪解决未命中问题。

## 25级洗点结果与后续顺序

- 首组五个角色已在幽暗城完成首次洗点，移除神圣系5/5《纯净圣印》。
- 当前25级16点统一结构：5/5《祈福》、2/2《强化审判》、3/3《十字军之心》、1/1《命令圣印》、2/2《正义追击》、3/5《定罪》。
- 五个号必须保持相同的2/2《正义追击》，避免主号移动更快导致跟随队形持续拉长。
- 后续优先顺序按当前希尔斯布莱德/敦霍尔德人形怪路线调整：
  - 26—28级：3/3《征伐》。对人形、亡灵、恶魔和元素等常见目标，每点收益高于单点《定罪》。
  - 29—30级：把《定罪》从3/5补到5/5。
  - 31—33级：3/3《双手武器专精》。
  - 34级：1/1《圣洁惩戒》。
  - 35—36级：2/2《战争艺术》。时光服已把该天赋对审判、十字军打击和神圣风暴的伤害加成提高到13/25%，到达层级后优先点满。
  - 37—39级：3/3《复仇》。
  - 40级：1/1《智者审判》；时光服该天赋已由3点压缩为1点，直接取得完整回蓝效果。
- 40级以后再根据时光服后续天赋树和实际五开战斗情况继续规划；不提前照搬旧版标准树的3点《智者审判》。

## 2026-08-09 老手升级情报：需要重新审计天赋与装备优先级

- 用户转述长期实跑老手明确区分“升级天赋”和“满级天赋”，并建议升级阶段把《偏斜》点满。该结论与当前纯输出导向天赋顺序存在冲突，因此从现在起不能把现有40级后的天赋顺序继续当作冻结答案；下一次规划50级后加点时必须把5/5《偏斜》作为高优先级候选重新比较。
- 老手明确建议优先打亡灵和人形怪。当前已知《征伐》本身就提高对人形、亡灵、恶魔、元素的伤害，因此路线候选同等条件下应把人形/亡灵高密度击杀块上调，而不是只按怪物等级和任务经验排序。
- 蓝色装备只要对当前角色有明确提升，相应任务优先级提高；尤其是力量、敏捷奖励，因为它们会提高后续连续练级的击杀速度，价值不能只算任务交付经验。
- 武器仍单独作为最高装备检查项之一。接近当前等级、明显提高武器伤害的蓝色双手武器，应允许为其保留低偏移支线。
- 上述内容目前属于“高优先级老手实战情报”，不是首组自己已经完成的天赋A/B实测。后续通过当前50级左右实战和下一组复跑验证后，再冻结最终升级天赋模板。
