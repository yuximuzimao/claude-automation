# 65—68 当前首组：泰罗卡过渡 → 纳格兰入口

状态：**当前首组已废弃/被67级萨布拉金位置修正替代。** 仅保留为“若未来赞加实际结束在东侧塞纳里奥”时的过渡候选；当前执行见`67-68-nagrand-sprint.md`。

前提：赞加已完成；当前实际停在赞加东侧塞纳里奥附近。当前跨图任务：9957、9796、9797、9795、9724均完成待交；9442已放弃。

## 1. 泰罗卡只吃顺路过渡包

从赞加塞纳里奥向南进入泰罗卡，不展开整图。

1. 塞纳里奥树林 `(44.33,26.31)`：T9957《塞纳里奥树林出事了？》。
2. 同地接并完成9968《奇怪的能量》 + 9971《树林中的线索》。
   - 9968目标就在树林周围：普通/邪恶巨蛾样本。
   - 9971调查物约 `(45.10,21.77)`。
3. 两个任务交完后做9978《不择手段》；Empoor约 `(41.67,26.17)`，仍属同一小区域。
4. 不继续把泰罗卡整图展开，转向裂石堡。
5. 裂石堡/Stonebreaker Hold `(49.71,43.33)`：T9796《赞加沼泽的来客》；自然开飞行点。

这一过渡包Questie基础任务经验：`2600 + 10400 + 10400 + 10400 + 2550 = 36350`；服务器双倍任务经验约`72700`，另有击杀经验。

## 2. 进入纳格兰

裂石堡后继续向西，不去刀锋山、不回地狱火。

进入纳格兰后：

- 优先自然经过奈辛瓦里狩猎队时接第一轮三条狩猎任务：9854《狩猎风鹏》、9857《狩猎塔布羊》、9789《狩猎裂蹄牛》。五开共享击杀非常适合这类纯击杀任务。
- 随后到加拉达尔 `(55.37,37.45)` T9797《支援加拉达尔》，打开加拉达尔任务中心并开飞行点。
- 之后纳格兰作为冲68主体，不为9795《食人魔的威胁》转去刀锋山，也不为9724《通知塞纳里奥议会》回地狱火。

## 4. 选择理由

按当前本地Questie筛选（required level <=65、quest level >=63、排除Repeatable/Daily/Raid）：

- 纳格兰：64个一次性候选，基础任务经验约736090；服务器双倍约1472180。
- 泰罗卡：70个一次性候选，基础任务经验约701670；服务器双倍约1403340，但当前等级下大量内容属于更早的63—65主段，且全清会拖离纳格兰主轴。
- 刀锋山：65个一次性候选，基础任务经验约631880；服务器双倍约1263760，同时地形/高差更不利于五开连续跑图。

因此当前最优策略不是泰罗卡全清，而是利用当前位置吃掉约72700双倍任务经验的本地过渡包，再把纳格兰作为冲68主体。
