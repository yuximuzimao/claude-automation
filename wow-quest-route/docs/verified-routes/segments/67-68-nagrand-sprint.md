# 67→68 纳格兰冲刺路线

状态：当前首组直接执行稿。

当前五号均67级，经验：`362075 / 333271 / 327654 / 324504 / 328566`。WotLK 67→68需要585000经验，因此剩余分别为：`222925 / 251729 / 257346 / 260496 / 256434`。最低号还差260496。

当前起点：赞加沼泽萨布拉金。

## 1. 地图选择结论

当前不再走泰罗卡短包，直接从萨布拉金沿9797《支援加拉达尔》描述的南路进入纳格兰。

原因：
- 泰罗卡短包9957→9968/9971→9978→9796约72700双倍任务经验，但9968是五开4+4样本任务，普通蛾样本公开掉率代理约35%、邪恶蛾约80%，实际服务时间和切号拾取成本不稳定；
- 纳格兰一进图，T9797 + T10114 + 奈辛瓦里第一轮三狩猎的双倍任务经验约74100，与泰罗卡整包几乎相同；
- 三狩猎全是共享击杀，按当前五开模型36只怪×15秒≈9分钟纯击杀，明显更适合五开；
- 使用3.3.5a WorldMapArea同一外域坐标系换算，`萨布拉金→加拉达尔`直线下界约1649码；`萨布拉金→塞纳里奥树林→裂石堡→加拉达尔`约7583码。绕泰罗卡至少多5934码，按16.8码/秒约多353秒（5分53秒）纯骑乘下界，尚未计任务服务与道路绕行；
- 从萨布拉金直接走南路本身就是9797的天然路线。

所以9957《塞纳里奥树林出事了？》、9796《赞加沼泽的来客》继续携带；当前不为它们转泰罗卡。

## 2. 首组实跑后的权威顺序

用户首组已经跑到68，实跑顺序优先于此前纸面稿：

1. 萨布拉金出发，走南路进入纳格兰，到加拉达尔交《支援加拉达尔》、开飞行点、炉石改绑加拉达尔。
2. 加拉达尔只接当前冲68真正需要的任务：
   - 《奈辛瓦里狩猎队》；
   - 《通缉：巫婆吉塞尔达》；
   - 《通缉：顾问佐尔布》。
   - **《证明你的力量》不接。** 首组确认对本次68冲刺没有价值，禁止再作为背景任务塞入。
3. 去奈辛瓦里狩猎队接三条第一轮狩猎任务。
4. 前往基尔索罗堡垒完成《通缉：巫婆吉塞尔达》。途中用户顺路遇到三人一组巡逻的暗血入侵者；击杀任意一只会掉任务起始物 `Murkblood Invasion Plans（暗血入侵计划）`，拾取后自动接《暗血入侵者》，回加拉达尔交给加尔鲁什。该三人组会在纳格兰巡逻，不按固定点等候；没遇到就继续吉塞尔达路线，不为触发物品任务专门绕路。
5. 吉塞尔达完成后**不炉石、不回营地**。继续往下方塔拉方向：
   - 先在塔拉附近完成第一轮《狩猎塔布羊》与《狩猎裂蹄牛》；
   - 再绕山去完成第一轮《狩猎风鹏》。
   这一顺序取代旧稿“先鸟→再羊牛→吉塞尔达→炉石”。用户实跑确认它减少折返。
6. 三狩猎第一轮与吉塞尔达全部完成后，炉石回加拉达尔集中交任务。
7. 再跑奈辛瓦里狩猎队交三狩猎、继续接可用后续。
8. 去战槌山完成《通缉：顾问佐尔布》，随后顺路完成第三轮风鹏首领裂肠者。
9. 跑回交任务后，首组达到68；本次纳格兰冲刺结束。

## 3. 关键实跑修正

- **路线顺序**：吉塞尔达 → 塔拉羊/牛 → 绕山杀鸟 → 炉石加拉达尔 → 奈辛瓦里交付，比旧稿更顺。
- **《证明你的力量》**：永久从当前67→68冲刺线删除。
- **物品起始任务**：《暗血入侵者》由三人巡逻组“暗血入侵者”掉 `Murkblood Invasion Plans（暗血入侵计划）`触发；首组自然遇到并完成，后续仍只顺路处理，不为巡逻组专程搜索。完整地图扫描见下节。
- **68兜底**：首组实际用了《通缉：顾问佐尔布》+裂肠者即到68；不需要继续做巴克洛尔/班塔尔。
- **68转场实跑捷径**：沙塔斯对当前角色敌对时，不走正常城市服务。首组从纳格兰直接冲入沙塔斯，在城内死亡后复活/灵魂跑到传送门，成功直接传送奥格瑞玛。该路线已实测可用，可作为下一批“纳格兰→奥格→诺森德”的优先转场候选。

## 4. 怪物掉落物触发任务完整扫描

按当前Questie任务池对纳格兰全图反向扫描，部落可用的此类任务共有2条：

- 9861《呼嚎之风》：当前67→68冲刺线未采用。任务起始物 Howling Wind 可由灰尘咆哮者、风暴狂怒者、活体飓风掉落；这些是纳格兰普通空气元素，没有事件触发条件。当前路线不为这件随机掉落物专门刷；若后续做完整纳格兰路线时自然掉出，再按元素王座交付方向评估是否保留。
- 9872《暗血入侵者》：首组实跑已自然触发并保留。来源是三人一组巡逻的暗血入侵者；击杀任意一只掉 `Murkblood Invasion Plans（暗血入侵计划）`，拾取自动接任务，回加拉达尔交给加尔鲁什。特殊点是来源怪为游走巡逻组而非固定任务点，因此只在自然遇到时处理，不等、不追巡逻路线。

本节只负责保证纳格兰地图内的怪掉物触发任务不再遗漏；9861不会仅因为本次扫描自动插回67→68冲刺线。

## 6. XP截止说明

WotLK任务经验规则按项目长期口径：`Character Level <= Quest Level + 5`时拿满任务经验。因此任务等级62在角色67级时仍是100%；68级开始变为80%。这也是当前不应把62级已完成任务无限后拖的原因，但从萨布拉金出发，转泰罗卡的额外路线与9968五开掉落服务仍使其输给直接纳格兰的共享击杀路线。
