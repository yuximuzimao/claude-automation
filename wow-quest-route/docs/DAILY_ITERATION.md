# 每日路线复盘工作流

## 目标

先用Questie生成各区域候选路线，再按空间和任务链拆成小区块。玩家每次只执行当前区块；当天结束后导出人物历程或WoW Route Logger日志，比较候选路线与实际行为，并把经验同步到后续区域。

## 数据完整度

### Questie人物历程能记录
- 任务接取、交付/完成、放弃；
- 升级；
- 时间戳和事件发生时的等级。

### Questie人物历程不能记录
- 移动轨迹和事件坐标；
- 目标何时完成；
- 打怪、拾取、点击的过程；
- 五个角色各自进度；
- 跟随断开、地形绕路和楼层。

### WoW Route Logger补充
- 每角色独立保存，不使用Questie账号级共享数据；
- 接任务、目标完成、交任务、升级时的地图与坐标；
- 移动时按阈值采样实际轨迹；
- `/wrl note 文本`可手工记录异常；
- 不发送按键、不控制角色、不修改任务，只记录本地事件。

## 每日操作

1. 使用HTML只查看当前小区块。
2. 正常游戏；异常时可输入：`/wrl note 山猫尸体2号没有项圈`。
3. 当天结束后完全退出五个游戏客户端，或各自输入`/reload`。
4. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Export-WoWRouteLog.ps1 `
  -BridgePath "你的bridge目录"
```

5. 把生成的`wow-route-log-YYYYMMDD-HHMMSS.zip`交给ChatGPT。

导出脚本会匿名重命名角色文件，不把账号、服务器和角色目录名写入ZIP。

## 路线迭代层级

1. **全局候选层**：按Questie任务依赖、阵营/种族/职业、接交点和目标坐标生成。
2. **区域层**：一个游戏区域生成一份HTML。
3. **小区块层**：按任务中心、前置批次和空间簇划分，每次只执行一个区块。
4. **实测层**：用轨迹、事件时间、个人拾取和地形反馈修正。
5. **迁移层**：已确认的通用规则（击杀共享、个人掉落、建筑楼层等）自动应用到后续区域。

## 优化证据优先级

1. 任务依赖和固定NPC/物体：Questie数据库。
2. 实际接交顺序和等级：Questie人物历程/Route Logger事件。
3. 实际移动路线：Route Logger path。
4. 五开共享、个人拾取和楼层：用户实测与手工备注。

不要只根据一次人物历程推断道路；也不要只根据静态坐标推断最优路线。
