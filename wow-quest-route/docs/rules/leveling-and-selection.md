# 练级预算与任务取舍规则

用途：做经验预算、地图轴选择、任务保留/跳过、随机掉落/护送/固定拾取价值判断时读取。玩家文案格式和特殊任务操作见 `execution-and-mechanics.md`。

## 1. 五开计算基准

- 等级、经验、补经验需求和离图判断以五个角色中**等级/经验最低的角色**为唯一保证基准。
- 每个任务块开始/结束记录最低号等级、当前经验、本级总经验、位置和关键任务；有可靠墙钟才计算经验/小时。
- 用户新回报的等级/经验立即覆盖旧预测，不允许为了维持旧模型继续使用旧起点。
- 理论任务经验必须使用当前服务器已验证倍率/规则校准；具体倍率属于服务器阶段事实，从CURRENT、observations或当前版本证据读取，不在永久规则里硬编码。休息经验等额外个人加成不能写进保证预算。
- 五号交付后必须逐号确认任务从日志消失。单号经验异常先排查漏交，不先推断路线漏任务。

## 2. 经验预算必须分账

每段至少拆成：

1. **精确任务经验**：确定会完成并交付的任务。
2. **强制击杀保守经验**：任务明确要求的必要击杀，只作安全余量。
3. **零预算经验**：沿途怪、探索、竞争补杀、随机掉落额外补刷、异常刷新等保证账一律按0。

离图等级先用精确任务经验判断；不能用“正常会顺便打怪升级”填任务奖励缺口。

### 下界账与上界账

需要同时验证：

- **下界账**：最低号一定能获得多少经验，证明任务经验够不够。
- **上界账**：最快/最高号可能提前获得多少经验，证明后续低级任务不会因等级过高而衰减。

WotLK一次性任务完整经验截止按 `last_full_xp_level = quest_level + 5`。必须按**预计实际交任务等级**检查，而不是接取等级或任务等级。若后面低级链会越线，优先调整同图交付顺序，再考虑跨图穿插。

“仍给完整经验”不等于“值得做”。最终仍比较真实剩余墙钟。

## 3. 五开任务成本不能二元化

每个任务至少评估：

- 实际交付等级下的任务经验；
- 后续任务链价值；
- 强制怪数量与目标等级；
- 跑路、回头、交通切换；
- 是否共享击杀；
- 每号物品数量与掉率方差；
- 同尸体是否可多人分别拾取；
- 固定物体是否共享/个人；
- 刷新密度、命名怪搜索、洞穴、护送、载具、断跟随和失败重跑风险。

主号本来承担普通战斗和路线移动，不能把“主号要操作”统一当五开惩罚。真正需要加权的是逐号切换、逐号定位、断跟随、等待和失败重跑。

## 4. 固定物体、护送与随机掉落必须分开评价

### 固定拾取/固定交互

地面采集、固定容器、固定场景物没有怪物掉率长尾。只按逐号操作量、刷新周期、竞争、点位密度和路线偏移评估，不能因为“个人采集”就整类降权。

### 护送

护送不得按类型自动排除。与主路线重合、沿途本来要清怪、一次可让五号完成时可保留；真正的负担是启动等待、断跟随、失败重跑和明显绕路。

### 随机怪物掉落

从零设计时随机掉落默认低于共享高密度击杀和固定交互，但不是自动删除。

准备纳入主线时必须：

- 检查 Questie/数据库参考概率；
- 对高风险任务查公开 Classic/WotLK 社区实跑反馈；
- 优先使用当前服务器实测；
- 先确认是否存在高密度刷点，再评价掉率；不能用散点慢刷的学习成本直接证明任务本身低效。

明显低掉率且无高价值后续链的任务直接跳过；与主体击杀高度重叠、低数量、高掉率或后续链价值高的任务按剩余边际成本判断。

普通自由拾取不能套一条统一机制。是否“五号总需求累计”“同尸五号分别可取”“Party Loot”“个人独立掉落”以逐任务实测为准。误转团队会阻断普通任务物掉落，任务块开始前确认仍为普通五人小队。

## 5. 路线优化先地图轴、再地图内任务

### 地图轴

1. 优先连续完成当前地图/任务中心，减少飞艇、跨大陆、长飞行和回城。
2. 只有下一张地图整块墙钟明显更高效，或当前地图出现明确等级/任务断层，才提前转图。
3. 老手口述“某地图到X级”先视为连续阶段检查点，必须用本图可执行经验核验；任务自然清空仍不到口述等级时，进入下一任务中心，不在空地图无任务刷怪。
4. 新号优先对照 `docs/verified-routes/VETERAN-LEVELING-BACKBONE.md`，不复制首组早期因逐任务拼接造成的地图振荡。

### 地图内默认优先级

1. 共享刷怪 / 高密度击杀；
2. 固定拾取 / 固定场景物 / 可预测交互；
3. 与主路重合的护送；
4. 需要额外补刷的随机掉落。

随后再比较预计交付等级、真实路线、链价值和风险。类型只是先验，不是最终结论。

## 6. 任务中心与同目标区聚合

- 第一次到任务中心先扫描当前可接的一次性任务；交任务后再次扫描刚解锁的后续。
- 去刷怪区、洞穴、据点或固定物区域前，把当前可接且目标落在同一区域的任务尽量聚齐，避免同一地点二次返工。
- 日志容量不足时，优先当前目标区重叠、低等级截止链和结构性前置；远期引导、副本、PvP、可重复或明显不在本轮目标区的任务延后。
- 阶段终点必须复算下一地图进入条件、逐项归类当前日志任务、给所有延后任务明确回访点。

## 7. 已接任务使用剩余边际成本，不重算沉没成本

已接、已解锁、已拿到稀有触发物的任务，其前置/接取/触发物获取成本已经发生。后续只比较从当前状态开始的剩余成本。

同图多个已接任务按“任务包”计算，共享骑行、公共回城、重叠击杀不能给每个任务重复计费。

准备放弃已接任务前必须做**反向替代测试**：保持其它路线不变，明确删掉这些经验后，后面要新增哪些具体任务才能到同一里程碑，并比较新增墙钟。不能证明替代更便宜就不删。

前段多获得高效经验时，应从尚未开始的后半程任务中优先删边际成本最高的任务包，而不是只把经验余量越堆越大。

## 8. 阶段实验不进入永久规则

诸如“某一批新号减少哪类任务”“实验到几级停止”“当前批次经济权重”等，只保留在 `CURRENT.md`、`tasks/todo.md`、对应VETERAN/NEAT文档中。永久规则只保存实验验证后仍能跨批次成立的方法；不得把阶段实验本身写成长期硬规则。
