# docs/rules 目录

用途：说明这个文件夹里有哪些长期规则文件。这里只是目录，不判断当前任务属于哪一类，也不维护另一套执行流程；业务分类先走`../verified-routes/ROUTE-DESIGN-PROCESS.md`。

| `execution-and-mechanics.md` | 任务机制核验、证据优先级、五开事实 |
| `leveling-and-selection.md` | 任务删留 / now-later-never 决策 |
| `xp-model.md` | XP模型与XP派生操作 |
| `timing-and-benchmarking.md` | Timing模型、样本与Timing派生操作 |
| `economy-model.md` | Economy模型、样本与Economy派生操作 |
| `route-profile-and-lifecycle.md` | Route Profile / Program / CURRENT / Generated Product及生命周期传播 |
| `route-atlas-optimization.md` | 路线排序、空间/交通/服务优化 |
| `route-atlas-player-contract.md` | Route Atlas玩家前端共同目标与三个前端owner边界 |
| `route-atlas-route-display.md` | Profile原子到地点/NPC/接做交/步骤展示 |
| `route-atlas-task-presentation.md` | 任务标签、备注与玩家必要信息 |
| `route-atlas-ui-and-assets.md` | HTML容器、地图、控件、CSS、动画、离线资源与渲染 |
| `route-lifecycle-final-audit.md` | 最终机械审计、玩家冷读、项目cutover |

Task Card字段定义位于`../task-library/README.md`，不属于本目录。当前状态、Todo、测试、脚本和历史分别从`../INDEX.md`导航。
