## 估时器全局缺陷与修正

### 根因

`objective_names_for_group()`原逻辑先从动作句中移除`《任务名》`，再搜索任务执行token；因此最常见的`做《任务名》`会在移除标题后只剩“做”，而token表中原本依赖`做《`，导致整项任务的`T_objective_service`被漏掉。龙骨步骤11因此曾被错误估成4分钟，`objectiveMinutes=0`。

### 修正

- 在移除任务标题前识别`做《`这一显式任务执行语义；显式`做《任务》`现在必须进入该step的`objectiveTasks`。
- 给12046《柔软的包装》加入25分钟首组实测服务时间覆盖。
- 新增回归测试：北风/龙骨/灰熊/祖达克所有玩家动作中的显式`做《...》`，只要任务属于当前foundation，必须被估时器识别；漏一项即失败。
- `沿路/自然/顺手`的背景任务没有被机械按整项任务服务时间重复加收，因为这些任务常与前台目标共享击杀/移动；重叠成本仍按实际任务包建模，避免另一方向的重复计费。
