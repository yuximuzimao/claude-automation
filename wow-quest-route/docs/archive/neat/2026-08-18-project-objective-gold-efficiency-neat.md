# 2026-08-18 项目唯一目标归一：打金效率 NEAT

## 本轮结论

项目唯一第一目标固定为：**用尽可能少的玩家真实墙钟，获得尽可能高、可持续、可重复的净金币产出。**

升级、任务路线、任务剔除、装备选择、任务卡、Route Atlas、视频拆解和自动化都只是实现工具，没有独立优先级。

“最低脑力可重复、低失败率、低随机长尾、高复用性”不是第二目标，而是让纸面金币/小时能够长期兑现的执行条件；能折算为墙钟/重跑的直接计成本，难可靠量化但明显影响复用的作为硬约束或同收益方案的排序条件。

## 被本轮上位目标覆盖的旧口径

1. **“68级以前可删、68级以后诺森德全清”作废。**
   - 诺森德练级阶段的任务金币/装备变现、80级后同一批一次性任务的XP折金，都属于**任务路线打金这一种方式自身的收益**。
   - 练级经验只作为这套任务路径内部的状态变量：影响后续任务可接性、80级时点和XP折金时点；不得换算成“更早去做团本/日常”的机会收益。
   - 所有等级段统一回到这一整组号任务周期的总金币、总墙钟和金币/小时比较。

2. **“老手68→80约14小时是最终长期优化目标”作废。**
   - 14小时只保留为纯升级速度参考，证明路线墙钟还有多少压缩空间。
   - 它不能单独决定任务删留，也不能覆盖金币/小时更高但升级略慢的方案。

3. **“11591《钢腭的车队》是诺森德唯一允许跳过的权限例外”作废。**
   - 正确表述只是任务事实：11591是可选面包屑，11592/11593/11594可直接接做，之后11591会失去可接资格。
   - 当前基线路线不做11591，但这是具体机制与边际价值判断，不是全局例外权限体系。

4. P1—P4/A—C不再拥有任何等级段的自动删除权。
   - 只作为潜在高操作成本任务的候选召回标签。
   - 正式删/留必须重新做经济边际比较。

## 统一任务决策模型

以后每个任务/任务包至少比较三种动作：

- `现在做`
- `以后做（例如80级后清）`
- `永久不做`

至少核算：

- 当前直接金币；
- 装备/物品变现；
- 80级XP折金；
- 当前任务经验带来的升级时间价值；
- 后续任务链、交通、技能、区域或打金能力解锁；
- 当前/未来回图、移动、Hub接交、等待、五开操作与失败重跑；
- 脑力占用和稳定复用风险。

任务卡的`80级XP折金`继续固定保存，但只作为收益组件，不是保留条件。

## 打金方式边界

当前至少区分三种可以并行存在的打金方式：

1. **任务路线打金**：练一整组号 + 完成定义范围内的一次性任务；统计该周期总墙钟与总金币。
2. **团本打金**：另建独立周期与金币/墙钟模型。
3. **日常打金**：另建独立周期与金币/墙钟模型。

三种方式以后可以在更上层组合，但内部评估必须先各自闭合。当前任务路线项目**不得**用团本/日常的G/小时作为单任务删留的机会成本。

任务路线打金内部，任何删留试验至少输出：

1. 现在做 / 80级后做 / 永久不做分别需要多少clean墙钟；
2. 各自能兑现多少直接金币、装备/物品价值和80级XP折金；
3. 对后续一次性任务可达性、等级门槛和回访成本的影响；
4. 最终对这一整组号任务周期的**总金币、总墙钟、金币/小时**的影响。

不需要等待80后其它打金方式的G/小时，才能判断任务路线本身。
