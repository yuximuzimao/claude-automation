# 纳格兰 · 67→68五开冲刺路线

适用于67级新号；最低号到68即结束。

炉石：加拉达尔

## 步骤 1｜加拉达尔 → 奈辛瓦里狩猎队
从赞加南路进入加拉达尔，交任务、开飞行点并绑定炉石；接完本地任务后去奈辛瓦里接三条狩猎任务。
- 加拉达尔
- 克洛坎上尉 → 交【待实测】《支援加拉达尔》
- 开飞行点：加拉达尔
- 绑定炉石：加拉达尔
- 加拉达尔
- 欧洛恩·远行者 → 接【待实测】《奈辛瓦里狩猎队》
- 加拉达尔布告牌 → 接【待实测】《通缉：巫婆吉塞尔达》
- 加拉达尔布告牌 → 接【待实测】《通缉：顾问佐尔布》
- 奈辛瓦里狩猎队
- "好儿子"沙度·远行者 → 交【待实测】《奈辛瓦里狩猎队》 → 接【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 接【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 接【待实测】《狩猎裂蹄牛》

## 步骤 2｜基尔索罗 → 塔拉羊牛 → 绕山风鹏 → 加拉达尔 → 奈辛瓦里
先完成《通缉：巫婆吉塞尔达》，继续到塔拉附近完成塔布羊和裂蹄牛，再绕山完成风鹏；三狩猎和吉塞尔达都完成后炉石回加拉达尔集中交付，再去奈辛瓦里接后续。
- 基尔索罗堡垒 / 吉塞尔达
- ↳ 做【待实测】《通缉：巫婆吉塞尔达》
- 塔拉附近塔布羊 / 裂蹄牛走廊
- ↳ 做【待实测】《狩猎塔布羊》、【待实测】《狩猎裂蹄牛》
- 绕山风鹏刷新带
- ↳ 做【待实测】《狩猎风鹏》
- 使用炉石：加拉达尔
- 加拉达尔
- 监护者布罗克 → 交【待实测】《通缉：巫婆吉塞尔达》
- 奈辛瓦里狩猎队
- "好儿子"沙度·远行者 → 交【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 交【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 交【待实测】《狩猎裂蹄牛》
- "好儿子"沙度·远行者 → 接【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 接【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 接【待实测】《狩猎裂蹄牛》
备注：
- 《狩猎塔布羊》：《狩猎裂蹄牛》：沿同一条南向走廊同时完成。
《狩猎风鹏》本任务《狩猎裂蹄牛》：共享：
- 《狩猎裂蹄牛》：《狩猎塔布羊》本任务：沿同一条南向走廊同时完成。
《狩猎风鹏》《狩猎塔布羊》本任务：共享：
- 《狩猎风鹏》：塔拉羊牛完成后再绕山去东部/中东部密集刷新带，不单独折返。
《狩猎塔布羊》《狩猎裂蹄牛》：共享：

## 步骤 3｜西部风鹏 → 中部草原 → 奈辛瓦里
完成饥饿的风鹏及后续塔布羊、裂蹄牛目标，回奈辛瓦里交任务后立即检查最低号经验；到68直接结束。
- 西部风鹏刷新带
- ↳ 做【待实测】《狩猎风鹏》
- 中部草原
- ↳ 做【待实测】《狩猎塔布羊》、【待实测】《狩猎裂蹄牛》
- 奈辛瓦里狩猎队
- "好儿子"沙度·远行者 → 交【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 交【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 交【待实测】《狩猎裂蹄牛》
- "好儿子"沙度·远行者 → 接【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 接【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 接【待实测】《狩猎裂蹄牛》
备注：
- 《狩猎风鹏》：饥饿的风鹏主要向西侧移动完成。
- 《狩猎塔布羊》：《狩猎裂蹄牛》：沿中部路径边走边杀，不必围着单一坐标刷。
- 《狩猎裂蹄牛》：《狩猎塔布羊》本任务：沿中部路径边走边杀，不必围着单一坐标刷。

## 步骤 4｜【最低号未到68】战槌山 → 奈辛瓦里高级狩猎
仅最低号仍未到68时继续：先做《通缉：顾问佐尔布》，仍不足再做奈辛瓦里高级狩猎；每次交任务后都检查最低号，到68立即结束。
- 【最低号未到68】战槌山 / 顾问佐尔布
- ↳ 做【待实测】《通缉：顾问佐尔布》
- 【最低号未到68】加拉达尔
- 监护者布罗克 → 交【待实测】《通缉：顾问佐尔布》
- 【最低号未到68】奈辛瓦里高级狩猎
- ↳ 做【待实测】《狩猎塔布羊》、【待实测】《狩猎裂蹄牛》、【待实测】《狩猎风鹏》
- 哈罗德·兰恩 → 交【待实测】《狩猎塔布羊》
- 赫米特·奈辛瓦里 → 交【待实测】《狩猎裂蹄牛》
- "好儿子"沙度·远行者 → 交【待实测】《狩猎风鹏》
- 赫米特·奈辛瓦里 → 接【待实测】《终极挑战》
- ↳ 做【待实测】《终极挑战》
- 赫米特·奈辛瓦里 → 交【待实测】《终极挑战》
备注：
- 《通缉：顾问佐尔布》：击杀顾问佐尔布、5名战槌萨满祭司和5名战槌劫掠者。
- 《终极挑战》：只在三条高级狩猎全部交完仍未68时启用；击杀塔丝克后，确认每个仍需要任务物的角色都取得塔丝克之心再离开。

最低号到68后立即结束，不再执行第4步。
