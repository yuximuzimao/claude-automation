2026-08-04五开实跑确认：乌龟、食腐鹫和蝎子各自都有一个明显的集中分布区。此前给出的“沿赛车场外围逆时针绕完整盐湖”会在目标稀疏区浪费大量移动时间，现已废弃。

- 仍未到34级时，在乱风岗山柱顶部附近找峭壁卫兵图林·长角45.67,50.74，接《兄弟》（5361）。

## 五、阶段D：34级盐鳞鱼人＋荒芜之地，34→35前段

### 乱风岗 → 奥格瑞玛 → 格罗姆高 → 奈辛瓦里营地

从乱风岗飞往奥格瑞玛。到奥格瑞玛后前往城外飞艇塔，乘明确前往格罗姆高的飞艇。

- 确认《猎龙》（195）仍保留；若之前误放弃，现在从赫米特·奈辛瓦里重新接取。
- 《猎豹》（192）和《荆棘谷的青山》（338）继续不做。

最低角色未达到34级时不得执行下面的老虎、迅猛龙和鱼人战斗；先返回阶段C补足。

### 奈辛瓦里西北回访环：完成《猎虎》（187）和重试《猎龙》（195）

从营地向西北到31—36,16—20一带，先完成第三段《猎虎》（187）需要的老年荆棘谷猛虎。该任务以共享击杀为主，先确认五号进度同步；若有角色没有同步，不要拉散队伍分别打。

- 最低34级时与35—36级目标只差1—2级，先单拉一只测试命中率。
- 连续两只仍出现大量未命中、单怪耗时明显高于同级普通怪时，立即停止《猎龙》（195），保留到35级后，不把它当作本路线硬门槛。
- 命中率正常时完成10只，不追入多怪密集区域。

完成《猎虎》（187）后回奈辛瓦里营地交付，并接下一段《猎虎》（188）。《猎虎》（188）的辛达尔位于约32.2,17.4，只有在以下条件同时满足时顺手完成：

- 第一轮击杀能让五号同步完成任务或同一尸体可供五号完成所需拾取。

任一条件不满足就停止《猎虎》（188），不计入本路线保证经验。

若《猎龙》（195）完成，回营地交付；**不要接下一段《猎龙》（196）**，其目标更靠南且等级更高，不属于本轮西北海岸任务块。

预计耗时：20—40分钟；《猎龙》（195）或辛达尔触发止损时会更短。

### 奈辛瓦里营地 → 荆棘谷西北海岸：完成《坚硬的尾鳍》（1107）

从营地沿北部主路向西北海岸移动，到纳菲瑞提湖以北一带后，从主路向西转向海岸，目标区域在23—27,22—25。盐鳞鱼人分布在水边营地和浅滩附近。

- 35—36级盐鳞战士。
- 35—36级盐鳞强盗。
- 35—36级盐鳞猎人。

尽量少打36—37级盐鳞智者，不主动打37级盐鳞首领。鱼人会逃跑并引到邻近怪物，每次只拉1—2只；准备击杀前先观察目标背后的怪群，不要追进营地深处。

按五号缺口分配尸体。已经完成10个尾鳍的角色可以拉远，优先让最低经验且缺尾鳍的角色留在拾取范围。

完成后沿来路向东返回主路，再向南回格罗姆高。《坚硬的尾鳍》（1107）先保留，最后回赛车场交。

预计耗时：35—70分钟。

### 格罗姆高 → 幽暗城 → 塔伦米尔

在格罗姆高飞艇塔选择前往提瑞斯法林地/幽暗城的航线。如果当前平台只前往奥格瑞玛，就先到奥格瑞玛，再换乘幽暗城方向飞艇。

进入幽暗城后使用西南侧已开启的飞行点，飞往塔伦米尔。塔伦米尔落地后补充食物、饮水并修理装备；从这里开始是长距离首次开点路线。

预计耗时：20—35分钟，取决于飞艇等待。

### 塔伦米尔 → 首次开启落锤镇

从塔伦米尔东侧离开，沿希尔斯布莱德主路一直向东。道路会经过敦霍尔德附近并穿过地图东口，进入阿拉希高地西部。

从落锤镇西门进入后向营地北侧高台走，飞行管理员尤尔达位于约73.06,32.68。五个角色分别与尤尔达对话，确认首次开启落锤镇飞行点。

预计耗时：20—35分钟。

### 落锤镇 → 萨多尔大桥 → 湿地

开点后从落锤镇西门离开，沿来路向西返回阿拉希中部。到主路大岔口后转向南，沿道路前往地图最南端的萨多尔大桥。

途中会经过联盟据点附近。不要进入避难谷地或激流堡，不要攻击道路旁的联盟NPC；贴主路外侧通过。

萨多尔大桥是一座跨海峡的大型石桥，位于阿拉希南端。沿桥一直向南，经过断桥和连接段后进入湿地北部。

进入湿地后继续沿主路向南。到湿地中部的大岔口时，选择通往东南山区和丹奥加兹的道路，不要向西前往米奈希尔港。

预计耗时：20—30分钟。

### 湿地 → 丹奥加兹 → 洛克莫丹

沿东南道路进入丹奥加兹山口。这里由多层隧道、坡道和石门组成，五号最容易掉队。

通过方式：

- 主号每穿过一段隧道就在下一处开阔平台停一次。
- 确认四个跟随号全部到齐后再继续下坡。
- 不追道路两侧的怪，也不要进入矮人建筑内部。
- 若联盟守卫短暂攻击，以通过山口为目标，不停下扩大交战。

一路向下穿过丹奥加兹后进入洛克莫丹北部。

进入洛克莫丹后沿东侧主路向南。不要进入塞尔萨玛镇中心；保持在城镇东侧道路继续南下。到地图南部山区时，沿通往荒芜之地的山口道路离开洛克莫丹。

预计耗时：20—35分钟。

### 进入荒芜之地 → 首次开启卡加斯

从洛克莫丹南口进入荒芜之地时，位置在地图北部。先不要直接去流放者马特克，因为后续必须依靠卡加斯飞行点离开。

进入荒芜之地后向西移动，尽量沿北部山脚和开阔地带前进；之后转向西南，目标是地图最西侧约4,45的卡加斯。卡加斯是一座靠山而建、有兽人守卫和部落旗帜的营地。

从营地东侧入口进入，飞行管理员格里克位于营地内部靠北/东北侧，坐标约3.99,44.78。五个角色分别对话，确认首次开启卡加斯飞行点。

卡加斯开点后再离开营地向东，沿荒芜之地中央道路前往流放者马特克42.22,52.69：

- 交《流放者马特克》（1106）。
- 接《精铁碎片》（1108）。

预计耗时：30—50分钟。

### 流放者马特克 → 北部石窟穴居人区：收集精铁碎片

从流放者马特克的位置向北偏西骑，前往约35,23的北部岩石盆地和洞穴区域。

完成《精铁碎片》（1108），五号各取得10片精铁碎片。优先击杀：

- 35—36级石窟穴居人。
- 36—37级石窟斥候。

只在北部低等级区域循环。不要向东去64,42附近打37—38级石窟先知，也不要向南进入39—41级穴居人区域。

穴居人的掉落属于五号个人收集。保持怪物等级和拉怪量稳定，一次清1—2只；如果洞口内部怪物过密，就在外部刷新区循环，不强行深入洞穴。

五号全部取得10片后，原路返回流放者马特克42.22,52.69：

- 交《精铁碎片》（1108）。
- 接《回复菲兹尔》（1137）。

预计耗时：40—80分钟。

### 卡加斯 → 格罗姆高 → 奥格瑞玛 → 乱风岗：使用新航线返程

从流放者马特克向西返回卡加斯。使用刚开启的卡加斯飞行点直接飞往格罗姆高；若航线界面显示中转，保持乘坐即可，不需要中途下机。

这段禁止按原路徒步返回洛克莫丹、湿地和阿拉希；卡加斯飞行点的目的就是结束长途陆路。

预计耗时：25—45分钟。

### 赛车场集中交付：尾鳍、精铁碎片和瑞兹尔计划

在赛车场先完成两项直接交付：

- 维兹尔·铜栓78.14,77.12交《坚硬的尾鳍》（1107）。
- 菲兹尔·铜栓78.06,77.13交《回复菲兹尔》（1137）。

然后找普兹克80.18,75.88接《跟上节奏》（1190）。

《跟上节奏》（1190）的操作顺序：

- 找赛车场内的扎米克79.81,77.03，与他交谈并让他制造骚乱。
- 等附近地精被骚乱吸引离开后，向西走到77.21,77.39，寻找“瑞兹尔无人看守的计划”。
- 五个角色分别点击计划物体，交《跟上节奏》（1190），并从同一物体接《瑞兹尔的图表》（1194）。
- 如果计划在角色切换之间消失，就等待骚乱结束后重新与扎米克交谈，不要在营地里乱点其他物体。

五号都接到《瑞兹尔的图表》（1194）后，回普兹克80.18,75.88交任务。

交付完成后检查最低角色等级和任务日志：

- 最低角色已经35级、任务日志不超过21格，并且当前就在赛车场时，到克拉维尔·浓须77.79,77.27接《返回藏宝海湾》（1118），作为35级后续交接；本路线不继续执行1119—1122。

阶段D原计划固定任务奖励约31080，另外包含尾鳍和精铁碎片的大量必需击杀经验。《猎虎》（187）、《猎龙》（195）和可选《猎虎》（188）的奖励全部为额外经验，不计入该数字和35级保证预算。

### 阶段D等级检查

完成全部交付后检查最低角色：

- 仍为34级但距离35级很近：先完成尚未完成的《虫群的样本》（1148）、《虫群的消息》（1184）或最后一个角色的《火箭车零件》（1110）；不要为了少量经验直接进副本。

## 六、阶段E：血色图书馆固定经验兜底，确保35

### 本阶段路线总览

**乱风岗/奥格瑞玛 → 幽暗城 → 提瑞斯法林地东北部血色修道院 → 图书馆最右侧入口 → 只清到《亡灵威胁的起源》任务书 → 幽暗城 → 奥格瑞玛 → 乱风岗 → 多恩·平原行者。**

只有阶段D完成后最低角色仍未达到35级，才执行阶段E。任务日志中必须已经有《知识试炼》（1160）。

预计总耗时：约1—2小时，主要取决于五号在图书馆精英怪群中的稳定性。

### 乱风岗 → 奥格瑞玛 → 幽暗城

从乱风岗飞往奥格瑞玛。到奥格瑞玛后前往城外飞艇塔，乘明确前往提瑞斯法林地/幽暗城方向的飞艇。

抵达洛丹伦废墟后，先不要进入幽暗城交任务；《知识试炼》（1160）的任务书还没有取得。整理背包、修理装备并确认五个角色都在同一队伍后，直接从废墟北侧离开，前往血色修道院。

### 洛丹伦废墟 → 血色修道院：新手陆路指引

从洛丹伦废墟向北到布瑞尔附近，接上提瑞斯法林地的主路。沿道路总体向东再向东北走，目标是地图东北角约83,32的血色修道院。

途中判断方向：

- 不向西走银松森林方向。
- 不走东南通往西瘟疫之地壁垒的道路。
- 始终选择通往地图东北山地和血色十字军建筑群的道路。

接近目的地后会看到白色石墙、塔楼和大量血色十字军。沿道路上坡，穿过外部拱门进入血色修道院中央露天大厅。

到达大厅后先把五个角色集中在入口内侧安全位置，不要直接分别冲向不同副本门。

预计耗时：15—25分钟。

### 识别图书馆入口：进入大厅后的最右侧传送门

血色修道院中央大厅通向四个不同副本。以“刚从外面进入大厅、面朝大厅内部”为方向基准：

- 最左侧是墓地。
- 中间两侧是后续高等级区域。
- **最右侧的副本传送门是图书馆。**

本路线进入最右侧传送门。图书馆不需要先获得血色十字军钥匙。五号全部进入后，确认副本名称显示为“血色修道院：图书馆”；发现进入其他区域就立即退出，不在错误副本里清怪。

### 图书馆内路线：只清到任务书，不打奥法师杜安

进入图书馆后采用五号正常小队打法，不尝试单号潜入：

- 主号在前，一次只拉一组精英。
- 四个跟随号保持在主号身后，不站在下一组怪的巡逻线上。
- 优先打断施法怪。
- 优先击杀会低血量逃跑的怪，防止其引来下一组。
- 每清完一组停一下，确认五号血量、法力和跟随状态。

路线总体是线性的：

1. 清过入口走廊和前部房间。
2. 到达中间开放庭院时继续走正对面的主路线，不向右进入驯犬者洛克希的支路。
3. 继续清过后续走廊，进入陈列书籍和展品的“珍宝陈列室”区域。
4. 沿走廊向北前进时，注意左手边连续出现的小房间。
5. 《亡灵威胁的起源》位于左手边第一个、也就是最南侧的小房间内，书本摊开在桌上。

到书本房间后先清干净门口和房内会干扰交互的怪。随后五个角色逐个点击书本，确认《知识试炼》（1160）全部完成。

完成后立即原路退出副本。不要继续向最终Boss奥法师杜安推进；本路线不需要Boss，也不为了装备扩大副本范围。

止损条件：如果在到达书本前连续灭团两次，或同一组怪需要多次复活才能通过，退出副本。不要反复重置硬打；记录最低经验缺口，改用剩余固定任务补足。

预计副本耗时：30—75分钟。
