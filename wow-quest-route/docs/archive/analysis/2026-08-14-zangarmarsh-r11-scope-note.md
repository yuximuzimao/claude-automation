# R11 范围说明：局部构造，不是完整攻略

日期：2026-08-14

R1–R11 都是基于本次玩家当前进度构造的局部路线快照，用于验证目标簇增量插入方法。

本次已经完成的任务，可能不会再次进入当前路线；这只表示“本轮不用重复做”，不表示它们在下一轮可复用攻略中应被删除。

因此最终完整攻略必须重新补齐并审计：
- 本次已经完成而未重新插入的任务；
- 特殊机制与广域/背景任务；
- READY_TO_TURNIN 遗留交付；
- 跨区域任务；
- 声望、可见性、前置或机制条件任务。

当前R11只能回答：在本次玩家已有进度下，已经处理的明确主体目标簇如何局部排序。不能直接作为下一组角色从零开始的完整赞加沼泽攻略。

后续制作最终可复用版本时，必须以Questie完整任务事实层重新生成“全任务候选集”，再把本轮验证出的局部路线结构迁移进去，而不是直接把R11当成最终任务清单。
