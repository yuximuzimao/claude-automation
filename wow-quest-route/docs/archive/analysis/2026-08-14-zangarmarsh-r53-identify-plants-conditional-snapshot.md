# R53：9784《鉴定植物》——重复库存机会任务

日期：2026-08-14。历史快照，基线R52，后续不得覆盖。

9784前置9802，A/T都在塞纳里奥劳兰娜·萨维尔；Questie审计类型为`ambient_inventory_turnin_repeatable`，路线策略为`conditional_inventory`。
