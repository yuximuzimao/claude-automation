# 39级→55级逐任务证据审计 V1

状态：完成第一轮全路线静态扫描与高风险任务外部查证；原`2026-08-06-level39-to-55-full-speed-route-v1.md`降级为历史草案。菲拉斯首圈→赛车场→加基森的老手基础轴继续执行，后半路线等待V2经验余量闭环。

## 1. 审计目标

唯一目标是最低角色以最短有效操作时间达到55级，不以清图、完成任务链或保留任务为目标。

本轮不再把任务简单分成“共享击杀、个人掉落、固定采集、护送”后按类型决定。每项任务采用以下证据顺序：

1. 本服首组实跑；
2. 当前Questie v11.32.3的任务等级、前置、目标数量、NPC/物体坐标和动态双倍经验；
3. AzerothCore 3.3.5参考掉落；
4. 公开玩家评论中的实际完成时间、掉率抱怨、入口、巡逻、刷新和密集点；
5. 第一具尸体、第一处物体或第一座塔的本服现场测试。

静态数据库能够明确的共享击杀数量、前置链和任务等级不重复上网搜索；只有会改变时间判断的不明确点才外查。

## 3. 时间基准修正

### 3.1 撤销两个旧估计

- 16—20小时：没有经验余量闭环，撤销。
- 40—60小时：错误地用30—35级低效率实跑均速线性外推后半程，忽略双倍任务经验、40级坐骑、后半任务中心密度和成熟路线，撤销。

用户提供的老手外部基准是：1—55正常可压在36—40小时以内，55—80约三天。该基准不直接证明当前五开一定达到同速，但可以作为合理性检查：若39→55仍需40小时以上，路线或操作模型必然存在明显问题。

### 3.2 当前经验预算

从最低号39级40893到55级需要1631007经验。

第一版V1证据预算只有1186700—1631100经验，乐观上限只比所需经验多93，证明V1没有容错。补入辛特兰完整叠加块、安戈洛4145共享击杀与条件后续、西瘟第三/第四座锅，以及费伍德短备用块后，第二版候选池为：

- 核心/可保证执行任务奖励：1026400；
- 条件任务奖励：364600；
- 任务过程中击杀经验：289000—495000；
- 总经验范围：1315400—1886000；
- 候选池乐观上限比所需经验多254993，余量约15.6%。

结论：可用任务池已经超过10%余量要求，但仍不能把所有条件任务视为必得。V2必须从水晶塔、虫穴链、第四座锅和费伍德备用块中建立互相替代的分支，确保低掉率任务失败时仍能闭合。

当前任务块结构分钟草案为1025—1565分钟，尚未加入完整跨区交通，即约17.1—26.1个有效小时。结合交通后，V2应先以18—24小时作为中位验收目标，异常竞争或多次失败时可能接近26—29小时；40—60小时不再是合理估计。

## 4. 前半路线硬约束

保留工作区已记录的老手基础轴：

`莫沙彻菲拉斯首圈 → 赛车场固定交付 → 加基森/塔纳利斯 → 菲拉斯高等级第二圈`

当前炉石已设莫沙彻。第一次塔纳利斯结束后炉石返回菲拉斯第二圈；第二圈结束、再次到加基森时再改炉石到加基森。该安排只减少转场，不改变老手地图轴。

护送机制按用户实测更新：普通小队一个角色接取可共享护送时，其他队员收到接受弹窗。以后由主控领取，确认其余四号全部接受后启动，不再为“五号逐个找NPC接任务”增加成本。
