## 判定口径

本轮只标记真正需要取得多个任务物品的任务：

- 多个怪物掉落任务物；
- 多次拾取/搜取任务物；
- 多种不同任务物各取1件，但总任务物数量大于1。

明确排除：

- 单个命名怪任务物；
- 单个普通怪任务物；
- 单次点击/使用/脚本互动；
- 即使需要点击多个世界物体，但目标只是摧毁、打碎、使用，而不是取得任务物品，也不标本轮正向标签。

自动判定优先复用 `borean-tundra-task-foundation.json` 已有的 `objective_type / required_count / mechanic / fivebox_mode / count_confidence / sources`。Questie来源或计数不完整的8项按WotLK Classic任务资料人工复核；复核完成后当前待确认数为0。
