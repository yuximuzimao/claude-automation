# 赞加沼泽目标簇空间实例与剩余目标人工归位 v1

日期：2026-08-14

## 目的

冻结上一层“共享任务怪目标簇”，本文件只处理空间事实：目标簇在地图上的真实空间实例，以及尚未被共享怪目标簇吸收的任务目标应挂到哪个空间实例。所有归位均基于 Questie 真实目标坐标/人工核验机制点与赞加地图实际区域逐项判断；不使用距离阈值、质心聚类或自动最近邻来代替人工判断。

## 核心规则

1. 目标簇是语义簇，不等于单一地理点。一个目标簇可以有多个互不相邻的空间实例。
2. 剩余任务只有在真实目标区域确实与某空间实例重合/同营地/同一条局部进出路径时才挂入；不确定则保留独立空间节点。
3. 广域背景目标不强行归到单一点：它们只能作为沿途累计层。
4. 同一任务可以拆成多个空间目标。例如 9720《恢复平衡》四个水泵分别挂到四个不同空间节点；9772《尤尔巴的报告》两类怪分布在东北死亡泥潭与西南孢殖林两个实例。

- 巨人核心簇（东北实例）：枯萎的巨人，约 x78–86, y32–47。
- 巨人扩展簇（东北实例）：枯萎的沼泽领主，约 x77–86, y32–47。

## 广域背景目标：不允许压成单一点

### 9770《沼牙的威胁》

沼牙撕裂者在东半张地图广泛分布，约 x68–87, y32–88。它应该是“东部沿途累计”背景任务，不应生成一个伪代表点来支配路线。

### 9808/9809《亮顶蘑菇 / 更多亮顶蘑菇》

亮顶蘑菇分布约 x18–49, y29–64，横跨西中部多个任务区。作为西部/中部沿途采集层，不绑定单一目标簇。

### 9842《最锋利的刀刃》

沼牙切割者约 x18–40, y43–71，覆盖大片西部；“伯爵”昂古拉固定点约 (32.81,59.53)。任务整体应视为西部背景击杀 + 一个固定补点，而不能用一个中心点表示。其活动范围与沼光抽血者簇多个西部实例大量重合，因此动作层可与沼光抽血者路线共同累计，但空间层仍保留广域属性。

### 成熟孢子基础簇（9806/9807）

孢子蝠/大型孢子蝠/沼泽阔步者/泥沼游荡者遍布赞加，不生成单一空间点。该簇应作为全图背景累计层；真正固定的孢子之翼 (78.01,45.41) 与沼泽之鞭 (82.07,71.39) 仍分别保留为明确空间实例。

### 9773《别再提蘑菇了！》

暗泽鳗鱼沿东部水域 x71–77, y61–82 分布，适合沿“哈格哈兹/泻湖 → 暗泽湖”水路累计；不独立驱动一次往返。

## 目前空间层结论

1. 原共享怪目标簇不能直接作为地图节点；必须经过“空间实例”层。
2. 最关键的人工拆分：
   - 巨人核心/扩展簇 = 东北死亡泥潭实例 + 西南孢殖林实例。
   - 成熟孢子基础簇 = 全图背景层，不设中心点。
   - 沼光抽血者簇 = 多个西部实例，不设单一中心点。
3. 新增三个非常明确的空间簇：
   - 暗泽村南缘：9788 + 9894 + 10096。
   - 匕潭村：9816 + 10117 + 10118。
   - 暗泽湖水泵：9716 + 9720(Umbrafen Pump)，并承接9773鳗鱼南段。
4. 9720《恢复平衡》必须拆成四个空间动作，分别嵌入血鳞、弗亚希、哈格哈兹、暗泽湖四个区域。
5. 背景任务不能反过来定义路线；只能跟随主体目标簇自然累计。
