# 外域58—68：任务等级窗口与任务链趋势审计（2026-08-11）

状态：趋势审计，不是玩家执行攻略。目的不是给出具体坐标路线，而是先确定哪些任务/任务链存在满经验交付截止，哪些地图必须提前介入，哪些任务可以整块延后到80级再回收。

## 1. 口径

- 主池：外域开放世界一次性任务、沙塔斯一次性跨区链、其必要前置/后续。
- 单独池：副本任务、职业/专业任务、PvP任务、日常/可重复任务、70级残局/飞行坐骑前置等。单独池不直接塞进58→68主轴。
- 原始`world-candidate`只能做召回：其中包含DEPRECATED、特殊任务、重复/互斥/引导项；原始任务数和原始经验总量不能直接当作可执行精确预算。
- WotLK任务经验满额窗口：角色等级 <= 任务等级+5。外域规划必须看五号中可能升级最快的角色，而不仅是最低号。
- 本服任务经验和普通怪经验均为2倍；休息经验只作为现场额外收益，不进入保证账。

## 2. 真正的满经验截止层

| 任务等级 | 最晚满经验交付等级 | 58→68阶段意义 |
|---|---:|---|
| 60 | 65 | 最高优先，角色66后即衰减 |
| 61 | 66 | 高优先，角色67后即衰减 |
| 62 | 67 | 高优先，角色68后即衰减 |
| 63 | 68 | 只要在离开外域前、最高号仍68即可满额 |
| 64 | 69 | 58→68阶段没有硬衰减压力 |
| 65 | 70 | 无硬压力 |
| 66+ | 71+ | 58→68阶段无需因衰减抢做 |

因此真正决定地图穿插的只有60/61/62级任务；63级任务属于“离开外域前结清或整块留到80”的边界层。

## 3. 地图等级趋势（原始候选，仅用于风险定位）

- 地狱火半岛：60×7、61×57、62×30、63×17、70×5。低等级任务极多，是整个外域最紧急区域。
- 赞加沼泽：61×1、62×18、63×6、64×28、65×2。必须优先处理61/62档，64/65可后置。
- 泰罗卡森林：62×2、63×12、64×23、65×30、66×1、67×3、68×1、69×3、70×5。只有最早两条62级任务有67级硬截止；63档要在最高号68时结清，否则干脆留到80。
- 沙塔斯城：63×1、64×3、65×8、67×3、70×22。没有60—62级硬截止，但存在泰罗卡↔沙塔斯跨区链，不能当纯主城独立处理。
- 刀锋山：最低64级（之后65—70）。到68前无硬衰减压力。
- 纳格兰：最低65级。到68前无硬衰减压力，但部落玛格汉任务中心受地狱火前置链/声望影响，是结构性前置风险。
- 虚空风暴：最低68级。不是低等级抢跑区。
- 影月谷：最低69级。不是58→68低等级抢跑区。

### D. 《地狱火半岛的工事》（13409）ql60

这是特殊PvP任务，首次完成后又存在可重复/日常版本。不能和普通一次性世界任务一样机械塞进主轴；正式路线要单独判断服务器阵营占领状态、PvP开关和五开可执行性。

## 7. 63级边界层：最高号68时仍满经验

63级任务不存在“必须在67前抢”的压力，但它们有一个明确决策点：

- 如果打算利用其经验，就必须在最高号仍为68时完成并交付；
- 如果准备转诺森德，不要在69—79再零散回头做，因为此时经验开始衰减、又尚未获得80级的满级金币补偿；
- 更好的做法是：要么在68前按完整任务块结清，要么整条链/整个任务中心留到80再回收。

需要特别注意的跨区链：
- 泰罗卡《不择手段》（9978）ql63 → 沙塔斯《星界商人拉斯莱》（9979）ql63 → 泰罗卡《私人事务》（10112）ql64 → 后续火翼岗哨链。

这说明沙塔斯不是独立“回城交任务”，而是泰罗卡任务循环的一部分。

## 8. 64级以上：58→68阶段没有硬抢跑压力

### 刀锋山
- 最低ql64，随后主要66—68。
- 到68时仍全部处于满经验窗口。
- 可以作为升级后段完整任务块，也可以把完整任务中心留到80回收；不要留下散点。

### 纳格兰
- 最低ql65，主要65—68。
- 到68时全部满经验。
- 重点不是衰减，而是玛格汉链前置；地狱火前置必须提前完成，避免到纳格兰后才发现加拉达尔链不开放。
- 典型长链包括三条狩猎线汇合《终极挑战》，以及玛格汉/加拉达尔故事线。若以后延后，应该整链延后而不是只剩每条末尾一两环。

### 虚空风暴
- 最低ql68，绝大部分69/70。
- 完全不属于低等级抢跑区。若58→68目标是尽快转诺森德，虚空可以整体作为后置经济/任务清理地图候选。

### 影月谷
- 最低ql69，主要69/70。
- 不影响58→68零衰减目标；天然适合后置。

### 沙塔斯
- 最低ql63，真正需要68前判断的主要是与泰罗卡连接的ql63链。
- q64/65/67及大量70级任务没有当前硬截止，可按其跨区后续决定什么时候做。

## 9. 当前路线趋势（非具体攻略）

路线不应再是：

`地狱火全清 → 赞加全清 → 泰罗卡全清 → 纳格兰……`

更合理的等级窗口趋势是：

1. 58进入地狱火，优先推进所有ql60/61任务链及其必要前置。
2. 最高号逼近65—66时做第一次截止审计：地狱火ql60必须已清；ql61必须进入收尾。
3. 在最高号66以前，提前介入赞加，至少处理《别再提蘑菇了！》（9773）及其ql62后续。
4. 最高号67以前，清完外域所有仍计划拿练级经验的ql62：地狱火剩余ql62、赞加ql62包、泰罗卡两条ql62入口；玛格汉链优先于普通ql62。
5. 最高号68以前，决定所有ql63任务：完整任务块现在结清，或者整个任务中心留到80。不要留下69—79期间需要回头的零散ql63任务。
6. 处理完ql63经验负债后，外域64+任务不再有58→68衰减压力。此后才真正比较：继续在外域做高密度任务升级，还是最低号68后直接转诺森德，把完整的纳格兰/刀锋山/虚空/影月任务中心留到80经济回收。

## 10. “80级回头清金”初步机制结论

标准WotLK服务端机制中，角色达到当前满级后，任务不再调用普通`CalculateQuestRewardXP()`，而是直接使用任务固定的`RewMoneyMaxLevel`作为满级金币补偿；这不是69—79期间灰任务的衰减经验。也就是说，从机制上确实存在“升级期不做，80后回头拿满级金币补偿”的策略空间。

但是否值得后置必须同时看：
- 第二次进图交通；
- 任务链是否已经被前段切碎；
- 任务中心是否能形成一整圈；
- 80级飞行/战力提升能否大幅缩短任务时间；
- 时光服非可重复任务还会给泰坦碎片，任务等级越高奖励越丰厚，因此高等级外域任务后置的经济价值可能高于低等级散任务。

因此后置规则应该是“整块留”，不是“零散剩”。

## 11. 下一步需要做的，不是写攻略

下一步先建立一个链级总表，每条链记录：

`链名 / 地图与任务中心 / 链内最低任务等级 / 最晚满经验等级 / 是否跨地图 / 是否解锁后续地图任务中心 / 是否适合68前结清 / 是否适合80整块回收`

之后再用用户当前五号真实58级经验差，把“最高号65/66/67/68”四个截止点转换成实际路线检查点。只有这一步完成后，才开始写地狱火的具体循环攻略。
