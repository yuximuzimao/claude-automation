# 历史档案

本目录只保存已经被替代、一次性形成过程或阶段快照。它们用于复盘和考古，不是当前项目知识入口。

日常工作先读 `../INDEX.md`、项目 `SKILL.md` 和对应 `CURRENT.md`；只有当前问题明确需要追溯历史时，才进入本目录定向读取。

## 分类

- `analysis/`：日期化分析、求解过程、地图专项审计、R快照和设计形成过程。
- `proposed-routes/`：没有进入正式执行、后来被放弃的候选路线与旧方案。
- `routes/`：曾经实际作为执行稿/完整攻略使用、后来被新版本替代的历史路线。
- `neat/`：首组练级、Route Atlas等阶段复盘/NEAT；不再混放完整路线版本。
- `video/`：视频拆解的历史审计与阶段NEAT。
- `generated/`：已经退出当前工作流、但仍由旧生成器保留的内部审计输出。
- `scripts/`：已退出当前实现链的阶段性脚本及其专属历史测试；只用于追溯当时如何形成结论，不得被当前builder、默认审计或活跃测试导入/执行。

## NEAT审计边界

NEAT每次必须全文审查**当前活跃知识区**，但不重复全文读取整个历史档案库。

历史档案默认只检查：

1. `archive/README.md` 本身是否仍能正确导航；
2. 本轮Git新增、修改、移动到 `archive/` 的文件；
3. 当前 `CURRENT.md` 或活跃文档明确引用、且本轮任务确实需要回溯的最近历史文件。

除此之外的旧路线、旧设计稿、旧分析和旧NEAT保持只读，不因每次NEAT重复审计。需要考古时再按主题或关键词进入对应目录。

历史材料不得反向覆盖当前真值：当前状态看 `CURRENT.md`，永久规则看 `../rules/`，当前路线数据看 `../../data/route-atlas/` 与 `../verified-routes/`。
