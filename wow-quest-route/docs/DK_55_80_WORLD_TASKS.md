# 血精灵死亡骑士五开 55—80 全世界任务母版内部归档

## 项目目标

- 首组血精灵圣骑士只承担解锁55级死亡骑士创建条件；现有1—80路线继续保留为首组实跑参考，不再作为后续重复打金的主模型。
- 后续循环以五个55级死亡骑士为起点，完整跑55—80级主要打金地图，并逐轮记录任务阻断、死亡点、回头路、洞穴风险和逐号操作。
- 当前页面是全任务覆盖母版，不宣称第一版已经是最短路线；只有实跑稳定的地图段才能升级为固定循环。
- 当前静态核算仅用于判断经验总量：死亡骑士出生链加“外域八区全部候选”任务奖励约1520万经验，理论上不足以单独从55升到80；但老手实际采用哪些全清地图尚未确认，因此不得提前固化最终地图组合。
- 已确认时光服当前死亡骑士创建机制：账号内任意一个角色达到55级后，即可在任意服务器创建一个55级死亡骑士；不限制种族、性别或阵营。仍待向老手确认死亡骑士实际全清哪些地图、按什么顺序完成。
- 老手提供的收益基准为：一组五个号完成整套全清升级流程，合计约5万—6万金币。该实测口径优先级高于此前只统计任务现金与奖励装备卖店价得到的低估值；具体包含哪些掉落、地图和支出仍待确认。
- 探索性经验、耗时和金币分析见`docs/analysis/2026-08-03-dk-55-80-outland-xp-time-gold.md`，其中旧金币区间已标记为失效估算。
