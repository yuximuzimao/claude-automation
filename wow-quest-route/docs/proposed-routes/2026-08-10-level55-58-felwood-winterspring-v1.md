# 55→58 费伍德过路包 + 冬泉谷 V1

状态：首组待实跑验证；当前55级，奥格瑞玛出发。目标只看五号中最低经验角色；出发前把五号炉石改绑奥格瑞玛，最低号到58后立即结束旧大陆阶段并直接炉石奥格瑞玛准备外域。永望镇飞行点仍首次到达时开启，作为长期交通和备用退出节点。

## 路线原则

- 不清费伍德整图；只做贴着南北主路、几乎不增加跨区折返的木喉任务。
- 不把冬泉谷任务等级误当接取等级；55级可接的56—60级任务继续看真实目标怪等级。57—58级怪正常纳入，60级目标当前跳过。
- 任务和普通怪经验均按本服2倍；五人组队后同等级普通怪每号实收约100—200经验。
- 路上顺手杀当前任务目标，不为了无任务怪偏离主路。只有任务自然清完仍不足58时，才考虑专门补怪。
- 冬泉谷跨回费伍德、塔纳利斯、安戈洛、东瘟疫等后续默认不做；本轮目标是一次进入冬泉后闭合到58。

## 一、奥格瑞玛 → 碎木岗哨 → 费伍德南口

从奥格瑞玛飞碎木岗哨。五号已有碎木岗哨飞行点；落地后向西北进入费伍德森林，沿主路北上。

### 格拉兹（50.9,85.0）——南口顺路包

第一次经过格拉兹时接：

- 《木喉熊怪的盟友》（8460）：杀6名死木战士、6名死木探险者、6名死木园丁。

目标就在格拉兹西侧/西南侧死木营地（约46—50,88—94）。这是18只共享击杀；清够后立刻回格拉兹交《木喉熊怪的盟友》（8460）。如果交后出现《与纳菲恩交谈》（8462），直接接走，因为纳菲恩正好位于费伍德最北端必经的木喉入口。

这一块不延伸到翡翠圣地、加德纳尔、血毒岗哨，不接需要离开主路再回头的费伍德任务。

## 二、费伍德一路北上 → 木喉入口

交完南口任务后只沿费伍德主路向北。途中不为了普通费伍德任务停靠任务中心。

### 纳菲恩（64.8,8.1）——北口顺路包

到木喉入口前先处理纳菲恩：

- 若日志有《与纳菲恩交谈》（8462），先交。
- 接《北方的死木熊怪》（8461）：杀6名死木守卫、6名死木复仇者、6名死木萨满祭司。
- 接《与萨尔法交谈》（8465）：本来就要穿木喉去冬泉，因此这是白送对话任务。

《北方的死木熊怪》（8461）目标就在纳菲恩西南侧魔爪村/北部死木营地（约61—63,10—15），同样是18只共享击杀。做完立即回纳菲恩交任务。

这两组费伍德共享击杀任务按当前项目数据约提供：

- 《木喉熊怪的盟友》（8460）：约12600任务经验；
- 《北方的死木熊怪》（8461）：约16300任务经验；
- 《与纳菲恩交谈》（8462）与《与萨尔法交谈》（8465）两项对话合计约3300任务经验；
- 合计约32200任务经验，另有36只任务怪的本服双倍击杀经验。

在进入木喉隧道前看一眼木喉要塞声望。若仍为敌对，不硬冲隧道；继续在纳菲恩附近杀北部死木熊怪，直到木喉不再主动攻击。若已经不敌对，立刻进入隧道。

木喉隧道岔路优先走通往冬泉谷的一侧；不要误入月光林地。

## 三、萨尔法 → 永望镇

从木喉隧道进入冬泉谷后，萨尔法就在出口附近（公开旧资料约27,34；现场以Questie箭头为准）。

- 交《与萨尔法交谈》（8465）。
- 接《冬泉熊怪的活动》（8464）。该任务要求杀冬泉熊怪，后面与多诺瓦的《冬泉熊怪的威胁》（5082）高度重叠，必须提前带上。

接完后先不在西边开打，直接沿路前往永望镇。

## 四、永望镇（约61,38）——第一次接任务

第一件事：五号分别开启永望镇部落飞行点。以后最低号到58即可直接从这里离开旧大陆。

第一次只接当前本地图主干：

- 《雪怪计划！》（3783）：10张厚雪人毛皮；后续为《雪怪计划！》（977）。
- 《碎齿熊尤西乌斯》（5054）：杀尤西乌斯；后续为《冰风奇美拉布鲁米兰》（5055）。
- 《冬泉谷的麻烦！》（6603）：去找多诺瓦·雪山；交后开启《冬泉熊怪的威胁》（5082）。
- 《一点运气》（6606）如果现场可接/可直接对话完成，原地顺手处理，不为它额外移动。

明确不接/不做：

- 《祝你好运》（969）：南部霜槌区域，当前60级目标风险不值；
- 《炽热板甲护手》（5124）：制作材料任务；
- 《永望镇报告》（6029）：送西瘟疫；
- 《尼古拉斯·瑟伦霍夫公爵》（6030）：送东瘟疫；
- 《奇怪的家伙》（6605）：送回费伍德。

## 五、永望镇 → 多诺瓦 → 冬泉村 → 冰蓟岭 → 尤西乌斯：第一大环

### 多诺瓦·雪山（31.3,45.2）

从永望镇沿主路西行到多诺瓦：

- 交《冬泉谷的麻烦！》（6603）。
- 立即接《冬泉熊怪的威胁》（5082）：8冬泉探路者、8冬泉巢穴守卫、8冬泉图腾师。

之后转头向东返回。路上看到《冬泉熊怪的威胁》（5082）的目标顺手杀，但不为了西侧散点绕路；主要数量放到东侧冬泉村集中解决。

### 冬泉村（约66—68,35—38）——两任务合并

这里同时推进：

- 《冬泉熊怪的活动》（8464）；
- 《冬泉熊怪的威胁》（5082）。

两任务共享冬泉巢穴守卫，其他冬泉熊怪也集中在同一村庄与北侧山坡。优先在村口、村内和约64—67,35—38山坡清怪，不画大环线追散点。

如果在清熊怪时自然掉出触发《冬泉火酒》（5083）的空火酒瓶，立即右键接任务；后面本来就要回多诺瓦，可以零额外转场交掉。但《冬泉火酒》（5083）后续《堕落熊怪》（5084）会把你重新带回费伍德，本轮到此为止，不继续追链。

### 冰蓟岭（约65—71,40—45）

从冬泉村直接向南/东南切到冰蓟岭，完成《雪怪计划！》（3783）。五号总需求50张厚雪人毛皮；这是当前第一项随机掉落长尾任务，但雪人等级与本轮经验区间匹配，因此允许自然多杀，不单独设很短止损线。优先清密集的冰蓟雪人刷新区，不追全图散点。

### 尤西乌斯巡逻区（约56—64,24—38）

雪人块结束后向北寻找56级尤西乌斯，完成《碎齿熊尤西乌斯》（5054）。他是巡逻命名怪，外观与普通白熊接近；沿56,38 → 60,31 → 61,27 → 64,24附近巡逻点搜索，避免原地死等。

完成后进入第一轮集中交付。

## 六、第一轮交付：先西后东，不重复折返

第一轮已经同时完成东西两侧任务，因此按一趟西侧回收后再回永望镇：

1. 从尤西乌斯区域向西去萨尔法，交《冬泉熊怪的活动》（8464）。
2. 再向南到多诺瓦·雪山，交《冬泉熊怪的威胁》（5082）。如果自然拿到《冬泉火酒》（5083），同趟一起交。
3. 多诺瓦交《冬泉火酒》（5083）后若出现《堕落熊怪》（5084），不要接/不要做；其后续还会继续要求回费伍德。
4. 返回永望镇，交《雪怪计划！》（3783）与《碎齿熊尤西乌斯》（5054）。

交后立即接：

- 《雪怪计划！》（977）：2支完美雪人角/号，五号总需求10支；
- 《冰风奇美拉布鲁米兰》（5055）：击杀58级布鲁米兰。

## 七、第二大环：完美雪人角 → 布鲁米兰

### 冰蓟岭（约67—71,38—43）

第二次进入冰蓟岭只打冰蓟雪人女王/雪人王，完成《雪怪计划！》（977）。该任务是个人掉落、单次只掉一支角，五号共需10支，存在明显随机长尾；本轮因为怪物经验也是2倍，可以容忍一定额外击杀，但不要把“必须刷齐任务”置于58级停止条件之上：若过程中最低号已经58，立即停止旧大陆任务。

### 布鲁米兰（约62.5,57.9附近巡逻）

从冰蓟岭向南找58级非精英奇美拉布鲁米兰，完成《冰风奇美拉布鲁米兰》（5055）。

然后返回永望镇集中交《雪怪计划！》（977）和《冰风奇美拉布鲁米兰》（5055）。

交后会出现：

- 《希洛塔姆》（5056）：任务60，目标希洛塔姆本身60级，当前战力规则明确跳过；后续《以往的努力》（5057）还要去雷霆崖，因此整条在5055结束。
- 《雪怪计划！》（5163）：要求去永望镇、加基森、安戈洛三个地点吓NPC；本轮不接/不做，雪怪链在977结束。

## 八、58级停止条件

每次大任务交付后都看最低号经验，不用等整张图清空。

- 最低号达到58：立即停止当前旧大陆任务；五号直接炉石奥格瑞玛，准备外域。若炉石异常或现场未成功改绑，再回永望镇用新开的飞行点作为备用退出。
- 第二大环结束仍未58，但差距已经很小：优先在冬泉村或冰蓟岭杀55—58级密集怪补齐，不开启跨费伍德长链。
- 若第二大环结束仍差一大截：再单独比较《冬泉火酒》（5083）后续5084→5085→5086→5087→5121的跨费伍德长链，与冬泉本地纯刷怪的剩余墙钟；没有比较前不自动接长链。

## 当前明确排除的冬泉链

- 《雪怪计划！》（5163）：跨永望镇/加基森/安戈洛。
- 《希洛塔姆》（5056）→《以往的努力》（5057）：当前先被60级目标卡住，后续还去雷霆崖。
- 《冬泉火酒》（5083）之后的《堕落熊怪》（5084）→《神秘的粘液》（5085）→《剧毒之水》（5086）→《冬泉信使》（5087）→《冬泉酋长》（5121）：前半段要求重复进入费伍德，本轮只作为第二大环后仍严重缺经验时的备选包。
- 费伍德《冬泉谷的枭兽》（4521→4741→4721）：虽然目标全在冬泉且是共享击杀，但每一环都要回费伍德交再回来，地图轴成本过高，本轮不启用。
