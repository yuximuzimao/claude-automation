# 39→55五开路线二次优化：视频独立、零购买、增量操作成本

状态：候选路线比较阶段。前段莫沙彻菲拉斯→赛车场→塔纳利斯不变；后半保留“灼热峡谷全东部收尾”和“安戈洛后回西瘟”两个近似候选，待前段实跑后按最低号等级与时间选择。

## 1. 三项用户纠偏

### 1.1 单号视频不是五开速度基准

单号视频只能证明任务、地点、入口、任务块和机制可行。单号杀怪速度、联盟任务集合和视频作者取舍不等于血精灵五开最优路线。

五开每个角色取得完整任务经验，而共享击杀只需队伍完成一次。老手五开能达到与单号视频相近的总升级时间，反而证明视频路线存在五开专属优化空间。

结论：优化器从部落35—55全任务池独立选块；视频不限制地图顺序、任务集合或预计时间。

### 1.2 主号操作不能统一计为成本

主号本来就承担战斗、骑乘和路线控制。成本必须分四类：

1. 基线主控：正常打怪、跑路、骑乘，不额外惩罚；
2. 短暂主控偏离：短跳、从高台跳下、一次任务物使用、短暂绕障碍，只计真实秒数；
3. 逐号串行：五号分别点击、摸尸、使用物品，按切号次数和单次秒数计；
4. 破坏队形：断跟随、逐号重新定位、卡地形、等待刷新、失败重跑，才是高成本。

6025《未完的任务》是典型高收益短主控任务：主号到高处观察炉石镇即可，不应因“高台手动走位”降权。

### 1.3 尸体/场景物不假设同时使用

不再假设五号必须同时对尸体或场景物使用任务道具。现场只按以下两种正常机制处理：

- 主号完成后队伍同步；
- 物体正在被使用时其他角色暂时不能操作，随后按顺序使用或等待正常刷新。

因此此类任务的机制本身不降权；只评估目标分布、击杀总量、逐号操作秒数和路线重叠。

菲拉斯3123—3127灵魂容器链由“机制风险”改成正常免费候选链。当前整链约70800双倍任务经验，是否最终主线只由跨区目标成本决定。

## 2. 零购买硬约束

保证路线不得要求：

- 拍卖行购买；
- 邮寄材料；
- 专门制作任务物；
- 有意义的前置金币投入。

因此：

- 4449所需五号合计75块丝绸不计保证路线；
- A-Me 4244所需5个秘银外壳不计保证路线；
- 4284四色水晶不得以预购140个为前提；
- 已经持有材料只开启额外奖励，不计保证经验。

零购买总候选池仍达到约216.87万经验，高于39级40893到55所需163.10万约53.8万，金币不是经验闭环的必要条件。
