## 4. 为什么完整清图不是最快

五开任务成本必须分型：

- 共享击杀：打一批怪，五号同步，通常高效。
- 个人掉落：五号分别判定掉落，是最容易失控的类型。
- 固定物体：五号逐个点击，时间稳定，可计算。
- 命名怪：加入刷新等待、尸体是否可供五号拾取和失败重打风险。
- 跑腿：加入骑行、飞行、船、飞艇等待、楼层和回访次数。
- 洞穴/护送：加入断跟随、死亡、回尸和失败重来概率。

已识别的菲拉斯低效候选：

- 3128《天然材料》：2原木、6矿石、20肌腱、40金属碎片，个人高数量收集，冲级默认跳过。
- 2974《可怕的发现》：20个恐怖图腾之角，个人掉落，默认跳过。
- 7730《祖卡什的入侵》：20块虫壳，个人掉落，默认跳过。
- 7003《被缩小的巨人》：15份残渣，默认跳过。
- 2973《新斗篷的光辉》、7734《更高的品质》、7721《压缩器的动力》：各10件个人掉落，只有和多任务高度重合或实测掉率高时保留。

已识别的塔纳利斯低效/条件候选：

- 654《塔纳利斯的样本》：三类各8份且带工具时限，冲级默认跳过。
- 3042《巨魔调和剂》、2865《圣甲虫的壳》、2768《探水棒》、3527《摩沙鲁的预言》：属于祖尔法拉克副本任务包，不混入户外路线。
