# R18：插入9809《更多亮顶蘑菇》

日期：2026-08-14。历史快照，基线R17，后续不得覆盖。

本轮严格只插入9809。

前置9808。R17把T9808放在炉石2之后再次经过孢子村时，因此原地A9809。9809每号只需1枚亮顶蘑菇，五开总共5枚。

姆希菲附近最近5个刷新点分别约在 `(19.73,51.12)`、`(19.89,53.24)`、`(20.00,53.85)`、`(20.07,54.40)`、`(18.27,50.12)`，距离孢子村锚点均约2.4个地图坐标单位以内。

因此R18采用孢子村本地微型采集环：
```text
姆希菲：T9808 + A9809
→ 孢子村周边5个亮顶蘑菇：C9809
→ 姆希菲：T9809
→ 继续去莉萨奥
```

不把9809带到后续路线再回头交，因为后面没有自然返回孢子村的停靠。R18只增加一个很小的本地环，不改变主体跨区顺序。
