# 外域低收益拾取任务筛选审计（地狱火样板）

状态：2026-08-17首轮完成。目标不是重排整张地狱火路线，而是先验证老手“时光服双倍经验下跳低收益拾取任务”的真实适用边界，并形成后续赞加/泰罗卡/纳格兰可复用筛选口径。

## 1. 新证据与结论边界

老手已确认：时光服双倍经验下，成熟路线不要求把一张地图所有任务做完才换图；外域以后会主动跳过大量需要额外拾取/补刷、且没有值得拿的装备收益的任务。这里不仅包括怪物多件掉落，也包括部分多件地面拾取。

但奖励机制本身并不支持“外域拾取任务全部不出装备”这一硬规则。地狱火、赞加、纳格兰都存在明确反例。因此正式路线不能按“目标字段=拾取”直接删除，而应按以下顺序判断：

1. 本任务是否直接给装备；
2. 若不直接给装备，是否只需很短的后续就能拿到装备；
3. 拾取是随机怪掉落、固定地面物，还是与必做任务完全重叠；
4. 五开是否要逐号拾取/逐号点击，是否存在掉率长尾或竞争；
5. 删除整条任务包后，最低号到换图等级的经验是否仍闭合。

本轮只针对原地狱火91条户外主任务中的“多件拾取型”做删减判断；其余73条任务本轮全部保留，不因本原则删除。

## 2. 旧世界与外域奖励机制核验

### 旧世界并不存在“多拾取任务都只给经验”的统一机制

公开WotLK任务数据可同时找到两类：

- 《火箭车零件》：30个地面零件，无装备奖励；
- 《能量水晶》：四色各7个，共28个地面水晶，无装备奖励；
- 《荒芜之地的材料 II/Badlands Reagent Run》类多掉落任务也常为经验/金钱型；
- 反例《搜集材料/Scrounging》：需要7个废料，但直接给盾牌/鞋子二选一。

因此用户58级前“跳太多拾取后经验不够”的现象，不是因为旧世界拾取任务奖励结构与外域完全不同，而是旧世界阶段可用任务密度、地图连接和经验余量更紧，不能承受同样激进的删除比例。

### 外域同样不是“拾取=无装备”

明确反例包括：

- 地狱火《噬骨之血》：12瓶怪物掉落，直接给武器/盾牌等装备；
- 地狱火《我为部落工作！》：8木材+8金属地面拾取，直接给头/胸/腿等装备；
- 地狱火《以防万一......》：30个地面飞艇碎片，直接给装备；
- 地狱火《阻断援军》：怪物掉落恶魔符文石并炸两座门，直接给多件装备选项；
- 赞加《最锋利的刀刃》：10片怪物掉落刀刃，直接给武器；
- 赞加《偷回蘑菇》：10箱蘑菇，直接给肩/腰/头/腕装备；
- 纳格兰《潜水》：5个核心，直接给胸/腿等装备；
- 纳格兰《血环补给箱》：10个地面箱子，直接给鞋/远程武器/饰品类奖励。

所以老手口述必须理解为“跳低收益拾取”，不能理解成一条游戏系统规则。

## 3. 地狱火91任务经验闭合：先确认一个重要事实

权威首跑池：`docs/archive/analysis/2026-08-11-hellfire-time-server-circles-v2.md`，共91条时光服/TBC口径户外主任务。

项目本地Questie经验函数 `quest_xp_at_level()` 已内置服务器任务经验倍率2.0。按这些任务在64级前交付的当前服务器口径重算：

- 91任务完整任务奖励经验约：**1,535,050**；
- WotLK 58→64所需总经验：165,800 + 172,000 + 290,000 + 317,000 + 349,000 + 386,000 = **1,679,800**；
- 即使91条全部做，纯任务交付经验仍约差 **144,750** 才能从58.0到64.0。

因此后续不能再用“删完后剩余任务奖励必须单独到64”作为唯一门禁——这个条件连旧版全清主池都过不了。首组能到64，本来就已经包含大量任务强制击杀、路线自然击杀、探索等经验。

后续保证账改为两层：

- 第一层：保留任务的确定交付经验；
- 第二层：保留任务中**强制要求的必要击杀**按保守下界计入；
- 沿路额外怪、抢怪补杀、随机多刷一律仍按0，不拿偶然经验填缺口。

这只是外域当前阶段的筛选实验口径；实测稳定后再决定是否升级为永久规则。

## 5. 为什么“严格按老手口述逐任务删”还需要再修一层

如果把“当前这一步不给装备的拾取任务”逐条机械删除，会错误切断：

- 9366《邪恶之血》→9370《阻止净化》装备；
- 9372《恶魔的玷污》→10255《测试解毒剂》武器；
- 10236《外域这烂地方！》短链→10630《萨尔玛的地下》装备；
- 10278/10294虽然本身不出装，10295链尾也有装备；
- 10538虽然本身不出装，10876链尾有胸甲。

因此项目采用“老手原则作为第一筛选器，任务链收益作为第二筛选器”。真正删除条件是：**整包拾取墙钟高，且装备兑现不足以抵消该墙钟，且删后经验下界仍能支撑换图。**
