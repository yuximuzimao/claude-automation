# 北风苔原正式流程：第四轮剔除优先级锁定标签

状态：**优化决策标签已锁定；仍不是正式删任务决定，也不属于任务卡基础属性。**

## 规则

只有以下收集形态进入剔除优先级：

- `repeated_same_item`：重复取得同一种任务物；
- `repeated_plus_distinct`：重复取得某种任务物，同时还需要另一种单独任务物。

以下情况不进入剔除优先级：

- `multiple_distinct_one_each`：多个不同任务物各取1件；
- 单个任务物；
- 单次互动；
- 多次摧毁/使用世界物体但不取得多个任务物。

优先级采用用户确认的加减一级规则：

- 起点P1：**多件掉落 + 本任务无装备/无直接金币 + 有效后续链没有装备/金币价值**。
- “多件拾取”相对同条件的“多件掉落”降1级。
- 本任务存在装备或直接金币奖励，降1级。
- 有效后续任务链中至少有1个任务存在装备或直接金币奖励，再降1级，并打 `removal:potential_value_followup`。

因此：`priority = 1 + pickup + direct_value + valuable_followup`。

同一P级内部再按有价值后续任务数量分三级：A=0个、B=1个、C=2个及以上；A在同一P级内最优先剔除，C最晚。这个A/B/C只属于优化决策层，不回写任务卡。
