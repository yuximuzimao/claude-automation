# 视频34—37级任务带与现有路线差异

日期：2026-08-05

## 结论

此前从“当前35.5级、当前荆棘谷”直接构造35.5→37路线，起点过晚。视频第12集的任务并不是在第12集开头临时选择，而是在第11集结尾抵达南海镇后一次性接取，再于第12集执行。因此转换视频路线时，至少需要读取“前一集结尾＋当前集＋后一集开头”。

用户当前仍可能补做一组对应的部落任务：塔伦米尔→南奥特兰克→达拉然→破碎岭。这组任务的固定经验约24,700，主要目标等级33—37，适合把35.5级补到约36级后再进入荆棘谷第13集路线。

第11集末尾，作者抵达南海镇后批量接取：

- 540《保全书籍》：任务等级38
- 564《损失惨重》：任务等级34
- 659阶段《新的瘟疫？》：任务等级33

- 536《清理海岸》：任务等级30

- 505《辛迪加刺客》：任务等级33
- 500《破碎岭食人魔》：任务等级36

第12集执行顺序：

1. 南海镇西侧海岸：鱼人＋海龟。
2. 向北移动：取得遗失水晶。
3. 丘陵和山头：山狮。
4. 奥特兰克南部：辛迪加成员，同时触发《密文信件》等野外任务。
5. 破碎岭与奥特兰克废墟：食人魔＋书籍。

这是一条地理连续的任务包路线，不是按单任务效率逐项选择。

## 玩家等级与任务等级关系

批量接取发生在第11集最后约2分钟。视频标题边界只能把玩家等级限定在33→34附近，无法仅凭画面精确确认每一个接取动作发生在升级前还是升级后；但结论不受这一等级误差影响。

任务等级序列为：

`29, 30, 31, 33, 33, 34, 34, 36, 38`

- 若接取时玩家33级：3项低于玩家、2项同级、4项高于玩家。
- 若接取时玩家34级：5项低于玩家、2项同级、2项高于玩家。

第13集作者升到36级后，又同时处理30、31、33、34、35、36、38级任务，并接受40级后续《库尔森上校》。因此作者没有“只做低于当前等级”或“只做高于当前等级”的固定偏向。

更准确的规律：

- 接任务时：把同一枢纽可接、同一方向可做的任务尽量装满。
- 执行时：允许任务等级跨越当前等级上下约5级。
- 高等级后续：可以先接，但不一定立即完成。
- 是否立即完成：主要看目标怪实际等级、命中率、路线重叠和是否需要额外往返，而不是任务等级数字。

示例：

- 第12集以34级左右完成36级《破碎岭食人魔》，因为目标和路线可控。
- 38级《保全书籍》提前接取并沿路推进，但不会因任务等级高就单独硬刷。
- 第13集36级接受40级《库尔森上校》，但在本集不继续完成。

## 与此前设计路线的本质差异

### 视频路线

- 路线优先：先确定地图行进线，再把同方向任务全部装入。
- 任务包优先：以枢纽的一批任务和后续交接为单位。
- 跨等级带：任务等级可同时低于、等于、高于玩家等级。
- 跨集连续：上一集接取、当前集执行、下一集交付或继续。
- 高等级任务可携带：接受不等于立即完成。
- 低等级任务只要顺路仍然做，因为边际成本很低。

### 此前设计路线

- 从当前快照起算，遗漏上一集已经形成但尚未执行的任务包。
- 以“凑够到37的经验”为目标，路线结束点被等级目标反向控制。
- 过度依赖任务等级、推定合理完成等级和单任务成本。
- 将随机个人掉落任务拆成独立成本，低估了同怪并行时的共享击杀量。
- 按候选任务拼路线，而不是先找到一条真人可执行的地图路线再填任务。

### 修正后的方法

1. 视频至少读取前一集结尾、当前集、后一集开头。
2. 先提取真实枢纽、接取顺序、执行圈和回城节点。
3. 联盟任务逐项映射为：部落直接版本、同区替代、无替代。
4. 再用数据库核验前置、目标实际等级、固定经验和五开机制。
5. 任务等级只作为风险标签，不作为硬门槛。
6. 阶段等级是检查点，不是强制停手线；完成一个地理任务包后再看实际等级。
