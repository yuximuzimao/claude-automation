- `NDui` 保留，但 **NDui 自带姓名板已关闭**；当前姓名板交给 `Plater`。
- `Plater` 保留。
- `NewBeeBox` 保留：这是新手盒子插件下载/管理软件附带组件，不纳入精简名单。

- `Questie.zip` 是供项目/分析使用的压缩包，不按游戏插件重复项处理。
- 新手盒子配置中显示的 **4 个素材必须保留**。2026-09-14 曾误删，导致技能图标和物品图标无法显示；重新安装 4 个素材后已恢复正常。后续插件瘦身不得把“素材”当 AddOns 一起删除。

## 后续更新后的处理规则

1. 更新整合包后，先对照“已确认删除”6项；若被重新装回，直接再次删除/禁用。
2. 不因为整合包更新自动恢复 NDui 姓名板；默认继续使用 Plater，除非以后明确重新评估姓名板方案。
3. 素材、字体与插件分开处理。功能精简只针对 AddOns，不碰已验证必需的4个素材。
4. 新增删除项只有在实际确认“不需要/被保留插件完整替代”后再加入本文件。
