# QQ经典农场辅助

项目中文名：QQ经典农场辅助

## Session 启动

1. 读 SKILL.md。
2. 读 tasks/todo.md。
3. 读 docs/INDEX.md。
4. 真机观察前读 docs/CURRENT.md；再按当前任务进入玩法规则或种子资料。

## 当前目标

当前阶段是 QQ / 微信农场 UI 坐标制作与逐点核对，尚未进入自动化实施阶段。

此前助手设计/实现的自动化方案已被用户推翻。当前坐标核对阶段不以旧 Runner V2、现有脚本或旧实施计划作为实施目标；这是阶段性安排，不是永久弃用旧代码。用户逐步指挥要核对的页面和点位；助手负责整理两平台截图、候选坐标、确认状态和文档。坐标完成并进入新脚本设计后，按新需求重新评估旧实现，决定保留、局部改造、删除或重写，不预设必须兼容或全部推倒。

## 当前工作边界

- 唯一坐标核对页：工作区根目录 _sandbox/farm-coordinate-review.html；所有场景共用，不为每个场景新建页面。
- 土地与随场景移动的点使用已验证的 scene 层；首页贴窗口边缘的固定控件使用 fixed_ui 层。
- picker、弹窗、动态按钮、preview、确认按钮等必须直接采样验证，不得套用未验证的跨平台公式。
- 候选点只有用户明确确认后才进入正式坐标配置。
- 坐标核对只标点，不执行收获、种植、施肥、购买、领取奖励或发送分享等业务动作。
- 不主动等待或制造仓鼠气泡；好友农场只在用户明确授权的坐标核对或正常日常互动中观察。

## 安全边界

- 当前已验证的本机鼠标输入路径使用 CoreGraphics CGEvent，不通过 AppleScript / System Events 模拟账号内操作。该输入方式属于现阶段约束；坐标核对完成后的整体方案评估中，可结合新需求重新审查。
- 当前坐标核对阶段如需真机输入，必须取得当前 Chat 对本次操作的明确授权；历史会话、旧自动任务、Work handoff、子代理或先前测试授权不能替代本次授权。未来自动化的授权方式与定时执行边界，另在新方案中确定。
- 不主动充值、购买付费货币、消费不明确的高级资源，不处理账号安全/授权弹窗。
- 当前坐标核对阶段，有业务副作用的按钮一律只标点、不点击。
- 不把历史截图、旧代码常量或未验证推算值登记为用户确认坐标。

## Git / 数据边界

- data/seed-catalog.json、data/ui-layout.json、data/ui-anchors.json、assets/seeds/、assets/ui/ 与 scripts/ 是可版本化知识/工具资产；现有脚本不因此自动成为当前实现方案。
- 原始整屏截图、OCR 中间产物、坐标探针和实验脚本放工作区根 _sandbox/，不提交。
- 仓库数量是时间点观察值，再次实际操作时必要则刷新。
