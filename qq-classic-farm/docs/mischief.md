# QQ好友种草与放虫

本页维护用户2026-11-10指定的操作流程；当前验收进度见CURRENT/Todo。独立入口为 `scripts/farm_mischief_once.py`；由操作SOP按日常授权显式接续，`farm_qq_round.py`不会自动包含它。

## 判定与次数

- 点好友农场24号地后，出现“剩余数量”表示该地作物已成熟，跳过此好友，不采摘。
- 没有成熟提示，且识别到种草/放虫图标时才允许拖动。按钮位置从当前图片识别，不套用用户裁剪图的绝对坐标。
- 两个计数是**同一个每日共享余额100次**：任一操作成功一次，两处应一起显示99，不能按两份各100计算。
- 额度耗尽可呈现居中单按钮或双按钮：种草用完后可能只剩灰色放虫，放虫用完后可能只剩灰色除草；切换好友后可能显示双灰色按钮。所有可见按钮均为灰色且各自完整数字气泡匹配0、没有可用按钮时，判为当天完成。灰色但数字不明或颜色矛盾立即停止，不猜测。
- 不通过拖动次数推算成功次数。脚本统计的是种草/放虫手势次数，不是到账经验或实际消耗次数。

## 连续流程

1. 从正常自己土地首页开始；执行模式先通过首页确认器只读检查。
2. 点击好友、第一位拜访，再点24号地。
3. 成熟则下一位；没有可识别操作栏也转下一位，不在不明位置按下工具。
4. 有种草按钮则在识别到的按钮中心按下，保持鼠标按住，经过24号地后蛇形遍历24块土地，最后松开。
5. 再点24号地读菜单；灰色零余额则回家结束。没有放虫按钮则下一位；有放虫按钮则同样按住并遍历全田后松开。若首次查看只有放虫按钮，则只做放虫。
6. 放虫后再点24号地检查共享余额；未确认零余额则进入下一位，重复步骤。
7. 好友顺序复用已验证坐标：第二位、第三位，以及第四位起的右侧下一位。默认最多访问100次，达到上限仍未见零余额时回家并返回未完成，不能把访问完当成次数耗尽。

路线只使用 `ui-layout.json` 的明确土地中心：`24,23,22,21,17,18,19,20,16,15,14,13,9,10,11,12,8,7,6,5,1,2,3,4`。这是一条连续拖动，不是逐格点击；单击禁点约束不用于禁止用户明确要求经过的拖动路径。成熟判断按用户指定的24号地作代表，不额外推断其余23格的生长阶段；混合成熟情况及好友场景点24后的位移需在首次真机验收观察。

## 拖动工具与停止

`scripts/farm_path_drag.swift` 是QQ专用的一次连续手势工具，使用CoreGraphics。它不会修改现有仓库/商店滚动工具：

- 输入为操作按钮中心＋24个土地中心，共25个路径点。
- 一次鼠标按下，每段插值移动，最后一次松开；不会在每个地块重新按下。
- 每段移动前检查目标身份、窗口位置、焦点与遮挡。异常时先松开鼠标再返回部分执行不确定，不自动重试。
- 本流程的点击及拖动均使用farm_process.run_action托管子进程；非0、超时、SIGINT/SIGTERM先终止并回收动作进程组，再由farm_release_input独立释放左键并核验。释放失败明确报告INPUT_RELEASE_FAILED，不重放动作。
- 菜单不确定、点击失败或拖动失败立即停在现场，报告阶段；不通过额外点击掩盖异常。

## 使用

所有命令在`/Users/chat/claude/qq-classic-farm`执行；先按操作SOP打开农场并完成首页准备。

```sh
swiftc scripts/farm_path_drag.swift -o _sandbox/farm_path_drag
# 无输入计划预览
python3.13 scripts/farm_mischief_once.py
# 用户截图识别，不触碰桌面
python3.13 scripts/farm_mischief_once.py --image /absolute/path/to/screenshot.png
# 有人监管且明确授权后的真机执行
python3.13 scripts/farm_mischief_once.py --execute
```

正常运行使用 `--execute`，连续访问好友直到共享100次余额用完并识别到灰色零余额；不要传 `--max-visits 1`。`--max-visits` 仅为好友访问安全上限，不是应消耗次数。限一位仅用于明确要求的局部调试；访问上限退出表示未完成，不能推断余额或自动重跑。

模板来自用户提供的5张截图，`assets/ui/mischief/sources.json`记录来源序号和裁剪区域。原图仅保存在工作区 `_sandbox/farm-mischief/`。控件识别使用局部形状和颜色共同判断，防止绿色和灰色同形图标混淆。暂不OCR读取全部1–100数值；只严格识别结束所需的灰色零余额，其余次数以游戏界面为准。

## 返回结果与完成记录

真机模式只有退出0、`status=completed`、`reason=shared_quota_exhausted`且`shared_remaining=0`才能记当天额度已用完。Agent用文件编辑工具更新CURRENT对应自然日记录；`grass_gestures/bug_gestures/friend_visit`用于排错，不换算实际经验。

`stopped_returned_home`、访问上限或退出2仍是未完成，不能再调一次来“补满”；保留stage、reason、friend_visit和手势数。异常看图用[操作工具§4](execution-tools.md#4-异常看图与安全退出)，离线`--image`可对同一证据复核，不算重放动作。未知菜单没有统一自动修复入口。安全关闭也按工具§4，不直接在好友页继续点种植按钮。
