## 收获规则已收敛

- 正常收获只分一个条件：是否存在属于 4 格植物的“可摘”星星。
- 无四格可摘：手形一键按钮一次 → 等约3秒 → 空地终验。
- 有四格可摘：一次探测全部候选 → 只保留落在已知 2×2 四格区域中心附近的星星 → 连续逐个点击 → 手形一键按钮一次 → 等约3秒 → 空地终验。

- 4 格种子必须逐颗完成：打开目标 2×2 → 选种 → 出现 2×2 预览 → 明确二次确认 → 验收真正落地。
