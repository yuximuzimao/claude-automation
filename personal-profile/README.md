# 个人资料 / 职业档案

用于长期维护曲一凡的职业经历、求职方向与简历。

这个项目不是日记归档，也不是某个业务自动化项目。它只保存以后更新简历、修改 BOSS 在线资料、对照招聘 JD 时需要反复复用的个人职业信息。

## 当前入口

- 职业事实真值：`docs/career-profile.md`
- 简历表达与排版原则：`docs/resume-style.md`
- 当前简历正文：`docs/current-resume.md`
- 当前求职 / 在线简历状态：`docs/CURRENT.md`
- 文件导航：`docs/INDEX.md`
- 未完成事项：`tasks/todo.md`
- 阶段历史：`docs/archive/`

## 隐私与导出

- `private/`：联系方式等本地个人信息，不进入 Git。
- `exports/`：PDF / Word 等导出物，不进入 Git。
- 版本化文档只保留职业事实、表达规则和当前简历文本，不保存账号、证件、密码等敏感信息。
