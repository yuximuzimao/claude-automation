## 填写口径

### `服装图鉴.csv` 的 12 列

| 列名 | 含义 |
|------|------|
| `collectionType` | `set` 为套装部件，`single` 为暂未归套装的独立单件 |
| `setName` | 所属套装名称；独立单件留空 |
| `requiredPieceCount` | 解锁套装华丽魔法所需的必需部件总数；同一套装可重复填写，导入后落到套装级 |
| `gorgeousMagicPetName` | 华丽魔法对应精灵；没有或暂未知时留空 |
| `pieceName` | 部件名称，是最小展示/收集单位 |
| `category` | 部件分类，使用服装模型约定的 13 个枚举值 |
| `setRole` | `magic_required` 为华丽魔法必需部件，`optional` 为可选部件；独立单件留空 |
| `obtainType` | `standard` 为个人目标，`paid` 为只展示的付费非目标 |
| `obtainMethod` | 套装或部件的具体获取方式，未知时填 `待补充` |
| `obtained` | `是` 表示已拥有；付费件不能填 `是`，也不会写入个人进度 |
| `rawText` | 原始资料文本，便于回查拆分和命名 |
| `notes` | 名称差异、套装归属或具体类型等人工核对说明 |
