## 每个文件的详细要求

### 1. 外观图鉴.csv（最优先）

从游戏的"外观/装扮"图鉴界面逐行录入。只需要名称 + 是否已获得，其他字段尽力即可。

**填写后示例：**
```csv
name,rarity,series,source,source_details,obtained
迪莫·夏日泳装,紫,夏日系列,活动获取,2025夏日活动,是
火神·烈焰战神,金,,抽卡,,否
```

### 2. 家具图鉴.csv（最优先）

从游戏的"家具"图鉴界面逐行录入。

**填写后示例：**
```csv
name,series,size,source,source_details,obtained
星空壁纸,星辰系列,2x2,商店购买,,是
木质椅子,基础家具,1x1,图纸制作,主线任务解锁,是
```

### 3. 异色炫彩完整列表.csv

已预填152只精灵（从 wiki 数据中提取了所有有"炫彩突变"任务的精灵）。

**你只需确认：**
- `is_limited`: 是限定获取吗？（是/否）
- `limited_status`: 如果是限定，现在是 可获取 还是 赛季已过？
- `notes`: 补充捕获地点、天气条件等，可不填

**注意**：如果某些精灵游戏里根本没有异色形态，直接把那一行删掉。

### 4. 地区形态名称修正.csv

已预填100个地区形态（从 wiki 数据提取）。但形态名称是 AI 生成的（如"蜕皮时的样子""春天的样子"），不一定和游戏一致。

**你只需修正 `game_name` 列**，改成游戏里显示的真实名称。和游戏一致的直接打✓。

**填写后示例：**
```csv
sprite_id,sprite_name,form_index,sprites_label,game_name(请修正)
37,雪绒鸟,1,雪绒鸟（春天的样子）,雪绒鸟·春
37,雪绒鸟,2,雪绒鸟（夏天的样子）,雪绒鸟·夏
51,板板壳,0,板板壳（蜕皮时的样子）,✓
```

### 5. 其他类别统计.csv

在游戏里打开对应图鉴，看右上角的总数（如 "34/50"），填入 total 和 owned。
