## 每个文件的详细要求

### 1. 服装图鉴.csv（最优先）

从游戏的"外观/装扮"图鉴界面逐行录入。单件仍然是最小收集单位；套装的获取方式、特效、配对精灵是套装级共享信息，不要在同一套的每个部件上重复维护。

**填写后示例：**
```csv
collectionType,setName,pieceName,setHasEffect,setPairedPetName,setObtainMethod,singleHasEffect,singlePairedPetName,singleObtainMethod,obtained
set,木之本樱魔法装扮,发型,是,小可,洛克王国 x 魔卡少女樱联动活动,,,,否
set,木之本樱魔法装扮,上装,,,,,,,否
single,,独立服装样例,,,,否,,待补充,否
```

同一套装只需要在首个部件行填写 `setHasEffect`、`setPairedPetName`、`setObtainMethod`，后续同套部件可以留空，导入时归并到同一个套装。

### 2. 家具图鉴.csv（最优先）

从游戏的"家具"图鉴界面逐行录入。

**填写后示例：**
```csv
name,series,size,source,source_details,obtained
星空壁纸,星辰系列,2x2,商店购买,,是
木质椅子,基础家具,1x1,图纸制作,主线任务解锁,是
```

### 3. 异色炫彩完整列表.csv

已预填152只精灵（从 wiki 数据中提取了所有有"炫彩突变"任务的精灵）。

**你只需确认：**
- `is_limited`: 是限定获取吗？（是/否）
- `limited_status`: 如果是限定，现在是 可获取 还是 赛季已过？
- `notes`: 补充捕获地点、天气条件等，可不填

**注意**：如果某些精灵游戏里根本没有异色形态，直接把那一行删掉。

### 4. 地区形态名称修正.csv

已预填100个地区形态（从 wiki 数据提取）。但形态名称是 AI 生成的（如"蜕皮时的样子""春天的样子"），不一定和游戏一致。

**你只需修正 `game_name` 列**，改成游戏里显示的真实名称。和游戏一致的直接打✓。

**填写后示例：**
```csv
sprite_id,sprite_name,form_index,sprites_label,game_name(请修正)
37,雪绒鸟,1,雪绒鸟（春天的样子）,雪绒鸟·春
37,雪绒鸟,2,雪绒鸟（夏天的样子）,雪绒鸟·夏
51,板板壳,0,板板壳（蜕皮时的样子）,✓
```

### 5. 称号图鉴.csv

从游戏的称号界面录入。页面只显示一条主称号；如果游戏里显示为前后两段，录入时保留两段，前端会用中间符号拼接显示。

**填写后示例：**
```csv
upper,lower,obtainMethod,obtained
百分之零,魔法师,待补充,是
```

### 6. 遗迹副本.csv

从遗迹副本界面录入。奖励有多个时用 `；` 分隔。

**填写后示例：**
```csv
name,location,rewards,completed
遗迹副本样例,待补充,精灵蛋；宝箱；分光水晶；损坏的国王球；独角银币；各系血脉秘药,否
```

### 7. 其他类别统计.csv

在游戏里打开对应图鉴，看右上角的总数（如 "34/50"），填入 total 和 owned。
