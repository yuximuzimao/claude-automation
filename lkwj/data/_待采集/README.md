## 填写口径

- 服装：单件是最小勾选单位；套装获取方式、特效、配对精灵只写在同一套装第一行。
- 称号：游戏显示为上下两段时分别填 `upper` / `lower`；只有单段时填 `upper`，`lower` 留空。
- 商店：商店名优先使用 `data/shops.json` 已有名称；货币优先使用 `许愿星`、`独角兽银币`、`王国徽记`、`闪闪翎羽`、`绩点`、`拾光代币`。
- 地区形态：只修正 `game_name(请修正)`；确认和现有名称一致可填 `✓`。
- 通用品类：`category` 只用 `星星`、`支线任务`、`扭蛋机`、`音乐`，方便直接导入现有通用 Tab。
