# 采集规则

## 目标

从官方 QQ 当前可见/可滚动的指定群聊中取得尽可能完整的文字视觉信息，同时把对 QQ 的操作限制在最低必要范围。

## 允许的控制动作

默认只允许：

- 激活 QQ；
- 读取窗口几何/标题等系统可见元信息；
- 移动鼠标到已确认的聊天正文安全区域；
- 发送滚轮事件；
- 屏幕/窗口像素捕获；
- Apple Vision 本地 OCR。

不得：

- 点击输入框；
- 键入或粘贴聊天内容；
- 发送消息；
- 修改群设置；
- 加/退群；
- 自动操作成员列表；
- 依赖非官方 QQ 插件或注入。

如果后续确实需要“点击群列表切换目标群”，必须单独设计可验证的安全点击路径，且点击前确认目标控件不可能是发送/确认类动作。

## 正文读取优先级

1. 窗口级像素捕获：全屏实验验证稳定后优先。
2. 屏幕捕获 + 系统窗口几何裁剪：已验证可工作的 fallback。
3. Accessibility 正文只作为可选辅助，不作为当前主路径。

不得因 1/2 不完美升级到进程注入、数据库解密或协议抓取。

## 聊天区域

不得长期写死绝对屏幕坐标。

正式实现应把聊天区域表示为：
- 当前 QQ 窗口实时几何；
- 相对于窗口的聊天区；
- 必要时结合群标题等视觉/系统信号校验。

每轮正式采集前都要重新确认当前窗口仍是 QQ 且当前会话是目标群，避免 OCR 到其它应用或其它群。

## OCR前变化检测

滚动后先对聊天区域生成低成本图像指纹。

- 画面显著变化 → 进入 Vision OCR。
- 几乎未变化 → 等待有限时间后再检测。
- 连续有限次数无变化 → 交由状态机判断“未滚动成功 / 正在加载 / 已到边界”，不得无限重试。

变化检测是性能与可靠性门禁，不代替消息级去重。

## Vision OCR

- 使用 macOS Apple Vision。
- 优先内存中的图像对象直接 OCR。
- 保留每个识别块的 text、bbox、confidence 和当前 page_index。
- 识别语言至少覆盖简体中文和英文。
- OCR低置信文本仍可保留到 raw 层，但不得擅自“纠正”为模型猜测文本。

## 滚动

正式滚动以聊天正文区域上的系统滚轮事件为主，不依赖 Page Up 键盘焦点。

每次滚动应保留一定屏幕重叠，不追求整屏跳跃；重叠是后续可靠去重的重要证据。

## 停止条件

### 首次全量
达到用户给定历史边界、QQ实际可取边界，或经过明确验证的顶部/无变化边界。

### 每日增量
可靠命中上次 completed batch 保存的消息连续序列锚点。

“今天/昨天”文本只能辅助，不得作为唯一停止依据。

## 失败原则

- 捕获到错误应用/错误群：本页作废，停止本轮，不写入 messages。
- OCR失败：允许有限重试；原画面仍在时不先滚走。
- 滚动状态不确定：宁可停止为 incomplete，也不假装完整。
- 任何可能导致发送消息或业务写操作的异常路径：立即停止。
