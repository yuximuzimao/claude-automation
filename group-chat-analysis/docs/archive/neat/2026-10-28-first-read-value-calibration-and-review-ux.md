## 稳定编号

为降低用户反馈摩擦，每个 Silver 阅读单元新增稳定基线编号，如 `#001 / #304`。

编号性质：

- 基于完整 Silver 顺序生成；
- 不随筛选、搜索、翻页变化；
- 用户点击“没用 / 存资料库”后，其他编号不前移；
- 资料库或后续页面重建仍保留同一编号。

因此用户后续只需说“#304 有问题”，不需要复制整段卡片。

相关回归已覆盖“裁决/过滤状态不重新编号”。
