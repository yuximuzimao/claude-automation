# 群聊分析

一个本地优先的群聊文字采集与分析项目。

当前第一目标：从官方 QQ 客户端中以只读方式完整采集指定群聊的**文字信息**，整理成稳定的本地分析入口，再由 GPT 通过 CodexPro 读取并筛选有价值内容。

## 核心边界

- 不注入 QQ、不修改 QQ、不读取/解密 QQ 数据库、不获取密钥、不使用 NapCat/LiteLoader。
- 采集阶段不发送消息、不操作输入框，不自动改变群设置。
- OCR 使用 macOS 本地 Apple Vision；截图默认只存在内存，非诊断场景不落盘。
- 群聊原文、昵称、采集状态属于本地私密运行数据，不进入 Git。
- GPT 默认只读 `runtime/inbox/current.md`；分析时才把该批文字提供给模型。
- v1 只保证文字信息。图片、语音、文件、表情内容暂不做语义提取。
- 群友信息是线索，不自动成为其它项目的已验证事实；跨项目写入必须另行核验/确认。

## 稳定入口

- Agent：先读 `SKILL.md`
- 当前状态：`docs/CURRENT.md`
- 文档导航：`docs/INDEX.md`
- 当前待办：`tasks/todo.md`
- 架构：`docs/ARCHITECTURE.md`
- 每日分析输入（运行时）：`runtime/inbox/current.md`

当前阶段只完成项目建制与架构设计，尚未开始正式实现。
