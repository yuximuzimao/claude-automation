# 商品宣传图工作台

项目中文名：商品宣传图工作台

## Session 启动（必做，按顺序）
1. 读 `SKILL.md` — 项目入口、文件地图和操作边界，禁止跳过。
2. 读 `tasks/todo.md` — 确认当前待办和进度。
3. 处理具体品牌时，读该品牌 `brand-profile.json` 与 `asset-catalog.json`。
4. 读 `docs/INDEX.md` — 所有操作规则的权威入口。

## 项目目标
通过 GPT 对话完成模糊设计需求拆解、视觉判断、方案制定和局部修改指挥；通过本地项目持久保存品牌素材、图片描述、设计规则、任务状态和版本，使工作流可迁移到其他电脑或 GPT 账号。

## 关键边界
- 本项目不是固定模板生成器，必须能处理从未见过的宣传图类型。
- 历史素材描述解决“这是什么、如何使用”的重复沟通；当前构图、当前草稿和局部问题仍需按需查看图片。
- 未明确要求生成或修改图片时，不得调用生图工具。
- ChatGPT 对话附件与本地工作区不是天然同一文件系统。需要长期保存的附件必须导入本地品牌资产目录，并完成指纹登记。
